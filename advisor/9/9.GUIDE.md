# 2. 新的 operating envelope

## 2.1 Routine FAST-DIRECT envelope

本 GUIDE 不再使用 `D→A→Q` 作为所有常规目标的强制预条件。该 sequence 已经引入过明显的累计历史和 block-age 复杂性，也使“预热不超过 2 分钟”的人工约束难以直观解释。

新的常规目标 observation 定义为：

```text
FAST_DIRECT_V1

other source verified zero
source exact all-zero/off command
verified all-zero interval = 600 s
apply exact target or candidate command
continuous dwell = 120 s
capture
source all zero
```

含义：

```text
cool/reset proxy <= 10 min
single target warm/dwell <= 2 min
steady/settled claim = prohibited
```

## 2.2 独立 reset 的必要证据

一次 capture 只有在以下条件全部成立时，才能称为 independent FAST repeat：

```text
- source 在 reset 开始时已确认全零；
- 600 s 区间内没有任何 nonzero source command；
- reset 区间不是“保持上一 tested command 后单纯等待”；
- capture 元数据保存 off interval 和 exact zero/readback；
- source_on_elapsed 以该次重新上命令为起点；
- 前一个 mini-session 已明确结束并全零。
```

仅有字段名 `reset600`、sleep 600 秒或新的 session index 不足以证明独立 reset。

## 2.3 LONG validation envelope

Human 允许少量验证使用：

```text
LONG_VALIDATION_V1

off/reset proxy <= 1800 s
target continuous dwell <= 600 s
```

LONG：

- 只作 holdout；
- 不进入 FAST target fit；
- 不进入 FAST covariance；
- 不被称为 steady truth；
- 不用于放宽 FAST acceptance gate。

## 2.4 旧 chronology 的用途

旧 `D→A→Q`、长连续 block、R6、TD-B、TD-C 和 GUIDE7 数据继续作为：

```text
history_mechanism_evidence
candidate_generation_evidence
uncertainty_and_limitations_evidence
```

不得再作为新 FAST-DIRECT target 的 pooled center。

# 3. 强制 Ray-equivalent H/S 报告

## 3.1 目的

后续不能只报告：

```text
score = 1400
candidate failed
```

每一个 measurement-valid、可重复的 strip command 都必须被投影到 Ray 的冻结 HSI 流形，以回答：

> 该 exact RGBWW command 实际等价于 Ray 的哪个 Hue/SAT？

## 3.2 投影定义

对完整五通道命令 `u`：

\[
(h_{eq},s_{eq})
=
\arg\min_{h,s}
\left\|
W^{1/2}
\left[
f_{strip}(u)-f_{Ray}(h,s)
\right]
\right\|
\]

同时输出：

```text
requested_hue
requested_sat
ray_equivalent_hue
ray_equivalent_sat
circular_hue_error
sat_shortfall
orthogonal_shape_residual
projection_condition
nearest_competing_projection_distance
projection_unique = true|false
```

## 3.3 投影限制

若：

```text
projection is non-unique
inverse condition is unacceptable
orthogonal residual exceeds the frozen model-use limit
SAT is too low for identifiable Hue
```

则输出：

```text
ray_equivalent_status = no_unique_ray_equivalent
```

不得强行写一个 H/S 数字。

## 3.4 与 gamut 的关系

Ray-equivalent SAT 是描述“目前达到了多少”的主要进度量，但不能单独证明 `s_exact_max`。

只有：

```text
repeatable faithful lower endpoint
+
repeatable stable-nonfaithful upper endpoint
```

才构成可达饱和度 bracket。

# 4. 全项目统一停止状态

以后不得使用含糊的 `failed` 作为最终分类。每个目标必须落入以下之一。

## 4.1 `faithful`

```text
direct target-local gate pass
repeatability pass
reference pass
measurement quality pass
```

## 4.2 `stable_nonfaithful`

```text
exact command repeatable
measurement/reference valid
direct gate fail
best bounded search result frozen
Ray-equivalent H/S reported if unique
```

## 4.3 `operating_repeatability_unresolved`

```text
same exact command fails independent-reset repeatability
```

它是 operating-envelope limit，不是 gamut upper bound。

## 4.4 `measurement_unreachable`

```text
no legal observation inside frozen observer/exposure policy
```

它不表示光色不可达。

## 4.5 `bounded_search_exhausted`

```text
predeclared candidate/solver budget completed
stable best command remains nonfaithful
```

若该 command 可重复，可同时标记 `stable_nonfaithful`。

## 4.6 `faithful_region_not_established`

同一 Hue 在：

```text
SAT100
SAT50
SAT25
```

的有界路线内仍没有得到 faithful 且 Hue 可识别的 lower endpoint。

到此停止该 Hue 的 downward search；不得继续 SAT12、SAT6 或靠接近白点获得虚假的 Hue 成功。

## 4.7 `boundary_bracketed`

仅在有 faithful lower 与 stable-nonfaithful upper 时使用。

## 4.8 `operating_repeatability_limited`

高 SAT endpoint 在多次独立 reset 下仍不能形成 repeatable observation，但较低 SAT 可以。

这是产品 FAST 使用范围限制，不是颜色集合的物理边界。

# 7. H120 lower-SAT 路线

H120/S100 完成第 6 节分类后，自动进入：

```text
H120/S50
```

## 7.1 新的 bounded candidate-batch 方法

不再使用一个持续数十分钟的 adaptive strip block。

每个 target 的 candidate search 由独立 FAST-DIRECT mini-sessions组成。

### Batch 1

在设备运行前冻结最多 4 个 exact candidate：

```text
- P2 / historical model seed；
- high-white-participation candidate；
- RGB-dominant or low-white candidate；
- continuity candidate from nearest accepted H/S node。
```

它们只是多样化搜索点，不得由 prediction宣布通过。

每个 candidate：

```text
all-zero 600 s
exact candidate 120 s
capture
all zero
```

Ray before/after各一次。

### Best repeat

选择 direct score最低且 measurement-valid 的 candidate，追加两次独立 FAST repeat，使 best command总计 3 张。

### Optional Batch 2

只有当 Batch 1：

```text
- 至少两个 candidate稳定地沿同一方向改善；
- 离线局部模型给出清晰、不同的下一组命令；
- reference/measurement均有效；
```

才允许一个新 root 的 Batch 2：

```text
最多 3 个新 exact candidate
```

随后再次给最终 best command补足 3 张独立 repeat。

## 7.2 Target-level absolute budget

```text
candidate batches <= 2
unique tested commands <= 7
best-command repeats = 3 total
scale-relaxed diagnostic <= 1
lower-SAT fallback <= SAT25
```

达到任一上限即停止，不得用新名称继续同一搜索。

## 7.3 H120/S50 分支

### L-A — faithful

```text
H120/S50 faithful
```

若 H120/S100已有 stable-nonfaithful upper，进入 saturation bracket。

若 H120/S100是 repeatability unresolved，则按第 7.5 节寻找一个 stable upper。

### L-B — stable nonfaithful

进入：

```text
H120/S25
```

### L-C — operating repeatability unresolved

允许 H120/S25 一次；不在 S50继续换 face或scale。

### L-D — measurement unreachable

按一次 bounded exposure diagnosis处理。若无合法曝光，H120 route停止为：

```text
faithful_region_not_established_due_to_measurement
```

## 7.4 H120/S25 分支

### faithful

建立 lower faithful endpoint；可与 S50 或更高 stable-nonfaithful endpoint bracket。

### stable nonfaithful

```text
faithful_region_not_established
```

停止 H120 downward search。

### repeatability unresolved

```text
H120_operating_repeatability_limited_down_to_S25
```

停止 H120 downward search。

不得进入 S12、S10 或更低 SAT。

## 7.5 S100 不稳定时的上界搜索

若：

```text

S100 operating_repeatability_unresolved
```

则上行测试：

```text

```

分支：

- S75 stable nonfaithful：形成 `[50,75]`；
- S75 faithful：测试 S87；
- S75 unstable：测试 S62；
- 第二个上行点仍 unstable：停止为 `operating_repeatability_limited`。

上行 stability points最多 2 个，不得继续无限逼近 S100。

# 11. HSI command model 与 holdout

## 11.1 Ray target topology

继续使用：

```text

SAT0 Hue undefined
HSI and RGB endpoints separate
```

## 11.2 Strip command model

只使用：

- faithful nodes；
- stable、projection-valid nonfaithful boundary nodes；
- 明确 operating policy标签。

不得把 unstable endpoint作为普通数值节点插值。

模型应：

```text
Hue periodic
SAT monotone where data support it
command continuity regularized
white contribution explicitly tracked
active-set discontinuities retained, not smoothed away
```

## 11.3 Gamut compression

对有 `s_exact_max` 的 Hue：

```text
requested SAT <= boundary:
  faithful mapping

requested SAT > boundary:
  preserve Hue priority
  compress SAT toward boundary
  gamut_clipped = true
  report actual Ray-equivalent SAT
```

对 `operating_repeatability_limited` Hue：

```text
runtime status = operating_limit
```

不得伪装成精确 gamut compression。

## 11.4 Independent holdout

至少包含：

```text
H15/S50
H345/S50
one point near H285/S80
one non-node point in each 60-degree Hue sector
one low-but-Hue-identifiable SAT point
one point on each side of an active-set or scale-policy change
```

总数至少 8。

一次系统性 holdout失败允许：

```text
one local knot/refit
+
fresh holdout set
```

第二次系统性失败回 Advisor。
