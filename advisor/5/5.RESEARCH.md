## 1. 总结决定

### 1.1 数据有效，`nonlinear/non-additive` 标签不被接受

本轮接受 21 帧及其质量结论，但不接受 analyzer 的因果/模型分类。正确的新分类是：

```text
science_data_status = valid

scientific_classification =
  common_warm_reentry_shift_under_fast_protocol

r6_rank1_direction_transfer = rejected
period_main_effect = not_detected
predecessor_main_effect = not_detected
additive_model = not_rejected
nonlinear_or_interaction_effect = not_demonstrated
```

更保守的可读表述：

> 在 `off 600 s + dwell 120 s` 的人为短时协议下，初始冷却后 A0 与任意状态之后重新进入 A 的 warm-return center 存在共同偏移；偏移不能由 R6 的单一 PC1 漂移方向表示，但当前数据没有检测到 position、D/B/C predecessor 的稳定主效应，也没有拒绝加性模型。

### 1.2 不拟合复杂 thermal state-space model

当前不批准：

- exponential/多时间常数 thermal fit；
- ODE、Kalman/state-space、ARIMA；
- state × position 高阶 correction；
- 用同一 21 帧训练并验收 correction；
- 把热偏移塞入 covariance 以扩大通过范围。

原因是当前最主要遗漏项是一个简单的**共同 warm-reentry intercept**，而非已经被证明的非线性 interaction。

### 1.3 采用“两包络、无稳态声明”

```text
fit/acquisition envelope = fast_op120_reset600_v1
validation envelope = long_op600_reset1800_v1
```

- `fast_op120_reset600_v1` 是所有常规采集、Ray/strip 建模和优化的产品协议；
- `long_op600_reset1800_v1` 只作少量 holdout thermal-error validation；
- 两者中心和误差不得合并；
- long validation 不进入 fast target fit、covariance 或 threshold；
- 两者都不称为 cold equilibrium、settled 或 steady-state。

### 1.4 下一项科学动作

顺序冻结为：

```text
A. offline analyzer-v2 reclassification
B. strip-only 3x3 fast-protocol history experiment
C. two-state paired fast-vs-long Ray thermal bridge validation
D. Advisor review before combined TD-B / TD-C
```

不再重复 Ray 3×3 fast acquisition；现有 21 帧已经足够回答其设计内的问题。

## 2. 为什么原 `nonlinear/non-additive` 分类过强

## 2.1 `large_orthogonal_residual` 实际不是 additive-model residual

代码中的 `large_orthogonal_residual` 检查的是：


a. 每个 `A_after_Q - A0` 差向量；

b. 去掉其在冻结 R6 PC1 drift direction 上的投影；

c. 检查剩余分量是否超过直接 gate。

因此它准确表达的是：

```text
orthogonal_to_frozen_r6_direction_detected = true
```

它不等于：

```text
additive_model_residual_detected = true
```

事实上 artifact 明确给出：

```text
additive_model_rejected = false
```

九个真正的 additive-model residual score 仅为：

```text
0.8459 .. 1.1328
```

均远低于约 `9.5446` 的 frozen guarded limit。

## 2.2 当前模型遗漏了最重要的 common-return contrast

当前模型为：

\[
\Delta_{r,p}
=
\beta_0
+
\alpha_r
+
\pi_p
+
\kappa_q
+
\epsilon_{r,p}
\]

其中：

- `Δ = A_after_Q - A0`；
- `β0` 是所有 return anchor 共同的偏移；
- `αr` 是 session effect；
- `πp` 是 sequence-position effect；
- `κq` 是 predecessor-state effect。

原 analyzer 检查了 `π` 和 `κ` 的 contrasts，却没有把 `β0` 作为科学 contrast 报告。

本轮按包内 21 帧、冻结 58-feature、同一 pair variance 和同一 GLS design 进行独立只读复算，得到：

| 项 | whitened score | 解释 |
|---|---:|---|
| common return intercept `β0` | `14.8469` | 明显候选主效应，应使用正式 guarded routine 重算 |
| session 2 | `3.3985` | 未超过现有 guard |
| session 3 | `3.0071` | 未超过现有 guard |
| position 2 vs 1 | `2.6866` | 未检测到 |
| position 3 vs 1 | `4.3403` | 未检测到 |
| B vs D | `2.5079` | 未检测到 |
| C vs D | `2.8678` | 未检测到 |

common-return effect 在 R6 PC1 上的投影约为 `-0.4124`，而正交分量约为 `13.9917`。这说明：

```text
R6 PC1 is not a transferable thermal basis for OP120/COLD600
```

但不说明现象本身非加性。

## 2.3 原始 return delta 的结构

在九个 `A_after_Q - A0` 中，按同一 frozen pair variance 复算：

- `8/9` 超过约 `9.54` 的 direct compatibility limit；
- score 范围约 `8.845 .. 16.125`；
- 绝大部分差异位于 R6 PC1 的正交方向；
- 三个 session 的 A0 之间 pair score 约为 `3.01 .. 6.95`，均低于 direct limit。

这组结构最自然的解释不是某个 D/B/C 状态稳定地造成特异 hysteresis，而是：

```text
initial A after reset600
!=
warm A after any prior illuminated state
```

即 measurand 中混入了两个不同的 thermal/history envelope。

## 2.4 3×3 Latin square 的边界

3×3 cyclic design能平衡 predecessor 与 position 的主效应，但标准 Latin-square 加性模型假设 blocking factors 与 treatment 不存在 interaction。当前只有：

```text
observations = 9
parameters = 7
residual degrees of freedom = 2
```

因此它不适合凭一次实验拟合高阶 interaction。NIST 对 Latin-square design 的说明也明确指出，其基本模型依赖无 interaction 假设；如要识别 interaction，需要复制或改用更完整设计。

本项目不需要立即为 thermal physics 增加这种成本，因为产品目标允许一个明确定义的短时协议。

## 3. Human 约束如何进入科学定义

## 3.1 常规采集不是“近似稳态”，而是正式产品协议

冻结名称：

```text
fast_op120_reset600_v1
```

定义：

```text
between-session emitter-off/reset proxy = 600 s maximum
initial precondition A = 120 s maximum
state-to-capture dwell = 120 s maximum
steady/settled/cold-equilibrium claim = prohibited
```

600 秒不能再称为真正 cold proxy；建议 schema 使用：

```text
human_bounded_reset_600
```

120 秒也不称 warm equilibrium，而称：

```text
human_bounded_operational_dwell_120
```

## 3.2 必须把 initial 与 warm-reentry 分开

在 fast protocol 中至少有两个中心：

```text
A_initial120:
  A after reset600, then 120 s

A_warm_return120:
  A after another illuminated state, then 120 s
```

冻结规则：

- `A_initial120` 只作 startup/reset diagnostic；
- `A_warm_return120` 才是 command-switch calibration anchor；
- 两者不得平均；
- 两者差不得并入随机 covariance；
- 所有常规 HSI target 最好统一由 A precondition 进入，以固定 immediate predecessor。

## 3.3 长协议仅用于估计 thermal bias

冻结名称：

```text
long_op600_reset1800_v1
```

定义：

```text
emitter-off/reset proxy = 1800 s
state-to-capture dwell = 600 s
number of validation sessions = small and bounded
fit or covariance use = prohibited
```

long protocol 的用途是回答：

> 相同状态在 fast protocol 与更长 reset/warm 条件下偏移多少？这个偏移是否为 common，还是 state-dependent？

Human 已接受 thermal error，所以 long-fast 差异被检测到并不自动否定 fast protocol；它决定的是最终限制说明和是否可用一个 common thermal-bias summary。

## 4. 修正后的分析模型

## 4.1 Fast history model v2

对 return anchor：

\[
\Delta_{r,p,q}
=
\gamma_{reentry}
+
\alpha_r
+
\pi_p
+
\kappa_q
+
\epsilon_{r,p,q}
\]

正式 contrasts：

1. `common_reentry = γreentry`；
2. session 2/3；
3. position 2−1、3−2；
4. B−D、C−D、C−B；
5. additive-model residual；
6. raw return-delta compatibility；
7. orthogonal-to-R6-direction，仅作 transfer diagnostic。

分类优先级改为：

```text
if additive residual detected:
    interaction_or_nonadditive_unresolved
elif common_reentry detected
     and no position/predecessor effect:
    common_warm_reentry_shift
elif position and/or predecessor detected:
    additive_period_or_carryover_effect
elif all raw returns compatible with zero:
    no_history_effect_detected
else:
    underpowered_or_unclassified
```

`orthogonal_to_R6_direction` 不得单独触发 `nonlinear/non-additive`。

## 4.2 不确定性语义

保持：

```text
observer = frozen
58 features = frozen
pair variance / covariance = frozen
joint coverage / guard = frozen
exposure and frame selection = frozen
```

新增的 `γreentry` 是 operating-condition bias，不是随机 uncertainty。

常规 fast target center 可在其固定 envelope 内估计；long-fast 差作为独立 thermal bias 报告：

\[
B_{thermal,q}
=
\mu_{q,long600}
-
\mu_{q,fast120}
\]

不得使用：

\[
\Sigma_{new}
=
\Sigma_{old}+B_{thermal}B_{thermal}^T
\]

来让后续 candidate 更容易通过。

## 6. 下一项常规采集：strip-only fast history

Ray fast protocol 已经得到足够辨识数据；不再重跑 Ray 3×3。下一项常规采集应把同一问题应用到 strip：

```text

sessions = 3
captures per session = 7
total formal = 21
```

目的：

该实验属于 source characterization，不是 strip 色彩优化，也不构成 sentinel。

## 7. 少量长时验证：paired thermal bridge

## 7.1 必需设计

建立两个状态的 fast-vs-long paired bridge：

```text
Q = C (H300/S100)
Q = B (H0/S0)
```

选择 C/B 的原因：

- C 是历史 R6 唯一 blocking pair 对应的 stress state；
- B 是 white-heavy/SAT0，与高饱和 C 的内部负载路径差异最大；
- D 与 A 同 Hue 且为中间 SAT，在当前无 state main-effect 证据下优先级较低。

每个状态包含一个 fast mini-session 和一个 long mini-session：

```text
mini-session captures:
  A0
  Q
  A_after_Q
```

协议：

```text
FAST:
  reset/off = 600 s
  A/Q/A dwell = 120 s each

LONG VALIDATION:
  reset/off = 1800 s
  A/Q/A dwell = 600 s each
```

顺序平衡：

```text
C pair: FAST -> LONG
B pair: LONG -> FAST
```

必需总量：

```text
4 mini-sessions
12 captures
2 long-reset/long-warm sessions
```

最多允许一个条件性追加 pair：

```text
trigger = B/C conclusions conflict, or one valid run fails reproducibility interpretation
maximum total = 6 mini-sessions / 18 captures / 3 long sessions
```

## 7.2 分析

对每个 Q 报告：

1. `A_after_Q - A0` 在 fast 与 long 下的差；
2. Q direct center 的 long−fast 差；
3. B/C 两个 thermal-bias vector 是否兼容 common shift；
4. long protocol 自身是否仍出现明显 return split；
5. 所有结果继续用 frozen covariance 和 guard；
6. long 数据只作 holdout，不回写 fast target center。

## 7.3 结果分类

```text
thermal_bias_not_detected:
  fast vs long differences compatible

common_protocol_bias_detected:
  fast vs long detectable,
  but B/C bias vectors mutually compatible

state_dependent_protocol_bias_detected:
  B/C thermal-bias contrast detected

validation_inconclusive:
  long or matched-fast mini-session invalid/unrepeatable
```

前 3 类都允许继续把 fast protocol 作为 Human 选择的产品范围；区别只在最终 thermal-error 报告和是否可用一个 common bias summary。只有 `validation_inconclusive` 阻止 combined comparison。

## 9. 对抗式审查

| 假设 | 当前证据 | 反证/限制 | 决定 |
|---|---|---|---|
| 当前结果证明非线性 thermal dynamics | raw return delta 大且不沿 R6 PC1 | additive residual 全部通过；`additive_model_rejected=false` | 不接受 |
| C 有特异 carryover | R6 曾在 C 后首次越门 | order-balanced C contrasts 均兼容零 | 未证明 |
| position/cumulative time 是主因 | R6 PC1 近单调 | OP120/COLD600 position contrasts兼容零 | 当前不检测 |
| 什么 history effect 都没有 | period/state contrasts兼容零 | 8/9 raw return delta超界 | 拒绝 |
| common warm-reentry shift | GLS intercept大，session/state/position小 | 原 analyzer未正式测试 intercept | 首选并要求 exact gate |
| 需要更多 Ray 3×3 fast data | 复制可增加 df | 当前产品只需固定短协议，主遗漏已明确 | 暂不需要 |
| 可把 fast/long spread并入 covariance | 会提高表面 coverage | 系统偏差越大反而越易通过 | 禁止 |
| long validation必须通过才能采集strip | 可先减少风险 | Human 明确接受额外热误差；fast包络本身可独立定义 | strip history可先解锁，combined仍锁 |
| A0 可与 A returns平均 | 都是相同命令A | thermal/history envelope不同 | 禁止 |

## 10. 外部方法依据

### [E1] NIST/SEMATECH Engineering Statistics Handbook — Latin Square and Related Designs

用途：3×3 Latin square可用少量 run 平衡两个 blocking factor，但基本模型假设 blocking/treatment 之间没有 interaction；若要识别 interaction，需要复制或更完整设计。  
https://www.itl.nist.gov/div898/handbook/pri/section3/pri3321.htm

### [E2] NIST/SEMATECH Engineering Statistics Handbook — Measurement Process Characterization

用途：区分 repeatability、reproducibility、stability、bias、drift 与 hysteresis；支持将 fast/long protocol effects 分层，而不是混入一个误差池。  
https://www.itl.nist.gov/div898/handbook/mpc/mpc_d.htm

### [E3] JCGM GUM-6:2020 — Developing and Using Measurement Models

用途：measurement model 应包含已知 influence quantities，并只在已验证 input/operating range 内使用；支持把 reset time、dwell 和 previous-state envelope 写入 measurand。  
https://www.bipm.org/documents/20126/2071204/JCGM_GUM_6_2020.pdf

## 11. 最终研究判断

COLD600 V3 的最重要结果不是“发现了复杂 nonlinear thermal system”，而是发现了一个更简单且更适合产品约束的状态拆分：

```text
initial state after 10-minute reset
vs
warm re-entry state after an illuminated predecessor
```

冻结 R6 PC1 不能代表这个新短协议下的偏移，但当前 order-balanced 数据没有检测到 D/B/C 或 position 的稳定主效应，真正的加性模型 residual 也没有失败。因此最合理路线不是继续扩大 Ray history acquisition，而是：

1. 修正 analyzer，正式检验 common-reentry intercept；
2. 将 fast protocol 定义为产品 measurand，并把 A0 与 warm A 分开；
3. 立即转向 strip-only fast history characterization；
4. 用 2 个、最多 3 个长时 paired validation session 量化 Human 接受的 thermal error；
5. 在 Ray/strip fast envelope 都可解释后，再决定 combined TD-B。
