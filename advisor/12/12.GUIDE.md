# GUIDE12 — 满幅光色复制、有效测量、可解释覆盖与预测误差

日期：2026-09-29。角色：Advisor。依据：GUIDE11 完整处理后证据包（SHA-256 `5c348c023027e96b149edf41b4654d26b2dfc26e868add29f3b5e8243f9d5e65`）。

本文件规定科学问题、采样、判定和停止条件。实现纠偏见 `CODEX_GUIDE12_IMPLEMENTATION_PROMPT.md`；阶段结束交付合同见本文件第9节与 `GUIDE12_DATA_PACKAGE_REQUIREMENTS.md`。历史结果不可覆盖。

## 0. 决定与本阶段边界

GUIDE12 替代 GUIDE11 的活动路线，不从更早 GUIDE 拼接相冲突的门。完整补包足以开始本次审阅；明确未做、未记录或已经不可恢复的历史事项不再索要。

本阶段只研究：Ray CCT brightness=100%、HSI intensity=100%（API 1000），灯带实际五通道 PWM `max(CW,WW,R,G,B)=4095`。这是用户选择的满幅工作集合，不是已经证明的光通量全局最大值，也不要求灯带与 Ray 绝对亮度相同。把“低亮度一定降低 Ray 准度”留作未验证的物理假设；本阶段固定100%并不需要该假设成立。

上述100%/4095约束作用于正在被测或优化的点亮光源；隔离、reset与all-off必须真实关灯，不受点亮约束。不得为了“Ray始终100%”在拍strip时留下Ray污染。

停止新增 Ray/strip INT50/20/5 与 strip max3072/2048 实验。GUIDE11 已有低档数据保留为历史诊断，既不回填满幅模型，也不追认成满幅验证。后续调光阶段参考已验证的100%灯带自身颜色，沿自身 duty 建立补偿，届时另立阶段。

目前不能接受白光或彩光已经达到能力极限。接受的成果是既有观测、直接确认的命令偏差、真实 LONG 观察和有限的重复性估计。撤回作为当前采用依据的：45/70独立认证、中带连续域已经通过、四主Hue边界(0,25)、产品层SAT0已通过、C4低/中SAT通过、以及有界搜索等价于硬件极限。

## 2. 冻结分析量与有效测量

### 2.1 主层与并列层

主层继续采用固定白块 block_06 的原生四平面数据：

`G=(G1+G2)/2; z=[ln(R/G), ln(B/G)]`。

CCT/mired/Duv保持项目原计算模型及每点原容差。它们是相机观察者代理量，不能宣称光谱仪溯源精度。白光导航与最终判定统一：

`E=max(|e_K|/tau_K, |e_mired|/tau_mired, |e_Duv|/tau_Duv)`，`e=strip−同块Ray`。

彩光继续沿真实Ray菜单的实测H/S轨迹反解，不改成标准HSL/HSV。SAT≥25且Hue可辨识时，产品容差仍为Hue±2°、SAT±2个百分点；SAT0不评价Hue，两个log色比误差各≤0.01。低SAT用预冻结Ray局部轨迹的色度误差和可辨识程度评价，不强造Hue。

原58-feature严格层保持原ID、原统计、原判据并列报告，作为材料/空间响应诊断和主光色非劣时的次级优化目标。本GUIDE明确区分测量资格：主层要求固定block_06四平面全部有效；其他58特征无效则严格层“不完整/未通过”，不得因此把主层合法测量叫成物理不可达。不得删除四个主平面来使主层通过，也不得将这项分层追改成旧58层通过。block_05等已冻结中性块作独立一致性检查，出现不一致报告空间/反射/测量影响，不擅自换白块。

### 2.2 原生RAW削顶资格：新增明确的前瞻修正

不得把渲染后的sRGB图像饱和比当作原生CFA的饱和比。`rawpy.postprocess`的白平衡、颜色转换和显示曲线会改变渲染域的上限；该画像仅作辅助诊断。对原生主平面，保留原near-noise、像素数、nonfinite要求，增加以下资格：

1. 保存每平面的有效white level、min/max、分位数、均值、方差、MAD及上限附近计数；使用原像素掩膜，不能事后掩掉亮像素。
2. 至少使用 `effective_white_level−2 DN` 作为前瞻上限保护起点。出现白块大面积近上限平台，尤其min=max且方差0，直接判非定量观测；不能因旧`clipped_fraction=0`保留。
3. 2 DN不是已知线性区边界的物理定理。仍须用同状态两个相邻曝光档，验证曝光归一化主平面/色度的一致性；取较快的合格档位并保留余量。任何更大的传感器非线性区只能通过资格实验确定，不根据匹配失败调门。
4. 本轮先在满幅R、B及一个高白通道负载命令资格化。每类最多6张诊断；起点从已有数值预测安全快门，再最多两个相邻档，必要时反向复查一次。只改相机曝光，不降低Ray或strip输出；不因为更慢快门“看起来好”绕过削顶。
5. 仍无合法主层窗口时报告`measurement_window_unqualified`，停止该目标曝光搜索，不叫gamut不足。不自动引入HDR或改变ISO/光圈；那些是另行科学选择。

资格化帧不能同时当独立模型验收帧。后续固定目标block内快门不临时变更。实际MakerNote、设置请求、实际曝光三者分别记录。

### 2.3 隔离、时序与环境诊断

每张Ray前确认strip五通道为零；每张strip前确认Ray真实读回为零。FAST保持独立 `off600 → 精确命令120 → capture`；记录实际曝光起点，不把通信延迟藏入“120秒”。LONG保持`off1800 → command600`，少量独立holdout，不参与FAST拟合。不声称稳态。

本轮新增all-off环境诊断，不追索未拍过的历史照片。按实际曝光类别，在一次reset结束、点亮前拍all-off，并在该批结束再拍同档all-off；覆盖实际最慢strip档和Ray档，最多6类×2=12张。环境数据不是“相机盖帽暗场”：包含环境与暗信号，二者不可凭它们分离。

按每个主CFA平面比较`A/on`，并计算`z(on)−z(on−A)`的敏感性区间；环境项来自相应曝光/几何/时段，不用Ray百分比套到strip。若环境影响的上界足以改变产品判定，先遮光/稳定环境后重复受影响目标。禁止未经独立验证就给历史观测减背景或把不可测弱通道置零。改善环境后需新参考，不与旧环境中心混用。

## 3. 不确定度：N2补的是设计缺口，不是无限追噪声

### 3.1 已知与不可辨识分开

现有N1提供6个白光状态、每点2个独立循环，以及3状态的短burst；可给极小样本的条件t区间，不能从中证实正态性或可靠尾部分布。两个循环位于两个会话，cycle/session/order不能完全分离。当前没有逐点可迁移的预测模型。

历史环境温度、照度及环境照片没有记录：永久标记历史不可恢复。现有硬件不能单独辨识纯传感器与LED/PWM短时波动，亦不能把未测温的会话效应分成“温度占x%”：只报告合成分量。该结构性限制一次结案，不再制造下一轮追索任务。环境光本阶段可测，局部命令可控性、曝光线性和模型反解可验证，必须实际完成，不能统称不可知。

### 3.2 N2最小设计与预算

先固定4个白光状态（1800/100、3200/0、5600/100、20000/100）与2个极端彩光满幅命令（R主导、B主导）；后两者使用对应Ray H0/S100、H240/S100作本地参考。这里允许固定命令存在匹配偏差，不在重复性实验中优化。

每状态3个明确分隔的会话，每会话2个独立FAST配对循环，Ray/strip顺序在会话内反转并在会话间轮换：`6×3×2×2=72`张主观测。两次循环使会话内/会话间统计至少可区分。三会话仍不足以证明任意环境泛化，分量区间须如实给宽。

在3个代表状态的一次源观测中各源再拍2张紧邻burst，共12张，主设计合计84张。burst不增加600秒reset，不当独立循环；所有实际时间都记录。另允许最多6个未覆盖/最不确定风险状态，每点2组源配对，共24张，用于检查方差模型转移；N2科学捕获上限108张。曝光资格、all-off、优化候选另列预算，不能重复计数。

可让预先登记、命令已经冻结的N2循环兼任最终独立确认；必须共享同一个physical identity，不虚增n。若后续命令改变，旧N2只可支持明确验证的方差分组，不能当新命令确认。

### 3.3 统计输出

保存原始差向量与完整分组。优先在低维z/白点上分析`source + session + cycle + burst`，以设计中的独立单位估计；不对三会话拟合高维无约束协方差。均值CI与下一次独立FAST操作的PI分开。小n同时报告实测min/max、t条件区间、标准差的条件区间和参数不确定性。CI/PI必须标明适用的是哪个命令、源、协议、会话人群。

系统性order、session或LONG偏移作为独立影响，不能并入旧方差来放宽旧判据。若另建立未来操作误差模型，可以包含经验证的会话随机分量，但必须保留偏差项、效应区间和原门结果。相机波动已经在源测量中，不重复加一份“相机精度”。共享Ray、all-off、模型参数必须在源级重采样/MC中保留相关性。

所有产品通过声明要求：均值的联合95%区域、下一次操作的联合95%预测区域分别判断是否完全在既定容差内。未满足PI不能写“每次使用可复制”；可以写“均值近似/稳定偏差/操作范围未保证”。边际95%×多指标不自动等于联合95%；可用源级MC或预声明Bonferroni箱。不要把70点固定设计的点通过比例附上二项式总体CI。每点联合95%默认仅覆盖该点的多个输出，不等于全70点同时95%；若作全网格同时声明，须另做family-wise校准并注明。

逐点只在留一状态/留一会话的方差转移检验有支持时使用模型化区间。否则进入24张风险预算；耗尽后缩小采用域并给出该状态的可识别测量限，不以虚假数字填满表格。

## 4. 白光：四个剩余工作包

### W12-1：修正后有界求解与采用命令确认

立即离线重算49组W2同候选Ray/strip差、9个采用命令的全部有符号单位、25节点差分矩阵秩。历史Jacobian、P2/P3只能提供初值或探针排序，不当当前导数真值。全部目标参考在同目标block内直接测得。

按新鲜配对/历史有效观测形成一次冻结开放队列：先处理3200/0等大残差、1800/70与2000/100两个翻转节点，以及冷端风险。1800/100保持关闭主动G搜索，仅重复和报告。未变合格节点不逐个重做完整探针。

以实际PWM满幅face为约束。一个face固定某通道4095，其余4通道有界；探针必须仍在该集合。至少验证主色度两个非共线可用响应方向；若局部输出秩1，先区别“只测了一条方向”与“测了足够方向仍秩1”。后者只能称该face局部受限。

每开放节点的新增唯一命令先限8个（probe、候选、face种子均计入）；有实测改善且预测/实测方向一致才可扩至12个。至多2个有实测依据的满幅face，单步初始上限768码、无效预测按1/2缩短，最多一次重定局部中心。全阶段最多30个白光节点进入主动纠偏；不得按root/重启重置预算。

导航可在z中求信赖域步，但最终选择必须使用实际K/mired/Duv容差与不确定度余量；同一温度方向的K/mired不当独立秩。禁止先做无约束最小二乘再分别clip各通道并称它是受约束最优；实际候选必须满足完整约束，记录预测改善、实测改善、active face及方向证据。

每最多4个候选形成一个本地Ray before/after block，各strip候选独立FAST reset。若参考不兼容，仅该block不能认证；一次完整新block后仍失败，分类reference/operating_limited并继续其他节点，除非共享控制点也失败。不能把参考漂移误记成导数。

停止：达到预冻结误差/预测要求；或可行改善的置信上界已低于测量可分辨改善和整数变化尺度、且有效方向确已测试；或达到预算。三者分别命名`qualified`、`tested_neighborhood_practical_convergence`、`bounded_search_exhausted`。最后一项不是能力极限。量化受限只允许由直接相邻整数跨互斥容差且不确定度支持该跨越证明。

### W12-2：冻结真实70节点输出后独立验证

生成单一70节点实际PWM LUT；所有输出max4095，CCT/GM与API/raw-GM转换明确（旧raw GM100为中性，不是用户GM+1）。最终采用命令在验证前冻结。

一次新的70节点配对验证共140张。每个变更/尚未独立确认的最终命令至少再2个独立源配对，使独立验证达到3次；追加预算为`4×这类节点数`张，可复用事先登记且同命令的N2循环。选择帧不算这3次。未变节点可以有1次新配对加已验证适用的N2模型，但不可写“该点有3次实测”。

新验证后不继续无限调至70/70；只允许队列内尚未用完的预算和明确有预测改善的纠偏。命令再次变更须重新独立确认；原验证转为开发数据。最终可以带失败区科学收口，但不得把不可保证区域称满幅最高精度已验证。

### W12-3：真正满幅运行时插值

在mired×raw-GM中建立实际输出函数，明确face切换、duty转换、整数化及任何满幅投影的次序；最后实际PWM必须至少一通道4095。离线放大旧非满幅命令不使旧照片获得满幅资格。

冻结后采用20个新的非节点请求配对，40张；跨冷暖、GM两侧及face切换，并覆盖此前5300/100、6100/165附近失败结构。不能直接用已看过的旧20点再次宣称独立留出。

报告总的同点strip−Ray误差。节点本底与插值增量仅在有真实有符号基线且估计量可比时另报；没有节点数据不能用Ray−Ray=0充当节点误差，不把最近节点差异误称已分离的纯插值误差。

最多一次局部补点（≤6个knot，每点一配对）与新的6个留出配对，合计额外≤24张。失败则明确采用域、非采用域，不凭两个通过点画出整个连续矩形。

### W12-4：真实LONG的顺序复验

保持1800/100、3200/100、5600/100、20000/100四点，最终同命令；新增四组FAST/LONG配对，共16张。至少对GUIDE11偏差最大的20000与3200采用LONG先行，其余两点平衡，源先后也平衡。合并解释时保留此前全FAST先行的事实，不能把新旧拼成同一时段的理想ABBA。

主量仍为 `(S−R)_LONG−(S−R)_FAST`，另报每个源的LONG−FAST。若实际最终命令与GUIDE11不同，旧对照仅历史背景，不算同命令重复。最多对2个会改变采用决定的风险点各加相反顺序对照，共8张；本轮上限24张。

结论区分protocol-associated偏移、period/order影响和不可分离的组合。不把LONG当稳态，不回灌FAST拟合。单对照只给条件传播/描述，真实重复后才估计协议差的重复区间。

## 5. 彩光：五个剩余工作包

### C12-1：先让Ray映射能反解Ray自己

旧C3不再作为产品层SAT/Hue计量尺。立即离线做三张表：旧映射对Ray自身的反解误差；同命令有效strip−本地Ray的直接z差；实际满幅资格。不得把映射失配统称gamut不足。

使用真正Ray HSI/SAT0/INT100，不能取CCT均值或指定5600K代替。先用当前HSI S0在3个会话各一次作参考，并保留至少两个不同Hue的S0一致性诊断（可并入N2/优化参考，不重复计数）。旧Guide9真实S0只能作历史对照。S0白光命令也要经过满幅求解与独立验证，不能假定它必定通过。

保留历史P6的完整周期二维拓扑和非线性路径证据，利用GUIDE11有效Ray参考建立当前数值映射；历史到当前的数值转移必须检验。禁止不验证就退回“白点—S50—S100在log色比中线性”。周期样条/分片模型都可以，但选择依据是独立Ray标签误差与局部可辨识性，不是拟合残差小。

本轮对旧H120/S100、H300/S100仅允许一次新产品观察者/当前100%包络下的Ray-only资格检查，不重启旧58维无限solver；每目标S0控制加两次目标参考，最多3张。若目标持续不可观测/不重复，保留该扇区`reference_limited`，不阻塞其他Hue。

新增参考优先与本来就要拍的满幅strip目标配对。独立Ray留出至少10个，涵盖六扇区、0/360两侧、S10/S20和S75曲率区，具体未测坐标在拟合冻结前一次确定。既有C4已经被用于发现问题，不能再算新独立验收。除这些10张和优化配对自然产生的参考外，最多补12个Ray-only诊断点；总额外Ray-only预算≤31张（3个S0+6个特殊目标资格+10个留出+12个诊断，重叠可减少）。

要求源级不确定度与模型误差联合传播后，Ray自身反解与原菜单标签一致。为避免把全部±2容差消耗在尺子上，本轮预分配映射误差预算为Hue0.5°、SAT0.5pp；这是容差的工程分配，不是人眼阈值。应评价置信上界，不是仅训练集点误差。达不到时可在有直接参考的局部目标使用本地Jacobian评价，其他区域`map_unqualified`，不发布伪精确百分比。

逆问题保存完整局部Jacobian、奇异值、多解候选和联合(H,S)区域。SAT0/低SAT的Hue不确定或多解应如实表示；不通过任意取最小网格索引制造唯一性。原0.1°/1pp粗网格可作初值，不足以自行证明小于0.5pp的映射资格，需连续或局部细化并报告离散误差。

### C12-2：满幅主节点实际求解

六主Hue0/60/120/180/240/300各S50/S100，加S0，共13请求；参考确实受限的目标按上节停止并分类。现有有效满幅命令可以作为初值，非满幅命令只能提供方向，不以原照片认证放大版本。

明确作废近上限平台帧的定量solver输入。C1 B2公式虽然正确使用了z差，输入的24个失真候选却不能产生合法导数。不要仅补一个“渲染图片看起来正常”的判断继续使用这些斜率。

同目标同块Ray直接导航，先主色度再58层，使用与W12-1一致的真实fullscale face、局部可控性、信赖域、独立reset与参考检查。每请求≤8个新唯一命令，实测改善可扩至12，最多2个满幅face。独立确认至少3次，选择帧不算；可共享合法预登记参考但必须保留协方差。

如果某高SAT在两个合法face上没有可分辨改善，终止该请求并向S50/必要时S25推进。不得再通过降低Ray/strip总体强度诊断，也不得把一次错误曝光的饱和平台算作搜索已耗尽的物理证据。

### C12-3：每Hue覆盖，而不是寻找一个漂亮的最大点

每Hue默认请求S100→S50→必要时S25。此前四个S25命令全部非满幅，其失败不是本轮满幅边界证据；新S25使用修正后的真实满幅模型，按上节有界求解。到S25仍没有有效低端，不自适应下探S12/S10/S5；固定低SAT体验留出仍允许。

`s_best_tested`定义为：实际满幅、重复稳定、测量合法、逆映射合格且Hue有效的命令中，最大的实际Ray等效SAT。保存其区间及对应命令。它是可达能力的经验下界，绝不是硬件上界；也不等于“通过的最大请求SAT”。没有合格命令写null及原因，不写0。

`covered_intervals`要求实际模型在区间内的留出证据与可验证插值误差界；有限离散点本身不能证明所有实数SAT均可复制。无法给出连续保证时，分开列`validated_samples`与`model_supported_interval`及适用置信度。

有真实有效lower、稳定有界失败upper且局部请求行为单调时，最多5个中间SAT请求定向定位，每请求仍受唯一命令预算。若非单调，报告不连通/未建立连续区间，不硬套二分。`search_upper_request`只表示测试但当前策略未达到的请求，不证明任何其他命令不可达。

每Hue必须有数值表：请求H/S、实际H/S与联合区间、直接z差、Hue误差、SAT短缺、58层、actual PWM、有效face、独立n、模型/环境/会话影响及停止理由。使用误差界限制“Ray覆盖x%”的精度，映射未合格则不输出该数字。

### C12-4：运行时周期模型与独立体验验证

实际输出函数包括满幅约束、duty映射、取整和gamut压缩；运行时采用哪个函数就测哪个函数。Hue优先，SAT压缩单调，0/360连续；同时保存请求SAT与实际SAT，不把压缩后的颜色标成原请求已经复制。

冻结后另取10个新非节点请求，每个Ray前/后与strip观察，共30张；包括六扇区、两个周期近邻及两个固定低SAT点。不使用`distance<=C1最大失败distance`作为pass，旧C4“within_c1_anchor_envelope”只是一项比较，不是产品门。

最多一次局部模型修正与6个新留出（18张）。验证总误差、局部Hue方向、SAT单调性和有界预测区间。失败范围明确不采用；不凭观察到Hue大致排序就宣称线性饱和度体验复制成功。

### C12-5：满幅收口，不进入调光

分别交付：真实满幅支持范围；稳定有界近似但超容差；参考/测量限制；逆映射未建立范围。各Hue覆盖可不同，允许不连通，不要求全部S100通过。INT维度不计入本阶段里程碑。下一阶段低亮度的参考是本阶段冻结灯带100%自身颜色，不是Ray低亮度。

## 6. 科学预算的含义

预算约束的是有物理代价的新观测/新唯一命令，不约束修复普通代码错误的次数。不得因脚本语法错误耗尽“科学修复次数”，也不得为一次失败重置实验预算。

| 工作 | 固定/上限 |
|---|---|
| 原生曝光资格 | 3类×最多6张=18张诊断 |
| all-off | 最多6曝光类×2=12张 |
| N2 | 84张主体，含风险转移检查总≤108张 |
| 白光主动纠偏 | ≤30节点；每节点8、条件扩至12个新唯一命令；每≤4候选一个本地参考块 |
| 最终70白节点 | 140张，加`4×变更/未独立确认节点数`；合法N2重叠可扣减 |
| 白插值 | 40张；一次补点与新留出合计追加≤24张 |
| LONG | 16张；有采用意义时追加≤8张 |
| 额外Ray映射点 | 除主节点自然参考外≤31张，重复身份只计一次 |
| 彩光主请求/边界请求 | 每请求8、条件扩至12个新命令；每Hue中间边界请求≤5个；独立确认另计 |
| 彩光模型留出 | 30张；一次新留出追加≤18张 |

这是有限路径的上限，不是必须拍满的任务清单；不把所有上限机械相加后自动申请长跑。Planner先利用有效旧数据与预声明重叠，列出每个实际batch的新照片数、要回答的问题和early stop，再由Human授权。失败单点不阻塞另一条颜色主线。

## 7. 推进与回Advisor边界

普通实现错误、schema错误、单位修复、数据路径变更、单点预算内未达、已预声明的参考受限与预测区间宽，均可在本GUIDE内处理，不逐步请求Advisor。只在改变主观察对象/产品容差、引入HDR或新硬件、改变Human时间/满幅约束、系统控制点持续失效、或者科学分支确实未覆盖时升级。

没有“必须全部通过才算科学完成”的门。可以科学完成为有限域有保证、其他域稳定有界近似或已明确的测量限制。不能把“完成本轮预算”写成“最高精度的最大亮度已全部验证”；后者必须逐点/模型域满足其实际置信与预测合同。

## 8. 工作完成度口径

规划估计：白光约70%（合理规划范围65%–75%），8个总主里程碑，剩余4个工作包；彩光约50%（45%–55%），满幅阶段8个主里程碑，剩余5个工作包。百分比不是统计CI、颜色精度或色域比例。旧彩光9里程碑含INT维度，本轮明确剔除该维度，不能用C5执行量冒充满幅完成度。

## 9. 阶段结束后Agent必须交付的数据包

唯一交付：`GUIDE12-COMPLETE-PROCESSED-EVIDENCE-<实际结束日期>.zip`，另附同日期简明报告。完整字段与目录要求见 `GUIDE12_DATA_PACKAGE_REQUIREMENTS.md`，它是本GUIDE的一部分，不是可选“打包建议”。

至少包含所有有效/无效/失败/被拒/恢复前后的physical索引，完整逐帧patch统计、RAW小型数值与矩阵、请求/实际/readback/隔离证据、实际时序、环境诊断、精确LUT与运行时函数、全部候选/探针/最终确认身份、Ray映射和独立反解留出、源级区间模型输入与分组、最终逐点表、全部计算源码及配置、可离线replay脚本与逐成员manifest。
