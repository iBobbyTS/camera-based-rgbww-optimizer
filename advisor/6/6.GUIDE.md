# 2. Scientific method change: direct target-local comparison

## 2.1 Prohibited model

Do not use any of the following to predict a target absolute endpoint:

```text
independent core A absolute offset
+
independent post-state local coordinate

cross-session pooled warm-A center

FAST/LONG common correction

R6 600-second anchor transferred into FAST OP120
```

Parent artifacts remain valid only in their original descriptive scopes.

## 2.2 New primary measurement

For target `q` and strip command `u`:

\[
e_q(u)=f_{strip,q}(u)-f_{Ray,q}
\]

The Ray target must be measured in the same named target block and FAST operating envelope used for the strip candidate classification.

No absolute target may be synthesized from another experiment when a direct Ray observation is available.

## 2.3 FAST target-block contract

Each target block has:

### Ray start reference

```text
other source verified zero
Ray reset/off proxy 600 s
D = H120/S50 for 120 s
A = H120/S100 for 120 s
Q target for 120 s
capture Ray Q_before
Ray off
```

### Strip optimization block

```text
Ray verified intensity 0
strip reset/off proxy 600 s once
D command 120 s
A command 120 s
candidate Q command 120 s
capture candidate
```

For each additional candidate in the same target block:

```text
D 120 s
A 120 s
next candidate Q 120 s
capture candidate
```

No extra 600-second reset is required between candidates. The standardized `D→A` sequence is the immediate-history conditioner.

### Strip block drift controls

- repeat the frozen seed or current accepted base command after every two optimization updates；
- compare repeated base observations with frozen same-state pair coverage；
- if base drift fails, invalidate the target block and retain all evidence；
- one new-root repeat is allowed；
- a second drift failure is a mandatory Advisor gate。

### Ray end reference

After the strip block:

```text
strip all zero
Ray reset/off proxy 600 s
D120 → A120 → Q120
capture Ray Q_after
Ray off
```

Ray `Q_before` and `Q_after` must be compatible. If compatible, their mean is the block target. If incompatible, the block is invalid and may be repeated once in a new root.

## 2.4 Exposure and observer

Unchanged:

```text
Canon native Bayer
R/G1/G2/B
58 features
identity RAW response
frozen state-specific shutter map
frozen 1.0x..1.25x observer envelope
clipping/nonfinite/near-noise gates
source-level covariance and 0.9973 coverage
no threshold relaxation
```

Existing state-specific exposure qualification may be reused. Any new shutter outside the already qualified state policy is an Advisor gate only if it changes the frozen observer envelope; an ordinary replacement within that envelope is a Planner decision.


### Per-target solver ceiling

Planner may select the exact number within these ceilings:

```text
Ray references = exactly 2
strip base/seed = 1
full freedom probes = at most 4
feedback candidates = at most 4
confirmation captures = 3 ordinary / 5 boundary or near-limit
repeated strip drift anchors = at most 3
strip physical cap per target = 16
```

Use the existing bounded solver, backtrack and rebase. P2 remains seed-only.

## 3.2 Sentinel classification

### S-PASS

Required:

- H120/S100: measurement valid and `faithful=true`；
- H120/S50: measurement valid and either faithful or a stable, improving valid candidate whose failure is a frozen error excess rather than solver/measurement ambiguity；
- H0/S0: Hue excluded, SAT/shape valid；
- H300/S100: may be nonfaithful, but must return a stable best valid candidate and classified failure；
- all four Ray brackets pass；
- no unresolved strip block drift；
- cleanup and source isolation pass。

Then automatically continue to the 13-node INT100 grid. Advisor information-only report is allowed but no decision is required.

### S-SOLVER-RETRY

If H120/S100 or H120/S50 is measurement-valid but solver fails:

1. one autonomous offline solver-coordinate review；
2. one new-root repeat with the same scientific contract；
3. if it fails again, mandatory Advisor gate。

### S-MEASUREMENT

If a required point is not observable inside the frozen envelope:

- perform one bounded exposure-policy diagnosis；
- do not delete features or relax thresholds；
- if no legal exposure exists, mandatory Advisor gate。

### S-REFERENCE

A failed Ray before/after bracket allows one new-root repeat. Second failure is a mandatory Advisor gate.
