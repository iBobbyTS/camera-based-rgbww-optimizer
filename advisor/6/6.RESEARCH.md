## 1. v3 artifact 的实现审计

## 1.1 v3 做对的部分

以下结构是正确的：

- `r6_input_count = 0`；
- 只使用 FAST cross-source endpoint/core/history primitive observations；
- observation identity 在 Monte Carlo 前聚合；
- source-level Monte Carlo，`difference_center_used=false`；
- B exact `D→A→B` history cells 取自 session 1/2；
- B anchor-direction contrast 中 B observation 的 coefficient 为 0，说明 B 项发生代数抵消；
- B-minus-C contrast 中 core A coefficient 为 0，说明共享 core A 项发生代数抵消；
- observer、58 features、variance、coverage 和 parent artifacts 未被 refit。

因此，本轮不是推翻 exact-context 的基本思路，而是修正两个会改变最终数值的符号错误。

## 1.2 错误一：core A absolute offset 符号反了

项目统一定义：

\[
d_X=S_X-R_X
\]

正确的 synthesis residual 应为：

\[
e_B=d_B^{endpoint}-d_A^{core}-\ell_B
\]

当前 `core_a_terms()` 先生成：

\[
R_A-S_A=-d_A
\]

随后 `make_synthesis()` 又把所有非 endpoint term 取反，于是最终 residual 变成：

\[
e_B^{implemented}
=d_B^{endpoint}+d_A^{core}-\ell_B
\]

core A 被错误地加了两次符号方向。由于 core A cross-source offset 本身很大，这直接制造了：

```text
B exact pre score  = 1681.9585
B exact post score = 1680.5654
```

这些数值不能作为科学 gate。

正确的 primitive coefficients 应为：

```text
endpoint strip = +0.5 per endpoint session
endpoint Ray   = -0.5 per endpoint session
core strip     = -0.25 per core session
core Ray       = +0.25 per core session
history local  = negative of the local-coordinate coefficients
```

## 1.3 错误二：identity check 使用了相反符号

artifact 声明：

\[
e_{post}-e_{pre}-h_B=0
\]

其中：

\[
h_B=\ell_{pre}-\ell_{post}
\]

该恒等式是正确的。但代码实际计算：

```text
pre - post - h
```

正确实现应为：

```text
post - pre - h
```

当前：

```text
artifact identity norm = 0.000834955676
anchor-direction vector norm = 0.000417477838
```

前者正好约为后者的两倍。现有 test 只要求：

```text
identity_error < 0.01
```

这个容差比实际向量大一个数量级以上，因此没有发现符号错误。正确 test 应检查 coefficient identity 和浮点数值恒等式：

```text
max_abs(post - pre - h) <= 1e-12
L2(post - pre - h) <= 1e-12
```

不能用一个宽松的科学阈值测试代数恒等式。

## 2. 同一数据的更正后结果

使用：

- immutable v3 vectors；
- immutable TD-C core `mean(strip-Ray)`；
- frozen Ray/strip diagonal variance；
- 与 v3 相同的 primitive coefficient magnitudes；

进行只读更正。core coefficient 只改变符号，因此 null variance 和 guarded limit 不变。

### 2.1 更正后的结果

| Contrast | 更正后 score | Guard | 结论 |
|---|---:|---:|---|
| B exact pre synthesis residual | `24.3413505750` | `9.6022729131` | fail |
| B exact post synthesis residual | `24.3701108530` | `9.5625860610` | fail |
| B anchor direction | `2.8927944105` | `9.5618317255` | compatible |
| B-minus-C synthesis residual | `21.5722311246` | `9.5104544589` | fail |

更正后：

```text
norm(post - pre - h) ≈ 1.0e-16
```

### 2.2 正确科学分类

```text
cross_experiment_absolute_coordinate_synthesis_for_B = rejected

B_exact_local_coordinate_transfer = not_established

B_anchor_direction_effect = not_detected

B_C_relative_synthesis_transfer = failed
```

更简洁的 canonical classification：

```text
B_local_coordinate_transfer_unresolved
with_anchor_direction_compatible
```

但不能解释为：

```text
B physical bias
C-specific thermal cause
C-specific hysteresis
Ray/strip endpoint non-repeatability
observer failure
```

B、C direct endpoint paired-offset repeatability已经通过。失败的是跨 experiment/session 拼接的 absolute prediction，不是 direct endpoint observation。

### 2.3 B-minus-C contrast 的限制

B-minus-C contrast 已有 exact MC gate，且 core A 确实取消，因此它支持：

```text
post-state relative coordinate geometry
cannot be transferred unchanged to the new endpoint protocol
```

但是 C 不具备与 B 完全对称的两个 exact `D→A→C` cells。它不能单独证明某一个具体 state 的 physical bias。当前最稳妥解释仍是：

```text
cross-experiment state-relative transfer failed
```

## 3. 是否执行 B pre/post 12-observation experiment

## 3.1 该实验在统计上能回答什么

`A_pre → B → A_post` 的同 session 设计可以回答：

- 新 session 中 Apre/B/Apost 是否各自可重复；
- Apre 与 Apost cross-source anchor 是否不同；
- 新 session 的 B pre-anchor local coordinate 是否与历史 exact D→A→B coordinate 兼容。

因此，它不是无意义实验。

## 3.2 但它不是当前项目的最小必要动作

更正后的 v3 已经显示：

- pre synthesis fail；
- post synthesis fail；
- pre/post 几乎相同；
- anchor-direction compatible；
- pre/post residual 向量 cosine 约 `0.996`；
- residual 与 B-minus-C failure direction 高度一致。

所以当前主要问题不是 Apre/Apost 选择错误，而是**跨 experiment 的 local/absolute coordinate transfer本身不可靠**。

继续拍 12 张，最可能只会进一步解释一个已经可以绕开的模型分支。它不会直接产生：

- 新的 RGBWW 命令；
- Ray target LUT；
- `s_exact_max(h)`；
- 插值模型；
- 最终误差；
- 白光 70 点验证。

## 3.3 本轮决定

```text
GUIDE5_TD_C_FAST_ANCHOR_DIRECTION_B_V1 = not_authorized
GUIDE5_TD_C_FAST_B_PREPOST_TRANSFER_V1 = deferred_diagnostic_only
```

不是因为该实验不科学，而是因为它对最终项目交付的边际信息价值低于直接进入 target-local calibration。

只有后续 direct paired solver 出现以下具体失败时，才允许重新提出该实验：

```text
same target and same strip command
repeated within one direct calibration block
shows Apre/Apost-dependent candidate classification
```

在没有该新证据前，关闭 anchor-decomposition 路线。

## 4. 为什么应切换为 direct target-local comparison

目前已经获得：

1. TD-C core：FAST A cross-source offset 可重复，source order effect 未检测；
2. B/C endpoint holdout：B、C direct paired offsets 在相反 source order 下可重复；
3. FAST history：previous-state、position、additive residual没有形成稳定的主效应证据；
4. 失败集中在跨 experiment 合成，而不是 direct observation。

所以最直接、最贴近研究目标的 measurand 是：

\[
e_q(u)=f_{strip,q}(u)-f_{Ray,q}
\]

其中 Ray target 和 strip candidate 均在同一个冻结 FAST operating envelope 下、在相邻的 target block 中直接采集。后续求解器应最小化这个 direct difference，而不是依赖：

```text
independent core A
+
independent post-state local coordinate
```

这会增加少量 Ray capture，但显著减少 model ambiguity、Advisor gate 和无止境的 anchor decomposition。

## 5. Advisor 沟通频率审查

## 5.1 过去高频 Advisor gate 有一部分是必要的

此前多次 gate 发现了真正会改变科学结论的问题：

- 60 秒并非 steady；
- cold、warm return 和 session block不能合并；
- `reference_epoch_shift=false` 不能解释为无 shift；
- clipping 与 low signal 是不同 failure；
- common warm-reentry estimand曾错误使用 treatment-coded baseline intercept；
- TD-C core曾错误复用 Ray covariance；
- v3 又出现 core sign 和 identity sign 错误。

因此不能简单取消 Advisor。

## 5.2 但当前已经超过合理频率

现在很多 handoff 实际在询问：

- 一个已冻结统计分支应该叫什么名称；
- 一个 derived contrast 的实现是否正确；
- 预定义负结果后是否再拍一个只解释负结果的实验；
- 是否允许进入下一小步离线分析。

这些问题应由一个更完整的 science charter 预先定义，让 Planner 在合同内自行推进。此前“科学优先去工程化”也已经明确：普通实现 bug 应在当前 section 内修复，只有 frozen scientific contract、安全合同或 GUIDE 未定义科学分支才请求 Advisor。

## 5.3 新的里程碑式 Advisor 模型

### Planner/Executer 可自主决定

- ordinary implementation bug 与 algebra/unit test 修复；
- artifact schema 中不改变科学含义的字段纠偏；
- 预定义 target block 的执行顺序；
- 在冻结曝光档位内选择已验证的 state-specific shutter；
- 四点 sentinel、13 direct nodes、边界搜索和非节点 holdout；
- 预定义失败分支下的一次新 root repeat；
- 目标点之间的调度、分批和 balanced order；
- 直接 paired solver 的 step/backtrack/probe/rebase；
- 报告 P50/P90/P95/max 和 uncertainty budget；
- 白光 70 点的批次验证与失败点局部重优化。

### 只有以下情况必须回 Advisor

1. 改 observer、58 features、CFA、exposure envelope、covariance、coverage 或 threshold；
2. 改 Human 的 reset/dwell 上限；
3. 引入 time/temperature correction、state-space model 或运行时 thermal compensation；
4. 修改 P6 `full_periodic_2d_HB` topology、SAT0 或 HSI/RGB endpoint语义；
5. 把 `unconfirmed`、solver failure 或 measurement failure升级为 gamut/physical unreachable；
6. 稳定控制点在两次独立 direct solver attempt 中均失败，且不是普通实现错误；
7. 独立 holdout 系统性否定已冻结 interpolation/model；
8. 进入 P8 INT；
9. 冻结最终 `s_exact_max`、Gate-6、默认 LUT 或 runtime安装；
10. 发现 GUIDE 没有覆盖的新科学分支。

### 状态汇报但不需要决策

每个主要 batch 结束后，Planner 可以提交简短 progress report，但使用：

```text
ADVISOR_INFORMATION_ONLY
```

而不是 `ADVISOR_GATE_REQUIRED`。

## 6. 回到最终研究路线

## 6.1 HSI INT100 主线

```text
direct paired 4-point sentinel
→ 13 direct nodes
→ per-Hue saturation boundary
→ periodic/non-node holdout
→ final INT100 LUT/model/error report
→ Advisor Gate before P8
```

四点保持：

```text
H0/S0
H120/S100
H120/S50
H300/S100
```

所有误差直接相对同 block 的 Ray target，不再通过 core/local composition重建。

## 6.2 白光主线

现有 white-only 70 点候选不废弃。后续路线为：

```text
12 representative CCT/GM direct paired validation
→ failed nodes local re-optimization only
→ remaining 70-node final validation
→ at least 20 interpolation holdouts
→ 24-patch/held-out-material diagnostic report
```

P4 multipatch 仍是 diagnostic-only，不再要求先完成一个全局 multipatch forward model才允许白光项目收口。

## 6.3 Gamut 主线

对每个主 Hue：

- SAT100 faithful：边界为 100；
- lower SAT faithful、upper SAT stable nonfaithful：定向 bracket；
- boundary 必须有 repeat confirmation；
- full-scale failure至少做一次 max-code 3072 scale-relaxed diagnostic；
- 输出字段限定为：

```text
s_exact_max_fast_int100_fullscale(h)
```

不能简写成物理光谱色域。

## 6.4 最终 uncertainty 主线

最终报告必须分开，而不是合并成一个变大的 tolerance：

1. Canon/RAW/ROI repeatability；
2. Ray within-envelope repeatability；
3. strip within-envelope repeatability；
4. cross-session/block variability；
5. FAST vs LONG protocol bias；
6. solver residual；
7. interpolation/model error；
8. gamut compression error；
9. ColorChecker训练/留出与材料泛化；
10. 未覆盖的光谱、人眼和其他相机差异。

现有可直接进入最终报告的量包括：

- white Duv worst combined `3σ ≈ 1.48e-4`；
- high-CCT worst combined `3σ ≈ 120.84 K`；
- 一次 white command 的 60→120 秒变化约 `42 K / 0.000136 Duv`；
- FAST/LONG Ray holdout 对 B/C 显示 state-dependent Q-center protocol bias；
- FAST 600-second reset / 120-second dwell未被证明为 steady。

后续实验应补齐具体 Hue/SAT、节点、插值、gamut 和跨日分量。
