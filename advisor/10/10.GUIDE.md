

- 每个 Hue 的 strict faithful 区间，若存在；

- 超出灯带能力时的 Hue-priority saturation compression；
- 周期、非节点和 INT holdout；
- FAST/LONG 和重复性限制。

## 1.3 固定观察者

# 2. 双层结果体系：严格等价与最佳可达

## 2.1 `strict_equivalent`

表示在冻结 observer、uncertainty 和 acceptance limits 下，没有检测到超界差异。

白光必须同时满足：

```text
CCT gate
mired gate
Duv gate
repeatability / reference / measurement quality
```

HSI 必须满足冻结的 target-local strict gate、repeatability、reference 和 projection 质量。

## 2.2 `stable_best_approximation`

表示：

```text
- measurement/reference valid；
- exact command在独立 FAST repeats中可重复；
- 有界搜索预算已完成；
- command是已测试集合中的最佳结果；
- strict gate仍未通过；
- 误差和 stop reason全部报告。
```

这不是把 threshold 放宽后“通过”，而是项目真正需要的产品级最佳近似结果。

## 2.3 `operating_repeatability_unresolved`

同一 exact command 在合格 independent-reset FAST repeats 中无法形成可重复中心。该状态不能作为数值 LUT 节点参与普通插值。

## 2.4 `measurement_unreachable`

目标 source state 已确认建立，但冻结曝光/observer 不能产生合法 observation。它只描述测量链，不描述灯带色域。

## 2.5 `bounded_search_exhausted`

预先规定的命令、scale 和 lower-SAT 预算全部完成，结果仍 non-equivalent。若最佳 command 可重复，可同时标记 `stable_best_approximation`。

## 2.6 `strict_region_not_established`

同一 Hue 在 `SAT100 → SAT50 → SAT25` 的有界路线内，没有 strict-equivalent、Hue-identifiable 的 lower endpoint。到此停止下降，不继续 SAT12、SAT10、SAT5。

## 2.7 科学完成与产品采用分离

单个节点不是 strict-equivalent，不再自动阻塞整个 LUT 研究。科学路线完成条件是：

```text
每个节点有合法、有限、可复核的最终分类。
```

产品是否采用某个 `stable_best_approximation` 节点，由最终误差报告和 Human 的视觉/摄影使用判断决定，不通过隐式修改 threshold 实现。

# 3. Operating envelope

## 3.1 Routine FAST-DIRECT

```text
other source verified zero
source verified all-zero/off for 600 s maximum
apply exact target or candidate
continuous dwell 120 s maximum
capture
source all zero
```

语义：

```text
human_bounded_reset_600
human_bounded_operational_dwell_120
steady_or_settled_claim = false
```

## 3.2 Independent repeat

只有以下全部成立，才是独立 repeat：

- reset 开始前 readback 为全零；
- 600 秒内无 nonzero command；
- source-on elapsed 从重新上 exact command 开始；
- 上一 mini-session 已结束并归零；
- capture 具有 opposite-source-zero evidence。

## 3.3 LONG holdout

```text
reset/off <= 1800 s
target dwell <= 600 s
```

LONG 只作少量 validation：

- 不进入 FAST fit；
- 不进入 FAST covariance；
- 不被称为稳态真值；
- 不用于放宽 FAST gate。

# 4. 白光科学坐标纠偏

## 4.1 沿黑体轨迹的主导航坐标

白光局部搜索后续统一使用：


the reciprocal-temperature error:

\[
\Delta m
=
10^6\left(\frac{1}{T_{strip}}-\frac{1}{T_{Ray}}\right)
\]

和 perpendicular error：

\[
\Delta D_{uv}=D_{uv,strip}-D_{uv,Ray}
\]

即：

```text
white_local_navigation = normalized(mired_error, Duv_error)
```

原因：CCT 与 mired 是同一个沿 Planckian locus 坐标的非线性变换，不能在局部求解中一边忽略实际更严格的 mired gate，一边最后又用 mired拒绝结果。

## 4.2 CCT 的角色

CCT(K)继续：

- 作为人类可读报告；
- 作为现有 frozen final acceptance 的额外一致性 gate；
- 用于发现方向/计算错误。

但它不再与 mired 作为两个相互独立的优化轴重复加权。

## 4.3 多色块角色

58-feature/multipatch 在白光中继续作为：

- 光谱/材质响应差异诊断；
- 训练与 holdout 报告；
- 大方向异常检查。

当前白光节点 strict pass 仍由冻结 CCT/mired/Duv 合同决定；本轮不把尚未冻结产品容差的 multipatch score突然变成新的 hard gate。

# 5. `1800 K / GM100` 最终有界纠偏

## 5.1 当前证据

| observation | exact command | CCT error | mired error | Duv error | 结果 |
|---|---|---:|---:|---:|---|
| local candidate | `R4095/G1205` | `+4.5505 K` | `-1.2586` | `+0.00032905` | mired fail |
| reassessment r1 | `R4095/G1209` | `+7.0833 K` | `-1.9553` | `+0.00029555` | mired fail |
| reassessment r2 | `R4095/G1210` | `+8.8081 K` | `-2.4305` | `+0.00028779` | mired fail |

冻结 limits：

```text
CCT = 25 K
mired = 1.0
Duv = 0.0005
```

结论：G 增大时 Duv 改善，但沿 mired 方向越过目标。下一步必须沿 gate-aligned trade-off 做一次微型 bracket，而不是再增加 G。

## 5.2 预测整数区间

由已有 current-session G probe：

```text
d(CCT error)/dG ≈ +0.897 K/code
d(Duv error)/dG ≈ -1.04e-5/code
```

在 r2 中心附近，预计以下整数范围同时满足三个数值 gate：

```text
G = 1197..1204
```

该预测只用于 preregister test values，不构成通过证据。

## 5.3 实验 ID

```text
GUIDE10_WHITE_1800_GM100_MIRED_ALIGNED_MICROBRACKET_V1
```

## 5.4 固定命令与曝光

```text
CW = 0
WW = 0
R  = 4095
B  = 0

G test set = [1197, 1204, 1200]

Ray nominal shutter = 1/1600
strip nominal shutter = 1/50
```

以 Canon recorded exposure 为最终事实；不得在该节点的 bracket 或 confirmation 中临时改曝。顺序先测两个预测边界，再测中心，避免看到中心结果后临时选择边界。

## 5.5 Phase A：micro-bracket

```text
Ray target before
strip G1197, independent FAST
strip G1204, independent FAST
strip G1200, independent FAST
Ray target after
```

预算：

```text
Ray = 2
strip = 3
total = 5
ambient = 0
retry = 0
```

Ray before/after必须 compatible；每个 strip observation必须独立 reset600/dwell120、source-isolated、measurement-valid。

## 5.6 选择规则

### 有至少一个 strict pass

选择：

```text
先满足全部 frozen gates；
再最小化三个 normalized gate error 中的最大值；
再选择对 G±1 最不敏感的 command。
```

随后执行一个独立 confirmation block：

```text
Ray target before
selected strip command, independent FAST confirmation 1
selected strip command, independent FAST confirmation 2
Ray target after
```

两次 Ray reference 必须 compatible；结合 Phase A 的首次 observation，使该 exact command总计至少三次有效 observation。confirmation 不改变命令、曝光或 threshold。

### 三点均未通过，但存在单调 crossing

只有当实测 CCT/mired/Duv 随 G 的方向与局部模型一致，并可在相邻整数间推断联合 gate crossing，才允许：

```text
最多再测试 2 个新的相邻整数 G code。
```

整个节点最多：

```text
unique G commands = 5
maximum physical captures across bracket + optional refinement + confirmation = 13
```

若 refinement 中某 command strict pass，仍需使用独立 Ray bracket达到三次 valid command observations。不得为了用满预算而测试没有明确 crossing依据的 command。

### 无 strict pass

立即结束该节点，不重新探 CW/WW/B，不换 active face，不重做完整 probe。

## 5.7 最终分类

### W10-A：strict pass

```text
white_1800_GM100_strict_equivalent
```

### W10-B：可重复、无整数 strict pass，且相邻 code 证明离散冲突

只有在两个相邻 G codes的直接数据证明：一个越过 mired边界、另一个越过Duv或另一 frozen boundary，且没有联合可行整数时，才可写：

```text
white_1800_GM100_quantization_limited_under_R_active_face
```

### W10-C：可重复但仍不通过，未证明量化极限

```text
white_1800_GM100_bounded_local_nonconforming
cause = local_model_or_session_transfer_limit
```

### W10-D：最佳 command不能重复

```text
white_1800_GM100_operating_repeatability_unresolved
```

W10-B/C/D 均保存最佳可重复 command和实际误差，`strict_equivalent=false`，并停止该节点搜索。

# 6. 白光 70 节点完成路线

## 6.1 W1：关闭 representative 12

第 5 节完成后，不论 strict pass 或 bounded classification，代表性 12 点路线均视为科学完成。不得因单点小幅 strict miss无限阻塞后续 70 点。

## 6.2 W2：建立唯一 canonical 70-node state table

对每个 14×5 节点只保留以下之一作为当前候选：

1. 最新、合法、strict-equivalent 的 current-session command；
2. 若无 strict pass，最新的 repeatable bounded-best command；
3. 若 measurement/repeatability unresolved，保留原 command并显式标记，不能伪装成已纠正。

旧 session 的 observation不与新 session平均成一个虚假中心；它们作为历史 evidence和uncertainty来源保留。

## 6.3 W3：一次性低阶 command-correction field

为避免对 59 个失败节点逐个重复四方向 probe，允许一次候选生成层：

```text
input = 已测 current-session node corrections + strict pass nodes
coordinate = target mired × GM
model = low-order, shape-preserving, piecewise by active-face region
role = candidate generation only
```

限制：

- 不跨明确 active-face discontinuity做高阶平滑；
- 不使用多项式外推到没有 anchor的区域；
- 不把拟合误差当科学通过；
- 只生成每个未解决节点的一个候选；
- 只允许这一轮 correction-field generation，不反复全局 refit直到通过。

## 6.4 W4：70-node FAST validation round 1

对 canonical 70 个 commands做完整 direct Ray/strip FAST validation，source order按 batch平衡。

每节点输出：

```text
strict-equivalent / stable-best / repeatability-unresolved / measurement-unreachable
CCT / mired / Duv
neutral and multipatch diagnostics
exact command
session/order metadata
```

## 6.5 W5：残余节点的最后局部修正

每个 round-1 nonconforming、但 measurement-valid 且可重复的节点，最多允许：

```text
one gate-aligned local candidate batch <= 3 unique commands
one refinement <= 2 additional commands
best command total valid observations = 3
```

每节点 maximum unique commands：

```text
5
```

不得再进行第二轮全局 refit、第三次 local generation 或无上限 secant。

## 6.6 W6：最终 70-node validation

所有节点使用最终冻结 command进行独立 FAST validation。科学完成不要求 70/70 strict pass，但要求 70/70 都有合法最终状态且没有未解释的 source-isolation/reference问题。

## 6.7 W7：插值与 LONG holdout

### 插值 holdout

至少 20 个未用于节点修正的点，分层覆盖：

```text
mired midpoints
GM midpoints
1800..2300 K
10000..20000 K
low-CCT GM collapse
active-face transitions
```

允许一次局部 knot/shape-preserving interpolation修正和一套新的 holdout。第二套仍系统失败则停止，不继续调插值。

### LONG holdout

最多 6 点：

```text
1800/100
2300/200
3200/100
5600/100
14000/0
20000/100
```

只报告 FAST→LONG protocol bias，不回填 FAST LUT。

## 6.8 W8：白光最终产物

最终交付：

- 70-node canonical LUT；
- node status map；
- 20+ interpolation holdout；
- FAST/LONG差异；
- strict pass率与bounded-best节点；
- CCT/mired/Duv分布；
- multipatch/留出材质诊断；
- uncertainty和适用范围；
- 是否安装的Human gate。

58-feature strict gate继续报告，但不再是生成任何可用 HSI LUT 的必要条件。

# 8. Ray-equivalent H/S 与实际纯度上限

## 8.1 反投影

对 repeatable exact strip command `u`：

\[
(h_{eq},s_{eq})
=
\arg\min_{h,s}
\left\|
W^{1/2}\left[f_{strip}(u)-f_{Ray}(h,s)\right]
\right\|
\]

必须输出：

```text
requested_hue / requested_sat
ray_equivalent_hue / ray_equivalent_sat
circular_hue_error
sat_shortfall
orthogonal_shape_residual
projection_condition
nearest_competing_projection_distance
projection_unique
```

## 8.2 投影失败

若 projection不唯一、Hue在低SAT不可识别或orthogonal residual超出模型适用范围：

```text
ray_equivalent_status = no_unique_ray_equivalent
```

不得强行生成 H/S。

## 8.3 Strict saturation boundary

只有以下都存在时，才定义：

```text
s_exact_max_fast_int100_<output_policy>(h)
```

条件：

- 一个 repeatable strict-equivalent lower endpoint；
- 一个 repeatable stable-nonfaithful upper endpoint；
- 两端 Hue identifiable；
- 有界搜索得到最终 interval。

## 8.4 无 strict lower 时的实用纯度上限

若到 SAT25仍无 strict lower，不再虚构 `s_exact_max`。改为报告：

```text
s_best_tested_fast_int100(h)
```

定义：在所有 measurement-valid、repeatable、projection-valid tested commands中，满足 frozen Hue-identifiability/Hue-priority条件的最大 Ray-equivalent SAT。

它是：

```text
best tested camera-observer purity ceiling
```

不是物理光谱 gamut边界，也不是未测试命令空间的数学上限。

```text
  0, 60, 120, 180, 240, 300

SAT:
  50, 100

INT:
  100
```

已有合法分类直接复用。当前主要剩余：

```text
H0/S50, H0/S100
H60/S50, H60/S100
H180/S50, H180/S100
H240/S50, H240/S100
```

## 9.2 每 target 的绝对预算

```text
Batch 1 unique commands <= 4
optional Batch 2 additional commands <= 3
maximum unique tested commands = 7
best exact command valid repeats = 3
scale-relaxed diagnostic <= 1
lower-SAT fallback stops at SAT25
```

禁止：

```text
third candidate batch
unbounded active-face enumeration
more than one scale diagnostic
SAT below 25
same-command reshoot without a new repeatability purpose
```

## 9.3 Batch 2 的必要条件

仅当 Batch 1：

- reference、measurement和repeatability均有效；且
- 至少一个 command相对 preregistered base产生超过测量不确定度的有方向改善，或明显提高 Ray-equivalent SAT而未造成Hue方向恶化；

才允许 Batch 2。

若 Batch 1 只产生随机摆动、projection不唯一或没有可利用方向，直接冻结 Batch 1最佳结果，不用完预算只是为了“多试几个”。

## 9.4 每 target 最终输出

```text
strict_equivalent = true|false
best_repeatable_command
output policy / max code
ray_equivalent H/S or no_unique_ray_equivalent
Hue error / SAT shortfall
orthogonal and multipatch residual
repeatability/reference status
commands and batches consumed
stop reason
```

## 9.5 不阻塞其他 Hue 的单点状态

以下状态不阻塞网格：

```text
stable_best_approximation
strict_region_not_established
operating_repeatability_limited
isolated measurement_unreachable
```

只有系统级 Ray/camera/geometry failure，或多数新节点都无法得到合法 repeatable observation，才回 Advisor。

# 10. 每 Hue 的 lower-SAT 与停止策略

## 10.1 默认路径

```text
S100
→ S50
→ only if needed S25
→ stop
```

## 10.2 何时需要 S25

只在以下任一情况测试 S25：

- S50 stable nonfaithful，且需要寻找 strict lower；
- S50的Ray-equivalent SAT明显低于 requested，需量化低SAT曲线；
- S50 projection/Hue identifiability仍合法。

## 10.3 到 S25 后必须停止

### S25 strict-equivalent

可以与较高 stable-nonfaithful点形成 boundary bracket。

### S25 stable nonfaithful

```text
strict_region_not_established
```

冻结 best tested purity，不继续降低 SAT。

### S25 repeatability/measurement unresolved

```text
operating_or_measurement_limit_down_to_S25
```

不形成 boundary，停止该 Hue。

## 10.4 Boundary 搜索预算

存在合法 lower/upper bracket时：

```text
intermediate SAT values <= 5
provisional interval width <= 5 SAT points
final Gate-6 interval width <= 2 SAT points
```

超过五个中间值仍未收敛：

```text
boundary_search_budget_exhausted
```

# 11. HSI command model

## 11.1 输入节点

模型可使用：

- strict-equivalent repeatable nodes；
- stable-best repeatable、projection-valid nodes；
- 明确标注 output/operating policy 的 boundary或purity-ceiling nodes。

禁止把 operating-repeatability-unresolved 或 projection-nonunique节点当普通连续数值节点。

## 11.2 模型结构

```text
Hue = periodic
SAT = monotone where measurements support it
command field = continuity-regularized but preserves real active-set changes
white contribution = explicitly tracked
```

模型优先复现：

1. Hue方向；
2. Ray-equivalent saturation progression；
3. 避免异常orthogonal/material-response error；
4. command连续性和稳定性。

## 11.3 超界策略

### 有 strict boundary

```text
requested SAT <= boundary:
  strict/reference-faithful mapping when available

requested SAT > boundary:
  preserve Hue priority
  compress SAT to boundary shoulder
  gamut_clipped = true
```

### 只有 best-tested ceiling

```text
runtime status = best_approximation_limited
requested SAT maps to best repeatable command family
actual Ray-equivalent SAT is returned
```

不得把它标记成已证明的物理 gamut compression。

## 11.4 INT100 holdout

至少 8 个完全未用于 fit 的点：

```text
H15/S50
H345/S50
one high-curvature point near H285/S80
one non-node point in each remaining 60-degree sector
one low-but-Hue-identifiable point
one point near active-face/output-policy transition
```

一次系统性失败允许：

```text
one local knot/model refinement
+
one fresh holdout set
```

第二次系统性失败即停止模型 refinement并回 Advisor。

# 12. P8 INT 路线

## 12.1 新解锁条件

P8 不再要求至少一个 chromatic node strict-equivalent。进入 P8 需：

```text
- 13-node INT100 characterization全部分类；
- 至少4个不同Hue sector有repeatable、projection-valid best command；
- INT100周期/non-node holdout通过；
- strict boundary或best-tested ceiling语义已明确；
- unstable nodes未被普通插值；
- FAST output/operating policy固定。
```

进入 P8 仍需 Advisor gate。

## 12.2 首轮 INT 采样

```text
INT = 100, 50, 20, 5
```

只选择代表性集合：

- SAT0；
- 一个白通道参与高的中SAT点；
- 一个RGB主导中SAT点；
- 一个当前最难/最受限Hue；
- 一个当前最佳Hue。

先检验 normalized color shape 是否可分离。若可分离，使用一维强度层；若不可分离，只建立稀疏修正，不构建均匀三维密集 LUT。
