# 1. 总结结论

## 1.1 白光节点不应现在接受为最终负结果

`1800 K / GM100` 的三个最新合法结果均：

```text
CCT gate = pass
Duv gate = pass
mired gate = fail
```

而现有局部 solver 的二维导航量是：

```text
CCT_error / 25 K
Duv_error / 0.0005
```

它没有直接优化实际阻塞结果的：

```text
mired_error / 1.0
```

因此当前是一个**final acceptance 与 local navigation 不一致**的问题，不是已证明的灯带量化极限。继续重复相同的 `G=1210` 无科学增量；但直接把节点判成不可达也过早。

批准的最后动作是一个最多五个整数 G code 的 mired-aligned micro-bracket。无论结果如何，之后永久关闭该节点搜索。

## 1.2 白光后续不应逐个为 59 个节点重复完整四方向 probe

当前完整 70-node FAST validation 为：

```text
11/70 strict pass
59/70 local correction required
```

代表性 12 点的 local correction 又已经提供了一批 current-session correction anchors。若继续对 59 个节点全部执行完整四方向 probe，成本极高，而且没有利用白光 LUT 在 mired×GM 上应具有的局部连续性。

更合理的下一步是：

1. 关闭当前 1800/GM100；
2. 把最新合法 corrections 合并成唯一 node-state table；
3. 只做一次低阶、分 active-face 的 command-correction field，用于生成候选；
4. 70-node direct validation裁决；
5. 只对残余节点做有限微调；
6. 不进行第二轮全局 refit。

这不恢复 P2 为科学真值；它只是把已测 correction 的空间连续性用于减少设备采样，最终仍由 direct Ray/strip observation裁决。

## 1.3 彩光路线不应再要求先出现 strict faithful Hue

当前代表性结果为：

```text
H120/S100 = operating repeatability unresolved across tested scales
H120/S50  = stable nonfaithful
H120/S25  = no faithful lower endpoint
H0/S0     = stable nonfaithful
H300/S100 = reference repeatability unresolved; route closed
H300/S50  = stable nonfaithful
```

这可能正是用户最初担心的情形：Ray 的彩色纯度或跨材料 camera response 超出灯带。此时要求“至少一个 chromatic Hue strict faithful 才能测完整 13-node grid”形成循环：

```text
要证明灯带色域小，需要测各 Hue；
但因为尚未证明某 Hue strict faithful，所以禁止测各 Hue。
```

第十轮取消这一条件。完整网格的任务改为：为每个节点找到**有限预算内最佳、可重复、可解释的 command**，并报告 Ray-equivalent H/S。Strict equivalence 仍然保留为最高等级，但不是生成 best-achievable LUT 的前提。

## 1.4 项目必须有两个成功等级

原目标明确不追求光谱、CRI 或绝对准确。若把 58-feature 的 99.73%“不可分辨”设成唯一产品成功条件，即使灯带在 Hue/SAT 上已经非常接近，也可能因不同材料下的相机同色异谱长期显示 `nonfaithful`。

因此第十轮分开：

```text
strict camera-observer equivalence
stable best achievable Ray-HSI approximation
```

这不是放宽或更改旧 gate，而是避免把“没有达到最强等价等级”误写成“项目没有可用结果”。

# 2. 白光 `1800 K / GM100` 证据复核

## 2.1 三次合法 observation

| 轮次 | Command | CCT error | mired error | Duv error | Gate |
|---|---|---:|---:|---:|---|
| candidate | `CW0/WW0/R4095/G1205/B0` | `+4.5505139 K` | `-1.2586389` | `+0.0003290511` | only mired fail |
| r1 | `CW0/WW0/R4095/G1209/B0` | `+7.0832552 K` | `-1.9553101` | `+0.0002955541` | only mired fail |
| r2 | `CW0/WW0/R4095/G1210/B0` | `+8.8081082 K` | `-2.4304947` | `+0.0002877893` | only mired fail |

Frozen limits：

```text
|CCT error| <= 25 K
|mired error| <= 1.0
|Duv error| <= 0.0005
```

Handoff 中只列 CCT 与 Duv，因此表面上容易误读为“数值都不大，为何仍 fail”。完整 artifact 显示真正阻塞项是 mired。

## 2.2 低色温下 1 mired 很严格

定义：

\[
m(T)=\frac{10^6}{T}
\]

局部变化：

\[
\left|\frac{dm}{dT}\right|=\frac{10^6}{T^2}
\]

在约 `1900 K`：

\[
1\ \mathrm{mired}\approx 3.6\ \mathrm{K}
\]

所以当前 final gate 实际上要求沿 Planckian locus 的误差约在数 K 量级；`25 K` CCT gate在该位置明显更宽。CCT 与 mired不是两条独立颜色轴，而是同一坐标的非线性表示。

## 2.3 局部 solver 与 final gate 不一致

当前 white analyzer 明确要求：

```text
cct_pass AND mired_pass AND duv_pass
```

但 `white_point_metrics()` 和 `solve_damped_step()` 构造的 residual只有：

\[
r=
\begin{bmatrix}
\Delta T / T_{tol,K}\\
\Delta D_{uv} / D_{uv,tol}
\end{bmatrix}
\]

没有 mired 项。

结果符合这一结构：增加 G 使 Duv 从 `0.000329` 降到 `0.000288`，但把 CCT推得更高，mired从 `-1.259`恶化到 `-2.430`。下一次离线计划仍返回 G1210，说明旧导航坐标已经在自己的目标上停住，却没有满足真正的 final gate。

这属于 measurement/optimization model fitness 问题：测量模型应与要判定的 measurand和 acceptance requirement一致。JCGM GUM-6强调 measurement model需要 fit for purpose，并考虑已知影响；遗漏重要贡献可能给出错误的 measurand或过小的不确定度。第十轮不改变 final limits，而是把沿 Planckian locus的搜索坐标改为 mired。

## 2.4 G probe 的实际信息

`recovered-probes.json` 对 base `R4095/G1150` 给出 G 列：

```text
normalized CCT derivative = +146.8824 per full-scale weight
normalized Duv derivative = -84.8144 per full-scale weight
```

换算到一个 12-bit G code：

```text
d(CCT error)/dG ≈ +0.8967 K/code
d(Duv error)/dG ≈ -1.0356e-5/code
```

在 r2 strip CCT 约 `1908.09 K` 处，近似：

```text
d(mired error)/dG ≈ -0.246 mired/code
```

因此一个 code 对 mired 的影响是可辨识的，但并非大到只剩“两个 code之间无解”。

## 2.5 预测可行整数区间

把 r2 observation 沿已测 G derivative局部回推：

| G | predicted CCT error | predicted mired error | predicted Duv error | 三 gate预测 |
|---:|---:|---:|---:|---|
| 1196 | `-3.75 K` | `+1.04` | `0.000433` | fail mired |
| 1197 | `-2.85 K` | `+0.79` | `0.000422` | pass |
| 1200 | `-0.16 K` | `+0.04` | `0.000391` | pass |
| 1204 | `+3.43 K` | `-0.95` | `0.000350` | pass |
| 1205 | `+4.32 K` | `-1.20` | `0.000340` | fail mired |

这只是局部预测，current-session drift和非线性可能使它偏移；但它足以证明：

```text
quantization_limited = not yet supported
```

若 12-bit 量化真的是问题，实验需要直接显示两个相邻整数 command分别落在互斥的 acceptance boundaries两侧，而不是由三次方向错误的 candidate推断。

# 3. 为什么选择 micro-bracket 而不是新 full probe

## 3.1 已知方向足够

现有四方向 probe中，G 是当前命令附近直接调节 mired/Duv trade-off的清晰方向；当前失败又只差一个 gate。此时重新测试 CW/WW/B：

- 增加设备成本；
- 增加新 active-set/光谱变化；
- 可能把一个一维 gate-crossing问题重新变成高维搜索；
- 不能比直接测试预测可行整数更快地区分量化与模型偏差。

## 3.2 三个预注册 G 值的含义

```text
1197 = 预测联合可行区的低端
1204 = 预测联合可行区的高端
1200 = 接近mired中心
```

按 `[1197,1204,1200]` 顺序测量，可先看到两个边界，再看中心；不根据第一张结果临时选择另一个边界。

## 3.3 为什么允许最多两个 refinement

若实测关系保持单调，但整段因 session shift平移，三个点可能都落在 gate一侧。最多两个相邻 code足以定位一次离散 crossing。继续增加更多 code会变成在测量漂移中无限追阈值。

因此：

```text
maximum unique G = 5
```

是“足以判断局部整数可行性”与“防止无限搜索”的合理折中。

## 3.4 严格结果与可用结果分开

如果最终最佳 command只比 `1 mired` gate略差：

- 科学 classification保持 nonconforming；
- LUT仍可保存该 repeatable best command；
- final report给出实际 CCT/mired/Duv；
- 是否产品采用由 Human决定。

这符合 conformity assessment中的基本区分：specified tolerance、measurement uncertainty和accept/reject decision rule不是同一个概念。不能通过看到结果后改 tolerance来制造 strict pass，也不需要让一个小幅 strict miss阻塞整套研究。

# 4. 白光全网格路线审查

## 4.1 当前进度事实

当前证据至少包括：

- 旧 14×5、70-node white candidate；
- 70-node FAST-DIRECT 的 140 个 unique Ray/strip captures；
- frozen analysis：`11/70 pass`、`59/70 require local correction`；
- 代表性 12 点 validation；
- 5 个有 historical Jacobian节点已完成 local corrections；
- 6 个无 historical Jacobian节点已完成 probes/candidate/reassessment，只有 `1800/GM100` 尚未关闭。

这些 correction并未全部经过新的统一 70-node validation，所以不能简单把“代表点已通过”加到 `11/70`，宣称当前已有某个精确总 pass数。第十轮要求先形成 canonical node-state table，再进行统一 revalidation。

## 4.2 为什么 59 个独立 full probes不经济

白光目标沿 mired×GM是二维平滑控制面，而五通道命令在大部分区域也应具有局部连续性。已经测得的 local corrections包含：

- 哪个 active face有效；
- 各通道 correction的方向和幅度；
- current-session Ray/strip center差；
- 极端 CCT/GM区域的边界行为。

忽略这些信息、为每个失败节点重新拍 base+四 probes，相当于把每个节点当完全无关问题。它会显著增加：

- captures；
- reset/warm时间；
- session drift；
- exposure/reference故障机会；
- Agent决策次数。

## 4.3 一次性 empirical correction field

第十轮允许一个低阶、piecewise command-correction field：

\[
\Delta u = F(m,GM,\text{active-face region})
\]

其中 `m=10^6/T`。

它不是 Ray/strip的光谱模型，也不把 P2加法模型恢复为真值；它只是从已测 node corrections生成下一轮70个candidate commands。

科学约束：

- active-face切换处不跨区域高阶平滑；
- 无 anchor区域不外推；
- 一轮之后必须 direct validate；
- 不能根据同一 validation不断 refit到所有点通过；
- residual nodes进入有界 local micro-search。

这种“候选生成—独立验证”结构符合多基色系统的一般做法：多自由度解需要约束/正则化来选择稳定命令，但最终可达性必须由真实系统和目标观察者验证。

## 4.4 White completion不应等于70/70 strict pass

最理想结果当然是 `70/70 strict-equivalent`。但项目原目标是实用摄影灯色彩复制，不是计量级绝对标准。若一个或少数节点在有限搜索后仍小幅超 strict gate，应输出：

```text
strict pass rate
bounded-best node list
worst errors
interpolation impact
```

科学路线仍可以完成；安装由 Human基于实际误差决定。否则严格 gate会从质量标尺变成无限搜索触发器。

# 5. 彩光目标与当前 direct 58-feature gate 的关系

## 5.1 原始产品目标

用户要复制的是：

- Ray HSI Hue路径；
- Ray SAT数字的使用体验；
- WW/CW随饱和度的参与；
- 灯带达不到Ray纯色时的明确上限和压缩；
- 固定Canon观察者下的可测差距。

用户明确不要求：

- Ray SPD恢复；
- CRI/TLCI/SSI/TM-30等价；
- 绝对照度相等。

## 5.2 58-feature为何仍有价值

24色卡×Bayer planes提供比单白块更多的材料响应信息，能：

- 避免只在一个中性块同色；
- 构造Ray HSI经验流形；
- 识别Hue/SAT和路径弯曲；
- 量化Canon观察者下的metameric/material-response差异。

因此不能删除它。

## 5.3 为什么它不应是唯一产品完成条件

两个不同SPD即使主观光色相近，也可能在多种反射率表面上产生不同camera response。灯带又没有为光谱完整性优化。于是“58维差在99.73% measurement noise内”实际上是非常强的camera-observer equivalence等级。

当前：

- H0/S0、H120/S50、H300/S50均得到 repeatable、measurement-valid但极大direct score；
- 多轮face/scale/history实验没有产生 strict faithful chromatic node。

这既可能包含灯带Hue/SAT能力不足，也可能主要包含跨材料光谱差异。只用一个巨大的norm score无法直接告诉用户：“绿色纯度到底相当于Ray S多少”。

因此第十轮要求每个稳定command同时报告：

```text
Ray-equivalent Hue/SAT
Hue error
SAT shortfall
orthogonal/material residual
strict 58-feature equivalence grade
```

这样 strict-equivalence仍然诚实保留，而产品主目标也有可读进度。

# 6. HSI grid deadlock与纠偏

## 6.1 GUIDE9的旧解锁条件

旧条件要求：

```text
至少一个 chromatic Hue有faithful、Hue-identifiable endpoint
```

才能进入13-node grid。

## 6.2 为什么条件与gamut研究冲突

若Ray S100/S50超出strip的可达光色，先导点自然都可能nonfaithful。此时恰恰需要完整Hue网格来回答：

- 是所有Hue都不足，还是绿/青/紫特定方向不足？
- 每个Hue最多达到Ray的多少SAT？
- 哪些方向Hue能保住、只缺SAT？
- 哪些方向有较大orthogonal/material error？

因此“没有faithful点”应是网格characterization的输入，不应是禁止characterization的条件。

## 6.3 新的解锁依据

代表路线已经给出：

- 一个绿色方向H120；
- SAT0；
- 一个高曲率/洋红方向H300；
- reference、repeatability、scale/history、measurementfailure的多种结果。

这足以证明 measurement process能对合法点给出有界分类，也暴露了必须使用independent FAST mini-session的原因。第十轮因此解锁其余8个INT100节点，不再继续绿色基础设施试验。

# 7. 有限搜索和纯度上限

## 7.1 为什么固定命令预算比“直到收敛”更合理

五通道、active-face、scale和history组合形成很大的命令空间。没有光谱模型时，无法从有限局部失败证明全局物理不可达；反过来，也不能以“尚未证明不可达”为由无限搜索。

所以每个 target 的科学结论必须限定为：

```text
best result within preregistered diverse commands and one bounded refinement
```

这产生可复核的 empirical boundary，而不是虚假的数学证明。

## 7.2 Per-target budget

```text
Batch1 <= 4 diverse commands
Batch2 <= 3 only after measured directional improvement
one scale diagnostic
best command 3 repeats
SAT floor = 25
```

最大7个unique commands后停止。

## 7.3 Strict boundary与best-tested ceiling

### Strict boundary

只有：

```text
strict-equivalent lower
+
stable-nonfaithful upper
```

才可称 `s_exact_max` bracket。

### Best-tested ceiling

若没有strict lower，则报告：

```text
s_best_tested_fast_int100(h)
```

它回答：“在已经测试、可重复、Hue仍可辨识的commands中，灯带最接近Ray的最高等效SAT是多少？”

这正是用户提出的合理停止输出，例如：

```text
requested H120/S100
best exact RGBWW command
Ray-equivalent H118/S68
SAT shortfall 32
strict equivalence false
search budget exhausted
```

## 7.4 G=4095不是充分的gamut结论

单独写 `G=4095` 只说明一个物理通道触顶。实际颜色还取决于：

- CW/WW/R/B；
- code-duty曲线；
- scale/load；
- source age；
- observer和材料；
- active face。

所以“灯带纯绿等于Ray哪个H/S”必须对完整五通道command和指定FAST协议做流形投影。

# 8. HSI模型与holdout

## 8.1 模型目标

最终模型不是理论HSL/HSV，而是：

\[
u=hsi\_lut(h,s)
\]

使实际strip observation的Ray-equivalent H/S尽量跟随Ray命令曲线。

优先级：

1. Hue；
2. Ray-equivalent SAT progression；
3. projection唯一且orthogonal residual可解释；
4. command连续性；
5. white-channel contribution连续；
6. active-face变化不被假平滑掩盖。

## 8.2 可用节点

模型允许使用：

- strict-equivalent nodes；
- repeatable stable-best nodes；
- 已标注scale/operating policy的purity-ceiling nodes。

不使用：

- repeatability unresolved；
- measurement unreachable；
- projection nonunique。

## 8.3 Holdout

至少8个非节点覆盖：

- 0/360 wrap；
- 六个Hue sectors；
- 高曲率区域；
- 低但Hue可识别SAT；
- active-face或scale切换两侧。

只允许一次局部refinement和新的holdout。第二次系统失败即停止，不能继续加knots直到测试集通过。

# 9. P8 INT研究的纠偏

INT不应在INT100颜色模型完成前加入。新的进入条件不要求strict faithful chromatic node，而要求：

- 13节点均分类；
- 至少4个Hue sectors有repeatable、projection-valid best commands；
- INT100 periodic/non-node holdout通过；
- unstable nodes未进入普通插值；
- strict boundary与best-tested ceiling语义明确。

P8首先只测代表性5类颜色在 `100/50/20/5`，判断normalized color shape是否与INT近似可分离。若可分离，只需要一维强度曲线；若不可分离，再考虑稀疏修正节点，不直接建立密集三维LUT。

# 10. 不确定性结构

最终不确定性不能用一个总“误差条”代替。至少拆分：

## 10.1 Measurement repeatability

- Canon RAW/ROI；
- Ray FAST；
- strip FAST；
- source-specific exposure；
- independent reset。

## 10.2 Operating-condition effects

- 120→600 source-age shift；
- reset history；
- session/block；
- FAST vs LONG；
- active scale/load。

这些是condition/systematic effects，不加入随机covariance来放宽strict gate。

## 10.3 Model effects

- Ray manifold interpolation；
- Ray-equivalent projection；
- white correction-field candidate error；
- HSI command interpolation；
- gamut/best-tested compression。

## 10.4 Generalization

- 24色卡训练/诊断；
- 留出材质；
- 非节点；
- 跨日。

# 11. 外部调研与本轮用法

## 11.1 CCT与Duv

Y. Ohno 的 NIST/LEUKOS工作强调 CCT与Duv组合才是白光chromaticity的直观二维表达；CCT单独不能表达距Planckian locus的偏移。该文还覆盖约1000–20000 K的实用计算。

本项目的推论：

- 沿locus使用reciprocal temperature/mired更适合统一低/高CCT数值尺度；
- perpendicular方向继续使用Duv；
- 不应让solver只看宽松Kelvin tolerance而忽略final mired gate。

参考：

- NIST, *Practical Use and Calculation of CCT and Duv*  
  https://www.nist.gov/publications/practical-use-and-calculation-cct-and-duv
- DOE/PNNL, *Recommended Method for Determining CCT and Duv*  
  https://www.energy.gov/eere/ssl/articles/recommended-method-determining-correlated-color-temperature-and-distance

## 11.2 Measurement model fitness

JCGM GUM-6说明 measurement model需要adequate/fit for purpose，并考虑已知影响；实际模型通常只是可操作的近似，必须验证适用范围。

本项目的推论：

- final gate检查mired时，local search也必须沿mired/Duv导航；
- thermal/history不能被当随机噪声吸收；
- cross-experiment synthesis若holdout失败，应停止该模型而不是无限修补。

参考：

- JCGM GUM-6:2020, *Developing and using measurement models*  
  https://www.bipm.org/documents/20126/2071204/JCGM_GUM_6_2020.pdf

## 11.3 Conformity assessment

JCGM 106区分tolerance、acceptance interval、measurement uncertainty和错误接受/错误拒绝风险。

本项目的推论：

- strict gate不应看到结果后修改；
- strict fail不等于没有产品价值；
- best-achievable结果应单独报告，由Human决定是否采用；
- uncertainty不能恢复被忽略的模型坐标，也不能让系统偏差“变成通过”。

参考：

- JCGM 106:2012, *The role of measurement uncertainty in conformity assessment*  
  https://www.bipm.org/en/doi/10.59161/jcgm106-2012

## 11.4 多基色控制与观察者差异

多基色系统通常存在多个可实现命令，需要在gamut、功率、observer metamerism和连续性之间做约束选择；控制值的选择会改变观察者/材料误差。五通道前向模型适合生成候选，但实际非线性、热/负载和谱差要求独立验证。

本项目的推论：

- P2只能seed；
- correction field/LUT平滑只能生成candidate；
- full-scale某个active face失败不能证明整个五通道集合不可达；
- 但有限face/scale/command预算耗尽后，必须报告best tested ceiling并停止。

参考：

- H. Xie et al., *Multiobjective optimization for color display primary designs*, Journal of Electronic Imaging, 2017  
  https://www.hajim.rochester.edu/ece/sites/gsharma/papers/HaoMultiObjPrimDesignJEI2017.pdf
- M. Murdoch et al., *Characterization and control of a multi-primary LED light lab*, Optics Express, 2017  
  https://doi.org/10.1364/OE.25.029683

## 11.5 相机观察者边界

ISO 17321-1定义数字相机颜色表征测试方法，但本项目不宣称把Canon变成标准CIE观察者。固定native-Bayer链只是本项目有意选择的目标observer。

参考：

- ISO 17321-1:2012, *Colour characterisation of digital still cameras — Part 1*  
  https://www.iso.org/standard/56537.html

# 14. 本轮最终判断

## 白光 Advisor request

选择：

```text
run_one_final_mired_aligned_microbracket
```

不选择立即接受为terminal negative，也不选择重做完整高维probe。预测可行G区间和acceptance/navigation mismatch提供了足够具体的新假设；最多五个unique G code后必须停止。

## 白光全局路线

从“59节点逐个full probe”纠偏为：

```text
one empirical correction-field candidate round
→ full direct validation
→ bounded residual local corrections
→ final validation and holdout
```

## 彩光路线

取消“至少一个strict faithful chromatic Hue才能继续”的deadlock。后续目标是：

```text
finite characterization
+ Ray-equivalent H/S
+ strict grade
+ best achievable grade
+ explicit purity ceilings/limits
```

而不是继续围绕绿色寻找一个可能因光谱差异永远不存在的58-feature exact match。

## 项目停止原则

```text
没有一个节点可被无限搜索。
每个节点最终必须给出：
  exact best command、repeatability、strict status、可读误差、预算消耗和stop reason。
```

这使项目能够真正回答原始研究问题：白光复制到什么程度、各Hue的Ray饱和度能达到多少、哪些数值需要压缩、最终LUT和Ray相差多少，以及相机、热态、曝光和材料响应分别贡献多少不确定性。
