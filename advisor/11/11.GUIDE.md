# GUIDE11 — 光色复制优先、误差分层、有限搜索与真实验证

日期：2026-09-22。角色：Advisor。仅规定科学目标、实验设计、分析量、验收与停止条件；代码修改见独立的 `CODEX_GUIDE11_IMPLEMENTATION_PROMPT.md`。

## 0. 本轮决定

GUIDE11 取代 GUIDE10 的活动科学路线。历史 GUIDE 与分析保持原样，作为证据，不再拼接相互冲突的活动分支。

接受已有处理后观测与本轮补齐的数据。无需重采 P1/P2/P3/P6，无需继续追索没有保留的 W8 生成器。GUIDE10 的“完整包/采集完成”不等于科学完成：W6 是36/70点估计通过，W7是最近节点策略1/20通过，标为LONG的六点实际仍走600/120 FAST，彩光八个剩余主节点尚未执行。

**主问题是：在指定相机观察者和工作协议下，复制 Ray 的光色及控制体验，量化不能复制的部分。不是复制光谱、显色指数或全部材料的反射响应。**

不宣称无条件物理最优、稳态、所有相机/人眼一致。最终可交付的是：有测量依据的近似模型、可达集合的经验边界、剩余误差与适用范围。不能把预算耗尽重新命名成硬件极限。

## 1. 明确分开三个评价层

### 1.1 光色与控制体验：主评价层

白光：继续比较相同 Ray 设置下的 strip−Ray CCT、mired、Duv，沿用各点已有容差；CCT/mired属于同一个温度方向，不是两个独立噪声源。所有求解步骤必须针对三项实际容差进行导航。

彩光新增明确的产品色度坐标：以已冻结白块 block_06 的原生 R/G1/G2/B 测量计算

`z = [log(R/Gmean), log(B/Gmean)]`，其中 `Gmean=(G1+G2)/2`。

白块始终是固定观察对象，不声称理想光谱中性或CIE标准观察者。block_05等已合格中性块用于独立一致性检查，G1/G2差异仍单独诊断，不删除原RAW平面或58特征。新增坐标是从原观察导出的分析量，不替换原观测，也不追改旧门。

在这个二维坐标中，沿**实测 Ray H/S 轨迹**反解 Hue/SAT，不使用标准HSL/HSV公式，不假设白通道随1−SAT线性变化。必须检查局部可辨识性、周期性、多解与SAT0退化。

本轮预声明的产品工程目标（不是人眼JND，也不是标准规定）：对于SAT≥25、Hue可辨识的已测目标，Hue误差不超过2°、Ray菜单等效SAT误差不超过2个百分点；SAT0不验收Hue，要求两个log色比误差分别不超过0.01。中间和低SAT区间通过留出确认连续性；不得把2个百分点叫2%相对误差。这些目标同时报告点估计、95%区间和预测区间，后续不得根据失败结果临时放宽。

若主色度满足但全色卡响应不满足，分类为“光色近似支持、材料/空间响应不等价”，而不是旧58维strict通过。

### 1.2 58-feature严格相机响应：并列报告与次级优化

保留原冻结58-feature、原方差/覆盖门、原始结果。它负责显示全色卡相机响应是否一致，是更强的层级。

优化采取词典序：先改善主色度，避免主色度越界；在主色度非劣的候选中，再选择58维误差更小、对量化/重复性更稳健者。不得让很大的材料响应残差驱动求解器牺牲Hue或白点。

这是一项**公开的优化优先级调整**，不把旧58维nonfaithful改成faithful。历史报告中“strict_equivalent”字符串保持；新的文字说明区分“未检出差异/旧门通过”与“置信区域完全在产品容差内”。前者不自动证明后者。

### 1.3 操作包络与可信度：第三评价层

为每个输出记录：指定命令、输出尺度、FAST/LONG、验证日期/批次、预测是否来自插值、随机不确定度、会话差、材料响应、搜索停止原因。

可以独立出现：主色度好但会话不稳；主色度可重复但材料不等价；有界最优但超出容差；曝光不可观测。不得合并为一个无解释的“失败”。

## 2. 不变的测量边界

保持固定相机/几何、ISO/光圈策略、原生Bayer、现有required-feature质量要求和隔离规则。每张strip前确认Ray为零，每张Ray前确认五通道为零；使用各自已资格化曝光，不要求绝对亮度相等。

常规FAST：实际源关闭/全零600秒；应用精确状态；点亮120秒后采集。600秒和120秒是指定工作点，不是稳态证明。预热开始和相机采集存在的实际延迟照实保留。

真实LONG：实际关闭1800秒；应用状态；点亮600秒后采集。仅用于少量验证，不进入FAST拟合，也不称稳态。标注LONG、意外暂停、程序恢复或更长网络延迟均不能代替执行这一协议。

已经错标的12张W7照片改为追加FAST的派生分类，旧文件不改。1800/GM100那一对跨长暂停，不能作为普通短时间配对。不得因协议误标而丢弃其独立源观测。

具体设备实验仍需用户授权。普通计算/实现问题直接在本阶段修正，不再次创建架构或Advisor门。

## 3. 不确定度：必须回答“下一次会怎样”，不只回答“均值是多少”

### 3.1 先用现有数据完成离线基线

按物理照片身份去重，并以source、capture和实际时序配对，不用state名字连接热元数据。保持同一实验内共享Ray参考、共享暗场和共享基准的相关性。

分别保存：原始坐标、误差向量、点估计、样本量/独立循环数、条件测量95%区间、跨循环/会话模型的均值CI、下一独立操作的95%预测区间。

旧冻结方差传播结果仅为条件区间。全网格误差分布不是噪声分布；长时/会话系统偏移不加入旧方差以使旧门变宽。相机噪声已在source实拍波动中，不能重复相加。

### 3.2 最小新增辨识实验 N1

先选六个固定白光状态：1800/100、2300/200、3200/0、5600/100、14000/0、20000/100。覆盖暖端、红/白高负载、已知大残差、中间白和冷端。命令使用当前W6精确命令，不同时优化。

每点执行两个新、独立的FAST配对循环，分布在至少两个操作时段，并平衡Ray/strip先后。已有W6作为一次独立验证记录；与旧候选选择帧区分，不能把选中候选那一帧当独立确认。新采集预算为6×2×2=24张主观测。

在1800/100、5600/100、20000/100各一个循环，对每个源在同一120秒采集点增加两张紧邻RAW，合计再12张。因此N1最多36张，不增加这些burst的600秒reset，不把burst当独立热循环。采集延迟完整记录；若用户严格限制120秒后继续点亮，不做burst，明确将最内层噪声保留为组合分量。

估计三层：burst内、独立reset/cycle、跨session。六个点不能识别任意58维协方差，使用低维主色度和有物理分组依据的方差模型；正则化/部分池化必须预声明且做留一状态检查。与旧固定门并列报告，不替换旧判据。

若在未覆盖的active-face/负载分组出现明显不同的重复性，只增加最多六个风险状态，每点两个配对循环（最多24张），不重做整个P1。

### 3.3 预期分布与不可辨识部分

在n足够且没有单向趋势时，用分层模型或按完整循环重采样传播；小n同时给Student-t条件区间与实际min/max，说明正态假设未被验证。主色度方差传播时保留Ray/strip配对和非线性坐标；CCT、mired、Duv从同一Monte Carlo样本联合计算。

若会话/顺序有系统效应，先作为固定影响或独立状态报告，禁止称随机噪声。预测区间必须包含已验证可重现的循环/会话分量，并说明适用的工作条件；不能从三张照片制造99.73%经验分布尾部证明。

温度有现成传感器/温度计就记录环境、灯带背板、Ray外壳及时间。没有测温时，不强制购买或租仪器；只能量化组合的session/history分量，不能识别其中纯温度比例。纯传感器与PWM/驱动短时波动也可能不可分。**这类结构性不可辨识应一次写清，不在每轮重复标记为等待解决的未知。**

## 4. 白光主线：四个剩余工作包

### W1：统一目标与利用现有实测导数

冻结每点的Ray目标与全部容差，导航目标至少包含

`E(u)=max(|e_K|/tau_K, |e_mired|/tau_mired, |e_Duv|/tau_Duv)`。

mired和CCT通过同一色度模型传播。可采用平滑近似优化，但最终候选按真实E及置信余量排序。禁止仅导航CCT/Duv、最后突然追加mired门。

优先从W4/W5及旧合法局部扰动提取配对Ray参考下的实测响应。不同热协议/过时Jacobian只能提供初值，不是导数真值。只在导数证据确实不足的方向拍新probe；不得按通道字母序或误差正负猜通道作用。

### W2：一次有界纠偏与新的置信度评价

只处理W6未达到目标、且有可行改善证据的节点。每个开放节点最多三种新命令，包含新增probe在内；不因某次失败再清零预算。可使用一个真实替代active face，但它也计入三命令。始终保留当前实测最佳命令作为回退。

1800/GM100已被GUIDE10永久关闭主动搜索，本轮只观察重复性与报告限制，不重启G微调。

剩余量化只在有直接可辨识的局部单调证据时测试相邻整数；没有互斥边界跨越证据，不写quantization_limited。256/512码不能叫12-bit极限微调。

新的候选不能凭选择时的一张照片认证：在冻结后安排独立FAST确认，优先覆盖变更命令及接近容差/高风险点；其余未变节点保留W6证据，采用N1经验证适用的模型给出模型化区间。模型不适用的点进入风险追加样本，不伪装成逐点独立重复。

允许终态：目标及预测区间支持；点估计近似但预测不稳；稳定的有界最佳但超容差；曝光/操作限制。必须逐点给出数值和停止原因。只有验证过可行方向且有界改进不足以超过测量分辨力时，才称“已测试邻域内实用收敛”；不推断全五维物理最优。

### W3：真正连续插值与留出

明确最终实际控制模型。默认在mired×raw-GM坐标中做分片连续插值，处理active-face切换、整数码和连续限幅；不把最近节点复制冒充连续插值。模型必须输出有效12-bit命令，且光色随请求连续；满幅归一化/降幅策略属于模型本身，不能在验证后临时加入。

先离线给出旧W7二十点的真实候选命令并与历史最近节点命令对照。旧W7只能用于诊断/模型选择，不能在使用它之后仍叫独立留出。

冻结模型后，采集20个新的非节点配对（40张），按冷暖段、GM正负、active-face切换分层，至少包含两个已知困难区。CCT/GM点必须在采集前固定，禁止看结果后替换。每个点都同时报告节点本底残差和插值增量，不能把二者混称插值误差。

只允许一次局部加点修正，最多六个新knot；之后使用新的留出，不复用促成修正的照片认证。再次系统性失败则交付范围缩小/分段模型及失败区，不无限加密。

### W4：真实FAST/LONG验证与最终白光报告

首选四点：1800/100、3200/100、5600/100、20000/100。在同一冻结命令下，各做一组FAST与一组真实LONG配对；四点中两点FAST先、两点LONG先，源先后也平衡。共16张主观测，包含8个LONG源观测，不增加长期拟合。

主量为 `Delta_protocol=(strip−Ray)_LONG−(strip−Ray)_FAST`，并分别报告Ray_LONG−FAST和strip_LONG−FAST。该差不能被叫成已证明的物理温度因果。

只有结论/区间会改变产品采用时，允许对最大偏差的最多两点各再做一次相反协议顺序配对，共追加不超过8张。全阶段最多24张。单对照的点只能给条件传播区间，重复点可给有限样本的协议/会话差估计，不能把四点外推成任意CCT的已测热图。

输出70节点及连续运行域的主误差、条件/预测区间、额外协议偏差、未适用区域、58维材料响应和采用建议；保留局限也可以科学完成，不需要70/70严格通过。

## 5. 彩光主线：六个剩余工作包

### C1：完成尚未执行的八个主节点

直接进入 H0/H60/H180/H240 各S50、S100，INT100。H0/S0只是白，不算H0红色。不能再次要求先出现一个58维faithful Hue。

每target采用新主色度目标与旧58维并列报告。Batch1最多四个不同命令；只有实测改善支持才进入Batch2，最多三个。每个command独立FAST reset，Ray参考按目标局部获取；不恢复一小时连续探针块，也不用旧跨实验absolute-anchor合成目标。

最终所选命令需要三次独立FAST观测（选择帧加两次独立确认，但推断时标记选择过程；有独立验证记录优先用验证记录）。Ray前后不兼容则该块不用于匹配认证；允许一次完整新块，第二次失败关闭该目标为参考/操作限制并继续其他Hue，除非共享控制点也失败。

H120/S100和H300/S100的已关闭失败路线不自动重开。可以用其他Hue新数据改进离线假设，但不得重置其历史搜索预算。

### C2：每Hue的有界SAT可达范围

S100→S50→必要时S25。到S25仍无产品层有效范围就停止向下搜索；不自适应搜索SAT12/10/5。允许固定低SAT留出，这不是向下寻找通过点。

每Hue最多一次较低满幅尺度诊断（优先3072），必须真的在该尺度求解，不只缩放旧4095命令。输出尺度改变后仍只能声明特定尺度/负载下的结果。

出现有效lower和稳定nonfaithful upper时，最多五个中间SAT请求用于定向括界。失败upper只能叫“该搜索策略下的失败请求”，不是物理不可达证明。

报告三件不同的量：

1. `s_best_tested`：已测试、稳定、Hue有效命令的最大等效SAT及独立确认区间。它是可达能力的经验下界，不是未经穷举的硬件上界。
2. `covered_intervals`：已验证能连续复制的SAT区间。孤立高SAT点不能证明从0到它全覆盖。
3. `search_upper_request`：测试但有界未达的请求及停止原因。可能存在未搜索到的更优命令。

新产品层的H/S反解只在原生中性块色度的有效Ray映射内成立；旧58维投影另存，不能混用同一字段。

### C3：当前Ray映射与周期Hue×SAT命令模型

保留P6拓扑与历史节点，不要求重拍106帧。但历史P6数值只在当前协议验证后用作等效SAT坐标。利用C1/C2本来就拍摄的Ray参考建立当前锚点；先检查同一设置当前Ray是否反解回自身标签。

若历史到当前有系统偏移，不用一个未经验证的全局平移修正全部Hue。优先用新鲜Ray锚点建立局部分片映射，历史P6仅补形状先验。对没有当前支持的区域报告模型区间和转移资格，不能将其列为已测覆盖。

拟合周期Hue×SAT的五通道命令模型，保证0/360连续；SAT0只保留一个颜色目标，Hue不定义。饱和度压缩策略保持Hue优先和单调，明确返回请求SAT、实际等效SAT、clipped及不确定度。

### C4：独立体验留出

至少六个非主Hue点，覆盖六个60°扇区；另有0/360附近、一个高曲率区和至少两个固定低SAT点（如S10/S20），合计至少十个独立目标。低SAT点检验使用体验而不是开启无限下探搜索。

验证实际命令模型、Hue连续性、SAT单调性和等效菜单SAT误差，不要求相邻Ray SAT产生完全相等的欧氏色差；“复制Ray的SAT体验”不等于重新定义人眼线性饱和度。

最多一次局部模型修正和新的留出。失败范围单独标记，不能仅因某个孤立高SAT点通过就输出整Hue覆盖百分比。

### C5：INT可分离性

INT100路线在产品层有稳定分类、模型和留出后，进入INT100/50/20/5；不要求所有58维strict通过。用至少四个分层代表目标（SAT0、中SAT、两个极端Hue）检查按尺度调光是否保持颜色。每个降档实际测Ray与strip，不把较低PWM直接假定为颜色不变。

若可分离，保留二维色彩模型加一维强度策略；若不可分离，只对检测到的分组建立有限的强度修正和独立验证，不默认扩张成任意精细三维LUT。低INT单曝光不可观测时，报告最低可验证INT与运行限制，不改required-feature门掩盖。

### C6：最终覆盖图与采用决定

每Hue输出有效区间、best-tested、经验upper请求、主色度误差/95%区间/预测区间、旧58维误差、是否多解、当前映射资格、INT适用范围、停止原因。

未测Hue写未测，不写0%；无合格反解写不可形成等效SAT，不写数字0；无物理证明不写硬件极限。允许用户采用稳定最佳近似，但必须看见实际误差而不是一个空的complete标签。

## 6. 干扰来源登记与最小解决路径

| 问题 | 本轮分类 | 本轮/下轮解决方式 |
|---|---|---|
| 既有依赖缺失 | 已解决 | 使用已补齐文件；不再补包 |
| W7连续插值未测 | 可实验解决 | W3真实命令+新留出 |
| LONG未执行 | 可实验解决 | W4真实协议+差中之差 |
| 白光候选是否仍有改进 | 可实验解决 | W1/W2门一致方向+有限新命令 |
| 逐点循环/会话波动 | 可实验解决 | N1分层重复，必要风险追加 |
| 四个未测主Hue | 可实验解决 | C1八节点 |

| 材料 vs 空间光场成因 | 非主目标，可有界诊断 | 如影响采用，固定5600/100，以色卡原位和180°旋转、两源各两次重复，共8张；追踪同材料换位置。只作诊断，不重定义整个观察者 |
| 过去未记录的真实温度 | 历史不可追溯 | 明确组合分量；未来记录现有可用温度，不伪造过去 |
| 纯相机与快速LED/PWM份额 | 现有装置未必可辨识 | burst只给组合短时噪声；无独立稳定参考时不强行分摊 |
| 标准人眼、光谱和所有材质匹配 | 本项目范围外 | 不租光谱仪、不制造绝对准确性结论 |

## 7. 停止与Advisor节奏

每个阶段必须产生颜色点、可辨识误差分量、映射/留出或有限负结果之一。普通实现修正不消耗科学命令预算，也不触发新的架构边界；设备采集的命令/照片预算照实计算。

按本指南预定义的通过、最佳近似、操作受限、映射失效和预算耗尽继续推进，白光和彩光互不阻塞。只在更换观察者/质量门、突破人为时间约束、出现共同控制点持续物理异常或真正新增科学假设时回Advisor。不能在每个已预定义negative后再次等待Advisor。

最终允许的表述是“在已测试协议、尺度、邻域和预算下的稳定最佳近似/经验可达范围”。**没有全局证据，不把‘再搜不划算’写成‘灯带物理上再也做不到’。**
