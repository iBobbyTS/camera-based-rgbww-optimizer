## 0. 研究结论摘要

### 0.1 R5 是有效的硬失败，不是低信号重演

`FORMAL-R5` 的工程证据、返回 CR3、sidecar、physical-return ledger、双 cleanup 和 Terminal seal 均完整；失败发生在第 12 个返回 capture：

```text
capture_id = 011-ray-c-t60
state = Ray H300/S100/INT100
recorded exposure = 0.00048828125 s
nominal shutter = 1/2000
failure = required white-patch G1/G2 clipping
```

两个非零 clipped fraction 分别约为 `0.0798%` 和 `0.0599%`。因此本轮准确分类是：

```text
state_specific_exposure_policy_failure
causing_required_feature_observer_saturation
```

它同时意味着该 capture 的 measurement quality 无效，但**不意味着**：

- Ray 状态 C 本身异常；
- Ray 或相机发生 reference epoch shift；
- 灯带不可达；
- P6 流形失效；
- 600 秒协议需要改变；
- 旧 F0B-R1 的低信号问题再次发生。

### 0.2 不改变 observer、required feature 或零裁剪门槛

本轮决定保持：

```text
58-feature set = unchanged
block_06/white:G1/G2 = required
maximum clipped fraction = 0.0
near-noise / valid-pixel gates = unchanged
identity RAW response = unchanged
covariance / joint coverage = unchanged
no-ambient statistic = unchanged
```

EMVA 1288 的一般原则允许把“足够小、不会偏置均值和方差”的 clipping 作为饱和定义的一部分；但本项目没有预先验证 `0.08%` clipping 对 58-feature、local inverse 和 joint gate 是否无偏。现在看到失败后再把阈值改成 `0.1%` 会形成典型的 data-dependent relaxation。因此不在 R5 分支中修改 threshold。

最小且更干净的修复是：保留观察者，降低 **state C 的固定曝光时间**。

### 0.3 旧 11 帧只可作 diagnostic，不可参与 TD-B formal inference

R5 的前 11 帧对应完整序列的前半段：

```text
000 A0@600
001..004 D@60/120/300/600
005 A_after_D@600
006..009 B@60/120/300/600
010 A_after_B@600
```

这些帧各自通过了当时冻结的 capture-quality gate，因而仍可用于：

- exposure adequacy 的描述性证据；
- chronology/command/readback forensic；
- 下一轮 shutter 和预算设计；
- 验证 R5 fail-closed 与 evidence retention 是否工作。

但它们不得用于：

- 拼接新会话的 C 帧；
- 宣布 D/B 或 return-to-A formal pass；
- 估计最终 TD-B center、covariance 或 history effect；
- 冻结 operating envelope；
- 解锁 strip、TD-C、reference classification 或 sentinel。

`FORMAL-R5` 永久保持：

```text
formal_pass = false
classification = accepted_hard_failed_formal_attempt
```

### 0.4 采用 targeted exposure qualification，但正式 repeat 必须是完整新 16 帧

决定为：

```text
repeat_policy = full_new_formal_run
precondition = targeted_state_C_exposure_qualification
old_new_frame_combination = prohibited
```

只补拍 C 或 C+A 的 targeted formal repeat 不足，因为 TD-B 是顺序与 history 敏感的设计。C 在原设计中出现在：

```text
A0 -> D -> A -> B -> A -> C -> A
```

跨会话补拍 C 无法恢复原 run 的 session time、previous-state history、Ray 热状态和相机/环境 chronology。NIST 的顺序比较研究也强调：时间顺序、规则间隔和一致的 thermal handling 是比较设计成立的前提；不完整设计和不同热处理不能通过事后拼接获得同等推断。

因此新正式 Ray run 必须从 `000` 到 `015` 全部重做。

### 0.5 state C 曝光资格测试采用有界两档方案

只改变 state C 的 state-specific fixed shutter。A、D、B 使用 R5 manifest 中已经通过 11 帧质量门的原冻结 shutter；不得重新自动曝光或静默改变。

C 的候选 nominal shutter：

```text
candidate 1 = 1/2500
candidate 2 = 1/3200
```

MakerNote `Canon:ExposureTime` 仍是实际曝光权威。`1/2500` 大约是失败曝光的 `0.8x`，是首先测试的最小修正；`1/3200` 是 clipping 仍存在时的唯一预授权 fallback。

每个候选均执行：

```text
A precondition for 600 s
A -> C
C captures at 60 / 120 / 300 / 600 s
```

选择第一个 `4/4` 通过原冻结质量门的候选。最多 8 张 setup CR3：

```text
2 candidates × 4 slots = 8
```

若 `1/2500` 出现低信号、非有限、有效像素不足等非 clipping 失败，不再尝试更快曝光，因为 `1/3200` 只会降低信号；直接进入：

```text
exposure_window_unresolved
```

若 `1/2500` 仅 clipping，则允许测试 `1/3200`。若 `1/3200` 仍有任何 required-feature failure，同样停止，不继续自动追到 `1/4000` 或更快。

### 0.6 600 秒仍是固定时间 transient，不是 steady-state

Human/Developer 的决定继续有效：

```text
developer_selected_operational_dwell_s = 600
operational_dwell_claim = selected_time_limit_not_proven_steady
```

R5 clipping 是相机曝光问题，不是源输出 settling 结论，因此不改变 dwell。后续 P7 若继续，只能声明匹配：

```text
operational_600s_transient
```

而不能声明：

```text
steady
settled_at_600
t_formal = 600
TD-A pass
```

固定时间 transient 可以成为合法产品 measurand，前提是准确规定 elapsed time、previous-state contract 和可重复性。TD-B 的核心问题因此变为：在 600 秒时，return-to-A 是否兼容、固定时间点是否可重复，而不是把 60→600 的 trend 强行写成零。

### 0.7 后续解锁路线

```text
state-C exposure qualification
-> full new Ray 16-frame formal run
-> Ray operational-history analysis
-> conditional new strip 16-frame run
-> combined TD-B operational-600 analysis
-> conditional TD-C core
-> Advisor review
```

只有完整新 Ray run 通过 capture quality、ledger、cleanup 和 return-anchor gate，才允许进入新 strip run。R5 attempt 的 strip 永久保持 `0`。

TD-C core 仅在 Ray 与 strip 的新 TD-B run 均完整通过且 `A@600` history-compatible 后条件解锁。reference epoch classification、四点 sentinel、remaining 9、boundary、holdout、Gate-6 和 P8 在 TD-C 前继续锁定。

## 2. FORMAL-R5 证明了什么

## 2.1 工程与治理链已正确 hard-stop

R5 的价值包括：

- Human visible-Terminal launch 只消耗一次；
- retry 为 0；
- 前 11 帧 accepted ledger 与第 12 帧 returned-but-rejected ledger 分开；
- rejected CR3/sidecar/remote IDs 没有丢失；
- failure 发生后没有进入 strip、paired 或 public analyzer；
- Python/shell cleanup 和 terminal seal 成功；
- 没有通过删除 feature、放宽 threshold 或 post-hoc analyzer 继续。

这说明 fail-closed 架构按预期工作。R5 不需要因失败而删除，其 run root 应永久保留为验证工程合同的正例。

## 2.2 失败属于 measurement procedure，不属于目标状态本身

`block_06/white:G1/G2` 的非零 clipping 表明该 capture 已超出当前 required-feature 的可用 RAW 域。由于 `H300/S100` 只在当前 shutter 下失败，最直接的归因是：

```text
legacy state-C shutter did not provide sufficient saturation headroom
```

目前没有证据支持：

- 相机整体 white level 配置错误；
- 所有 Ray state 均过曝；
- exposure metadata 不可信；
- feature mask 错误；
- `block_06/white` 应从观察者删除。

A/D/B 的 11 张 accepted capture 反而说明现有 state-specific exposure 架构本身可以保留，只需重建 C 条目。

## 2.3 R5 没有产生完整 TD-B 科学数据集

计划需要 16 个 Ray formal。失败发生在 `011`，缺少：

```text
011 C@60 valid observation
012 C@120
013 C@300
014 C@600
015 A_after_C@600
```

因此无法完整回答：

- C 的 60→600 chronology；
- C 是否在 600 秒可合法观测；
- C 后返回 A 是否存在 history effect；
- 四个 A anchor 是否共同兼容；
- complete sequence 下的 order/chronology effect。

R5 的 11 个 accepted frame 是“局部有效观测”，不是“11/16 的部分通过策略”。

## 3. 为什么不放宽 clipping threshold

## 3.1 外部标准给出的边界

EMVA 1288 把 camera saturation 与可用线性范围分开，并指出 clipping 必须足够小，不能使均值和方差产生偏置；它没有要求所有应用都必须使用严格 `0.0` clipped fraction。同时，EMVA 也要求 linear model 只用于满足线性假设的 RAW channel，并建议多通道分别评价。

这给出两个结论：

1. `0.0` 是本项目的保守合同，而非普适物理常数；
2. 若想改成非零阈值，必须先通过独立实验证明 feature statistics、local inverse 和 acceptance decision 不被偏置。

## 3.2 为什么本轮仍保持 `0.0`

改变 threshold 的最低证据要求至少包括：

- 多个 clipped fraction 档位；
- 与无 clipping 保护曝光的 paired comparison；
- 58-feature 的 bias 与 variance；
- Hue/SAT/shape inverse 的偏差；
- 不同 Hue/SAT、patch 和 CFA plane；
- 独立 holdout；
- 预先冻结的 acceptance rule。

R5 只有一个失败状态、一个 clipping 水平和两个 plane。以此把 threshold 改为 `0.001` 会直接围绕失败数据定规则，不符合本项目此前的 guard-band 原则。

此外，当前存在简单替代方案：降低 state C 曝光。因此没有科学理由承担 observer-v3 重建成本。

## 3.3 未来可单独研究，但不属于本分支

未来若设备时间成为主要瓶颈，可以另开：

```text
observer_clipping_tolerance_validation_v1
```

研究稳健 median/trimmed mean 对极小 clipping 的容忍度。但该分支必须与 R6 独立，不得追溯性地把 R5 改成 pass。

## 4. 为什么 state-specific exposure 是合法修复

## 4.1 项目匹配的是 scale-removed RAW 颜色方向

P7 不匹配绝对亮度。测量先做 exposure normalization，再构造 scale-removed native-Bayer feature。在线性 RAW 区间内：

\[
y \propto E\,t_{exp}
\]

改变 shutter 只改变信号尺度，不应改变归一化颜色方向。ISO 17321-1 也把 RAW 数据作为数字相机颜色表征的基础；EMVA 1288 的线性模型明确把 pixel exposure 视为 irradiance 对 exposure time 的积分。

因此不同 HSI state 使用不同固定 shutter 是可接受的，前提是：

- ISO、aperture、camera processing 和 observer 保持固定；
- 每个 state 的 shutter 在 formal run 前冻结；
- MakerNote actual exposure 用于归一化；
- 所有 required feature 同时远离 clipping 与 noise-floor failure；
- formal run 内不自动改变曝光；
- 新 state C baseline 通过 P1 identity-response/quality 合同。

## 4.2 为什么只改 C

A/D/B 的 11 个 formal frame 已实际通过当前 quality gate。把所有 state 重新 auto-expose 会扩大变更范围并引入新的低信号风险。最小变更原则要求：

```text
A / D / B shutter = exact R5 frozen values
C shutter = successor state-specific value from qualification
```

这也让 R6 与 R5 的差异可追踪，避免同时改变多个输入量后无法归因。

## 4.3 为什么 formal run 不能 weak-reacquire

曝光 qualification 的目标是提前找到一条可用 exposure window。正式 16 帧运行中若遇到质量失败，再自动改变 shutter 会：

- 改变预冻结 measurement procedure；
- 使同 state 不同 time slot 使用不同 exposure policy；
- 产生 data-dependent retry；
- 破坏 exact physical budget 和 lineage。

因此 R6 formal 必须 fixed shutter、retry 0、首次 failure 即停止。

## 5. 旧 11 帧的精确用途

## 5.1 允许用途

可以生成只读 derived artifact，例如：

```text
r5-partial-diagnostic-analysis-v1.json
```

允许内容：

- capture ID 与 planned slot mapping；
- actual exposure、quality margin 和 feature availability；
- A0、A_after_D、A_after_B 的描述性差值；
- D/B 60/120/300/600 chronology 图；
- command/readback/source-isolation 检查；
- R6 shutter 和时间预算建议；
- 与 R6 完成后并列展示，但不 pooling。

## 5.2 禁止用途

```text
no threshold estimation
no covariance update
no uncertainty inflation
no P6 transfer fitting
no formal p-value/pass decision
no old/new frame pooling
no imputation of missing C/A-after-C
no TD-B acceptance
```

## 5.3 为什么不能“11 帧 + 新 5 帧”

TD-B 设计不是 16 个互相独立的静态样本，而是一个有顺序的 thermal/history sequence。新会话中的 C 和 A_after_C 具有不同：

- session elapsed；
- preceding source history；
- ambient/geometry epoch；
- Ray housing state；
- camera state；
- exposure policy；
- Terminal/process lineage。

把它们与 R5 拼接，会把缺失数据问题伪装成完整设计。NIST 的 drift-eliminating design 说明：只有满足预定顺序、近似规则时间间隔和一致处理，才可解释顺序比较；不同 thermal handling 会产生不共同 drift。

## 6. Repeat policy 的三个候选

| 候选 | 优点 | 主要问题 | 决定 |
| --- | --- | --- | --- |
| `no_repeat` | 不再消耗设备时间 | 一个可修复的 exposure failure 会永久阻断 P7 | 拒绝 |
| `targeted_repeat` | 最少拍摄 C/A-after-C | 无法恢复 R5 的完整 history/session；需拼接旧数据 | 拒绝 formal 用途 |
| `full_new_formal_run` | 单一 session、完整顺序、统一 successor contract | 重拍 16 帧，时间成本较高 | 批准 |

允许 targeted 的只有**曝光资格测试**，不是 targeted formal completion。

## 7. state C exposure qualification 设计依据

## 7.1 候选曝光

失败 actual exposure 为：

\[
t_{fail}=0.00048828125\;s \approx 1/2048
\]

第一候选 nominal `1/2500` 对应约 `0.8 × t_fail`；如果 clipping 是轻微 headroom 缺口，这通常应足以移回线性域。第二候选 `1/3200` 提供更大余量。

本轮不批准更快候选，原因是：

- 更快曝光提高 required feature 低信号风险；
- P4/P7 已多次证明 observer 的 noise-floor failure 同样是硬失败；
- 若 `1/3200` 仍无法同时避免 clipping 和低信号，问题已不是简单一档 shutter 修复，应回 Advisor。

## 7.2 为什么测四个 time slot

Ray 到 600 秒仍未证明 settled，且状态输出可能随时间变化。只在 t60 测一次不能保证 t120/t300/t600 仍有 headroom；只在 t600 测一次也不能覆盖早期 transient 峰值。

因此资格测试复用正式 C 的四个时间点：

```text
60 / 120 / 300 / 600
```

这不是重新做 TD-A，也不用于科学 settling inference；它只回答“这一 fixed shutter 在 formal C 时间窗内是否始终可观测”。

## 7.3 immediate previous-state contract

每个候选前使用：

```text
A = H120/S100/INT100 for 600 s
then A -> C
```

该条件复现正式 C 的 immediate previous state。它不能完全复现原 R5 的更早 D/B history，因此只作为 exposure qualification，不作为 TD-B scientific data。

## 7.4 资格结果状态

```text
qualified_1_2500
qualified_1_3200
exposure_window_unresolved_clipping
exposure_window_unresolved_low_signal
exposure_window_unresolved_other_quality
run_invalid
```

只有前两项允许生成新的 formal exposure policy artifact。

## 8. 为什么完整新 run 需要新 checkpoint 与 lineage

JCGM GUM-6 要求 measurement model 在其已开发并验证的输入范围内使用；measurement procedure 发生改变时，应通过实验验证其 adequacy。R6 将改变 state C 的 exposure baseline，并新增 qualification artifact。即便 observer 数学公式不变，measurement procedure 和 frozen input hash 已改变。

因此必须新增：

```text
new code/config checkpoint
new state-specific exposure-policy artifact
new successor lineage release
new public validator binding
fresh predevice / E2 gate
new visible-Terminal authorization
```

旧 R2 release 与 R5 root 保留为历史 evidence，不修改、不重新消费、不改写为 successor pass。

## 9. 600 秒 operational transient 的科学语义

## 9.1 Human 决定改变的是产品 measurand，不是 TD-A 事实

TD-A 已证明：

```text
settling_not_demonstrated_by_600
```

Human 选择停止追求 900/1200 秒，并把 600 秒作为产品时间上限。合理的后续定义是：

> 复制两个 source 在明确 previous-state 与 elapsed-time 合同下的 600 秒 transient output。

它不是 steady-state 的近似名称，而是一个不同 measurand。

## 9.2 后续 TD-B 的 hard gate

在 operational-600 路线中，60/120/300/600 chronology 仍要完整报告，但早期 trend 不再通过扩大 covariance 或伪装成 settled。真正的产品 hard gate是：

1. 每个 required capture quality 合法；
2. `A0`、`A_after_D`、`A_after_B`、`A_after_C` 在 600 秒处兼容；
3. exact elapsed、previous-state 和 source isolation 合同成立；
4. 同一 source 的 600 秒结果没有不可解释的 history split；
5. `steady_status=not_demonstrated` 明确保留。

若 A return anchors 分裂：

```text
history_dependent_at_operational_600
```

此时单一静态 LUT 的 measurand 仍未定义，不能进入 TD-C。

## 9.3 R5 clipping 与 dwell 无关

clipping 发生在相机端，降低 shutter 不改变 Ray 的光输出或产品等待时间。因此：

```text
operational_dwell_s remains 600
```

无需重新讨论 900/1200，也不产生新的 transient controller。

### 10.1 Ray full run acquisition/quality failure

## 15. 最终研究判断

R5 的失败并不要求重建 observer，也不要求废弃 TD-B。它准确暴露了一个局部、可修复、但不能被统计容差吸收的 measurement-procedure 问题：state C 的 legacy shutter 缺少饱和余量。

最可靠的路线不是放宽 `0.0` clipping，也不是把旧 11 帧与新 5 帧拼接，而是：

1. 保留 R5 为永久 hard-failed evidence；
2. 用两档、有界、四 time-slot 的 C exposure qualification 找到合法窗口；
3. 生成新 checkpoint、exposure-policy artifact 和 successor lineage；
4. 从 `000` 开始完整重跑 Ray 16 帧；
5. 只有 Ray 质量与 600 秒 return-anchor history 均通过，才运行新 strip 16 帧；
6. 仅在完整 TD-B operational-600 gate 通过后进入 TD-C；
7. 全程保留“600 秒是选定 transient、不是 steady”的事实。
