# 白点测量与 WW/CW 端点实验审计

## 1. 测量定义

项目不把相机 RGB 直接当作 Ray 标称 CCT。当前流程是：

1. 同一场景、同一色卡位置先拍 Ray；
2. 关闭 Ray 后拍灯带；
3. 从线性 RAW 白块得到 camera-neutral RGB；
4. 用相机矩阵近似反算 XYZ、`xy`、`uv1960`；
5. 在 Planckian locus 上求近似 CCT 与 Duv；
6. 比较同轮 Ray 与灯带，而不是要求估算值等于 Ray 命令数字。

这套 `white_patch_rawpy_matrix_inverse_planckian_locus` 方法适合做闭环相对误差和搜索启发，不等同于 Lightroom 的 RAW 温度/色调滑块，也不是光谱仪测量。例如 Ray 命令 `14000K` 在最终相机测量里约为 `9631K`。

## 2. 最初的端点方向

最初设想是先拍纯 WW/CW，再从 Ray `1800K` 和 `20000K` 两端做固定边界或二分搜索。2026-07-09 早期日志显示：

- WW 旧结果：Ray `2369K/GM100`
- CW 旧结果：Ray `6066K/GM172`

但事后直接比较白块发现对应相机 CCT 误差分别约 `451K` 和 `758K`；这些设置只是旧搜索控制量收敛，不是相机观测意义上的端点匹配，已经淘汰。

用户提出并最终采用的改进是：从灯带估算的 CCT 开始，根据 Ray 实拍误差反推下一 CCT；收集多个样本后使用反插值/近似 secant；完成一轮 GM 后再回到 CCT，共做三轮 CCT/GM 交替，以处理两轴耦合。后续还允许从前一次 Ray 设置作为起点。

## 4. 最终端点结果

用户确认 `20260709-023258` 是当时能做到的最佳环境。正式结果已整理为 `config/white/white-endpoints.json`。

| 端点 | 灯带白块估算 | 最终 Ray 设置 | Ray 白块估算 | CCT 误差 | Duv 误差 |
| --- | --- | --- | --- | ---: | ---: |
| WW | `2898.91K / -0.006345` | `2931K / GM176` | `2904.52K / 0.002044` | `+5.61K` | `+0.008389` |
| CW | `5552.56K / 0.000822` | `7702K / GM160` | `5548.46K / 0.006314` | `-4.10K` | `+0.005491` |

这里的 `2931..7702K` 是 **Ray 命令范围**，不是相机估算的 WW/CW 物理 CCT。后续 RGB 惩罚以该 Ray 命令范围为坐标：范围内优先白通道，低于 WW 端释放红，高于 CW 端释放蓝；GM 偏离端点原生值时再方向性释放 R/B 或 G。

最终端点运行保留 10 张 CR3、完整搜索 JSON、摘要和校验清单。历史总结称整理时约 `863M`。该 run 当时还保留 `.npy`；后来正式 LUT 流程改为统计后删除 `.npy`，两者保存策略不同。

## 5. Ray 低色温 GM 色域限制

在 `2300K` 附近，Ray 对 GM130 和 GM200 的相机实测输出非常接近，即使 OpenAPI readback 正确报告不同 GM。后续两个点曾使用同一灯带命令也都通过。这更符合 Ray 低 CCT 色域/内部算法限制，而不是控制命令失效。

因此：

- GM 数字不是所有 CCT 下都对应等距的可见色度变化；
- 低温端不能用 GM 命令差直接判断灯带应有多大差异；
- 搜索和验收必须继续依据 Ray 实拍白点。

## 6. 手工 RAW 交叉检查推翻旧“成功”

用户在 `/Volumes/4T/temp/rgbww-optimizer/cr3` 手工拍摄 Ray (`r`) 和灯带 (`s`) 的 1800K、GM0/100/200。白块比较得到：

| GM | 灯带减 Ray CCT | 灯带减 Ray Duv | `uv1960` 距离 |
| ---: | ---: | ---: | ---: |
| 0 | `+30.76K` | `+0.006394` | `0.006846` |
| 100 | `+12.02K` | `+0.010868` | `0.010911` |
| 200 | `+29.67K` | `+0.007231` | `0.007612` |

多块中性灰的偏差方向一致，白块也未剪切，说明肉眼看到的 1800K 偏差不是单一色块误检。这直接促成了更严格 Duv 阈值、独立复测和光源隔离检查。

## 7. 重复性和热稳定性

六个代表目标、两种光源、每种五次 power-cycle 的重复性测量得到：

- 最差合并 Duv sigma：`4.95e-5`，3 sigma：`1.48e-4`
- 最差合并 CCT sigma：`40.28K`，3 sigma：`120.84K`（高 CCT）

因此公共验收目标定为：

- `abs(Duv error) < 0.0005`
- CCT 至少容许 `25K`
- 高 CCT 时按相机实测 Ray 白点的 `1 mired` 换算 Kelvin 容差

单点重新优化则使用一半阈值：Duv `0.00025`、CCT `12.5K` 或 `0.5 mired`，给跨次漂移留余量。

同一灯带命令的热稳定性试验显示持续漂移：

| 约等待时间 | CCT | Duv |
| ---: | ---: | ---: |
| 2s | `9708.53K` | `-0.003502` |
| 15s | `9746.14K` | `-0.003360` |
| 30s | `9779.13K` | `-0.003245` |
| 60s | `9825.03K` | `-0.003068` |
| 120s | `9867.37K` | `-0.002932` |

60 到 120 秒仍变化约 `42K / 0.000136 Duv`。这说明 2 秒 settle 只适合快速探针，不能作为最终可复现验收；最终确认改为每次先全关一秒、重上同一命令并等待 60 秒。
