### 0.1 总体判断

项目可以继续，P0-R 至 P6 **不需要整体返工**。本轮报告能够支持以下判断：

### 0.2 必须返工或补齐的范围

6. 把 `faithful`、`s_exact_max` 和 gamut 状态限定为 `INT=100 + full-scale policy + frozen observer`，不得直接写成物理色域。

```text

→ 4-point sentinel
```

## 2. D1：P7 不确定性与 hard gate

### 2.1 决定

```text
decision = approve_alternative_with_formula
```

Planner 提出的“两层不确定性”方向正确，但必须按下述方式修正：

- Ray、strip 和模型误差先在冻结的 scale-removed 58-feature 空间组合；
- 不把“camera noise”作为第三个独立标量再次相加，因为它已经包含在 Ray/strip 实测重复性中；
- 不直接把 P1 的 white feature CV 换算成 Hue 度数；
- 不只对 Hue/SAT/shape 分别使用三个边际 3σ；必须校准三项同时通过时的**联合覆盖率**；
- 非线性、周期 Hue、SAT0 和非负 shape residual 优先使用 Monte Carlo 传播，而不是只依赖一阶 Jacobian；
- 三张 confirmation 不用于估计新 3σ，也不用于事后扩大 tolerance。

### 2.2 测量量与符号

对目标 $\theta=(h,s)$，定义：

- `f_R(theta)`：P6 Ray 目标的 scale-removed 58-feature 向量；
- `f_S(u)`：灯带命令 `u` 的同构 feature 向量；
- `g(f; M)`：冻结 Ray manifold `M` 上的 local inverse/projection；
- `delta_h`：圆周最短 Hue 差；
- `delta_s`：Ray-equivalent SAT 差；
- `r_perp`：相对于 manifold 的 orthogonal shape residual，非负。

SAT0 时：

```text
hue_defined = false
```

不得生成伪造的 `0°` Hue 误差，也不得把 Hue 计入 objective、hard gate 或 summary。

### 2.3 三类不确定性

#### A. Ray target/repeatability

记为：

\[
\Sigma_R(h,s)
\]

来源优先级：

1. 同一 P6 目标的直接 repeats；
2. 相同 SAT、相邻周期 Hue 的局部 pooled repeats；
3. P6 全局保守 repeatability floor。

使用哪一级必须写入每个目标条目，不能只保存一个无来源的最终数字。

#### B. Strip 预冻结噪声下限

记为：

\[
\Sigma_{S,0}
\]

来源是 P1 同几何、同 observer、同曝光包络的 scale-removed strip repeatability。它只能作为**预冻结下限**，不能证明高饱和状态的局部重复性已经被完整覆盖。

58 维 feature 而 repeats 数量较小时，不允许直接使用未经正则化的满秩 sample covariance。允许：

- diagonal covariance；
- 按 patch/CFA 预声明的小 block covariance；
- 有明确参数和版本的 shrinkage covariance。

所选方法必须固定并记录，不能按目标临时切换。

#### C. Target-model uncertainty

记为：

\[
\Sigma_M(h,s)
\]

包括：

- P6 target estimate 的有限样本误差；
- manifold 插值/投影误差；
- inverse 的离散化与局部曲率误差。

13 点 pilot 全部位于 P6 实测节点时，插值项可以很小或为零，但 artifact 中仍必须显式存在该字段并说明理由。进入随机非节点 holdout 前，必须用 P6 leave-one-node-out 或等价方法给出非零 interpolation floor。

### 2.4 组合公式

若 Ray 与 strip 的独立采集没有可证明的交叉协方差，则使用：

\[
\Sigma_{\Delta f}(h,s)
=
\Sigma_R(h,s)
+
\Sigma_{S,0}
+
\Sigma_M(h,s)
\]

这等价于在独立项上做 quadrature，但组合发生在 feature covariance 层，而不是把三个“3σ 数字”简单相加。

如果已有 ABBA/配对数据足以估计共享漂移协方差，可使用：

\[
\Sigma_{\Delta f}
=
\Sigma_R+
\Sigma_S-
\Sigma_{RS}-
\Sigma_{SR}+
\Sigma_M
\]

但不得在缺少配对证据时假定有利的正相关来缩小 gate。默认忽略交叉项是较保守的选择。

### 2.5 传播方法

#### 默认：Monte Carlo through the exact evaluator

对每个目标：

1. 从 Ray、strip floor、model 三个冻结分布采样；
2. 合成一个“真实底层颜色相同、只有测量与模型扰动”的 null pair；
3. 调用与正式 analyzer 相同的 `g(f; M)` 和 `evaluate_hsi_observation()`；
4. 记录 `abs(delta_h)`、`abs(delta_s)`、`r_perp`；
5. 使用圆周 Hue 算法；
6. SAT0 不生成 Hue 样本；
7. 对 `r_perp` 使用单侧分位数，不把它错误地当成以零为中心的高斯量。

允许先用局部 Jacobian 得到快速估计：

\[
\Sigma_z \approx J_g\Sigma_{\Delta f}J_g^T
\]

但在以下任一情况必须用 Monte Carlo 作为最终值：

- SAT0 或低 SAT；
- 0/360 周期附近；
- 高曲率区域；
- inverse 条件数差；
- shape residual 接近非负边界；
- Jacobian 与 Monte Carlo 的 coverage endpoint 差异超过预声明数值容差。

### 2.6 联合 99.73% coverage，而不是三个独立 99.73%

三个边际 gate 各自取 99.73% 并不等于三项同时通过仍具有 99.73% coverage。执行模型必须通过 Monte Carlo 校准联合区域。

推荐实现：

1. 从 null samples 得到各轴尺度 `sigma_h/sigma_s/sigma_shape`；
2. 对每个 sample 计算：

\[
q=
\max\left(
\frac{|\Delta h|}{\sigma_h},
\frac{|\Delta s|}{\sigma_s},
\frac{r_\perp}{\sigma_\perp}
\right)
\]

3. 取 `q` 的 99.73% 分位数 `k_joint`；
4. 冻结：

\[
T_h=k_{joint}\sigma_h,
\quad
T_s=k_{joint}\sigma_s,
\quad
T_\perp=k_{joint}\sigma_\perp
\]

SAT0 只用 SAT 与 shape 两项重新校准联合区域。

artifact 中统一使用：

```text
coverage_probability = 0.9973
```

只有在分布近似高斯且使用标准差表述时，报告中才可附注“约等于 3σ”。

### 2.7 `faithful` 的本轮定义

本轮允许保留 `faithful` 字段，但必须同时写明：

```text
faithful_scope = camera_observer / INT100 / full_scale_policy / frozen_geometry
```

`faithful=true` 必须同时满足：

1. 当前 P7 run 的 Ray reference anchors 有效；
2. measurement quality 合同全部通过；
3. Hue/SAT/shape 的冻结联合 gate 通过；
4. 至少三次独立 settled confirmation 全部通过；
5. 三次 confirmation 之间没有明显超出冻结 floor 的 gross spread；
6. uncertainty artifact 未在本次 run 内更改；
7. solver、measurement 和 reference drift 均未处于 unresolved 状态；
8. full-scale 产品约束被满足。

该 `faithful` 不是人眼 JND、通用色度或光谱一致性的声明。

### 2.8 局部重复性复核

三张 confirmation 不能可靠地重新估计 3σ，因此其作用是：

- 验证命令从全关重启后能重复通过；
- 发现 gross underestimation；
- 不用于重新计算或放宽 tolerance。

若出现以下任一情况：

- 任一合法 confirmation 超出冻结 gate；
- 三张之间的最大 pairwise difference 超过冻结 pairwise envelope；
- local inverse 在三张之间跳到不同 branch；
- 某一张需要改变 observer threshold 才可测；

则标记：

```text
uncertainty_unresolved
```

不能在原 run 内扩大门槛并宣布通过。

### 2.9 confirmation 数量

```text
sentinel / ordinary pilot point: 3 independent off/on 60 s captures
boundary endpoint / Gate-6 freeze / near-limit point: 5 independent off/on 60 s captures
```

“near-limit”定义为任一观测指标达到对应 frozen gate 的 80% 以上，或该点是 `s_exact_max` bracket endpoint。

失败确认后允许 thermal rebase，但新候选必须重新开始完整 3/5 张 confirmation；不得把旧候选和新候选的 confirmation 混合。

## 3. P7 reference-anchor gate

### 3.1 原因

P6 manifold 是冻结目标，但 P7 是后续会话。P6 的同轮 repeatability 不能自动排除：

- Ray 输出跨会话漂移；
- 相机/镜头/色卡几何变化；
- exposure 或 RAW decoder 状态变化；
- 新点位文件使用错误；
- 固件/风扇/功率模式变化。

只依赖 P6 hash 而不做当前会话 anchor，会把系统漂移误判成灯带误差。

### 3.2 最小 anchor 方案

在 4 点 sentinel 前：

```text
Ray H0/S0/INT100
Ray H120/S100/INT100
Ray H300/S100/INT100
```

在 sentinel 后：

```text
Ray H120/S100/INT100
```

要求：

- 使用与 P6 相同 observer、location、曝光包络、风扇/功率模式和 source isolation；
- 只用于 health check，不加入灯带优化样本；
- 与 P6 target 的差异必须处于冻结 Ray anchor coverage 内；
- H0/S0 只检查 pooled color direction 和单独报告的 brightness scale；
- 任一 anchor 超界时停止，标记 `reference_drift`，不在同一 run 内重拟合 manifold。

## 5. D3：`faithful`、`unconfirmed` 与 gamut 语义

### 5.1 关键纠偏：full-scale 不是纯数学归一化

P2 已发现通道响应档位依赖，P3 已发现混合非加法。因而：

```text
at_least_one_channel == 4095
```

会改变实际工作点、总负载和热状态，不再只是消除全局 scale 的数学 gauge。

本轮允许继续使用该约束，因为它定义了 `INT=100` 的产品工作策略；但所有可达性结论必须限定为：

```text
frozen observer + INT100 + full-scale policy + current settle protocol
```

### 5.2 冻结术语

#### `faithful`

满足第 2.7 节全部条件；必须带 `faithful_scope`。

#### `unconfirmed`

当前预算、初值、局部模型或样本不足以证明 faithful。它不表示物理不可达，也不表示 gamut 边界。

#### `measurement_unreachable`

冻结 observer/exposure/feature 合同下无法得到合法 observation。它只描述测量链，不描述灯带色域。

#### `reference_drift`

当前会话 Ray anchor 与冻结 P6 target 不一致，P7 结果失去可比性。

#### `uncertainty_unresolved`

局部重复性、inverse ambiguity 或模型误差超过预冻结 uncertainty；不能通过现场扩大 gate 解决。

#### `solver_budget_exhausted`

测量合法，但在冻结轮数、step、probe 和 rebase 预算内没有证明 faithful。

#### `boundary_bracketed_at_full_scale`

在同一 Hue、同一 observer、同一 full-scale policy 下，已有 faithful SAT 下界和稳定 non-faithful SAT 上界。

#### `s_exact_max_int100_fullscale(h)`

在本轮冻结合同下，经定向搜索验证的最大 Ray-equivalent SAT。P8 前不得简写成与 INT 无关的 `s_exact_max(h)`。

#### `gamut_compressed_int100_fullscale`

请求 SAT 超过 `s_exact_max_int100_fullscale(h)`，INT100 原型按已冻结策略回退到边界。

#### `empirically_unreachable_under_frozen_contract`

仅在完成 scale-relaxed、多起点、合法测量和重复确认后才允许使用。仍不得写成数学或光谱意义的“物理不可达”。

### 5.3 Hue identifiability

不得使用“在足够低 SAT 仍不能保持 Hue”作为 `hue_unreachable` 证明，因为 Hue 在接近 SAT0 时本身不可识别。

每个目标必须保存：

```text
hue_defined
inverse_condition
nearest_competing_projection_distance
hue_coverage_deg
```

只有目标 Hue 在冻结 observer 下可识别时，Hue failure 才能参与 gamut 结论。

### 5.4 `s_exact_max_int100_fullscale(h)` 最小证明

1. 同 Hue 至少一个 `faithful` SAT 下界；
2. 至少一个合法、重复稳定、非 measurement/solver failure 的 SAT 上界；
3. 在 bracket 内二分或定向加密；
4. 首轮 boundary width 不大于 5 SAT points；Gate-6 freeze 不大于 2 SAT points；
5. 两个 endpoint 均做 5 次独立 settled confirmation；
6. 保存 active-set、full-scale channel、white fraction、sensitivity、inverse condition 和 failure cause；
7. active-set 切换附近额外采一个点；
8. 不用 spline 平滑消除真实不连续；
9. `SAT=100` faithful 时可直接记录边界为 100，无需制造非-faithful 上界；
10. 该边界只对 `INT=100/full-scale` 有效。

### 5.5 Scale-relaxed 诊断

任何准备被写成 gamut boundary 的 non-faithful 上界，至少做一次非产品诊断：

- 允许最高通道上限降至 `3072`；
- 必要时再测试 `2048`；
- 保持同 observer、同目标、同 60 秒协议；
- 仍由真实闭环求解，不只按比例缩放命令。

解释：

- 若较低 scale 通过，则当前边界是 `full_scale_operating_boundary`，不是色度集合的物理边界；
- 若较低 scale 仍失败，只能提高“经验不可达”的证据强度，仍需排除 solver 和 measurement；
- 这些点不是 P8 INT 数据，不用于拟合 Ray INT 曲线。
