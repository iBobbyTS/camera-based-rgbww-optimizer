## 1. 研究结论摘要

### 1.1 已完成工作整体可信，不应重启 P1-P6

报告对实机证据、离线证据、条件通过和未覆盖的区分基本清晰。没有发现足以要求以下返工的具体证据：

- Remote 相机链；
- identity RAW observer；
- P2 三档五通道基底；
- P3 `forward_model_seed_only`；
- P4 停止 CCT multipatch 扩展；
- P6 106 点 Ray HSI 重拍；
- P6 从 affine 回退到完整二维周期流形的决定。

### 1.2 P7 架构可保留，但实拍前有六个实质缺口

P7 的 manifold、objective、feedback、runner 和 analyzer 分层合理。需要补的不是“大重构”，而是：

- uncertainty artifact；
- 联合 coverage；
- 三次独立 confirmation；
- current-session Ray anchor；
- command audit hard gate；
- full-scale/gamut scope。

### 1.3 Planner 的“两层不确定性”应批准，但不能原样执行

正确部分：

- Ray 与 strip 不能只取最大值，也不应直接线性相加；
- 应在优化前冻结；
- 局部噪声更高时应 unresolved，而不是事后扩阈；
- 三张 confirmation 不能兼任阈值估计与通过证明。

需要修正：

- camera noise 已经包含在实测 Ray/strip repeatability 中，不能重复加；
- 组合应在 58-feature covariance 层完成；
- shape residual 非负，Hue 周期且 SAT0 未定义，单纯 Jacobian/高斯 3σ 不稳健；
- 三个边际 99.73% gate 的联合 coverage 只有约 `0.9973^3 = 99.19%`（独立假设下），不是 99.73%；
- 需要第三类 target-model uncertainty；
- P6→P7 跨会话 reference drift 需要当前 Ray anchors。

### 1.4 三点 sentinel 不足，四点是最低合理集合

原三点：`H0/S0`、`H120/S100`、`H300/S100`，覆盖了零饱和、稳定高饱和和困难高饱和，却没有覆盖中间 SAT。由于 WW/CW 在中间 SAT 的参与和二维路径正是项目核心，增加 `H120/S50` 是必要的。

### 1.5 当前 `s_exact_max(h)` 只能称为满幅 INT100 工作边界

P2 已发现档位依赖，P3 已发现混合非加法，因此“至少一通道 4095”会改变颜色工作点。它不是无害的 scale normalization。当前边界应写成：

```text
s_exact_max_int100_fullscale(h)
```

只有做过 scale-relaxed 诊断，才能判断失败是 full-scale/load 边界还是更接近灯带颜色集合边界。

### 1.6 P8 应继续锁定

13 个直接节点不能证明：

- Hue 周期插值；
- 非节点二维插值；
- 高曲率区域；
- gamut 边界；
- 强度与颜色可分离。

因此先完成 Stage 7 holdout 和边界语义，再进入 INT。

## 5. 不确定性：为什么原方案不够

## 5.1 当前默认 strip tolerance 为零的问题

P7 evaluator 已预留三项 strip 3σ，但默认 `0.0`。结果是：

- Ray 侧重复性被考虑；
- strip/camera 的实际散布没有进入 acceptance region；
- 同一真实匹配可能被误判为 unconfirmed；
- 若实拍后再扩大 gate，会产生 data-dependent acceptance。

因此 P7 不能在该状态下开始正式实拍。

## 5.2 不确定性不是“Ray、camera、strip 三个数字相加”

一次 Ray observation 和一次 strip observation 都经过同一相机与 RAW observer。它们各自的实测 repeatability 已经包含：

- shot/read noise；
- exposure/decoder variation；
- chart statistics；
- source output variation；
- 短时环境变化。

如果再独立加入一个“camera noise”标量，会重复计算相机部分。正确做法是明确 uncertainty budget：

- Ray observation covariance；
- strip observation covariance；
- model/interpolation covariance；
- 可证明存在时才加入交叉 covariance。

JCGM 100 的核心原则是通过 variances/covariances 和 sensitivity coefficients 组合不确定性，而不是直接拼接最终“误差条”。

## 5.3 为什么应在 feature space 组合

Hue、Ray-equivalent SAT 和 shape 都是同一个 58-feature 向量经过 nonlinear inverse 得到。不同误差来源在 feature space 中有共同维度和相关结构。

若先把每个来源单独变成：

```text
Hue 3σ
SAT 3σ
shape 3σ
```

再做简单处理，会丢失：

- CFA/patch correlations；
- scale removal 引入的相关性；
- Hue/SAT/shape 之间的耦合；
- target-specific local Jacobian；
- periodic wrap；
- shape 非负边界。

因此组合顺序应为：

```text
source distributions/covariances
→ feature-space difference distribution
→ exact local inverse/evaluator
→ output coverage region
```

## 5.4 P1 white repeatability为何只能作 floor

同一 scale-removed feature perturbation，在不同 H/S 目标处经过 inverse 后会被不同程度放大。高饱和状态还会出现：

- 某些 patch/CFA 强信号；
- 另一些接近 near-noise；
- manifold tangent/normal 方向变化；
- inverse condition number 变化。

因此 P1 white covariance 可用作 `Sigma_S,0`，但最终 tolerance 必须 target-specific 地传播。

## 5.5 高维小样本 covariance

58-feature covariance 需要足够 repeats 才能稳定估计。若 repeats 少于维度，普通 sample covariance 必然 rank deficient；即使略多，也可能严重病态。

Ledoit–Wolf 的经典工作指出，大维 covariance 的普通 sample estimator 可能不可逆或病态，shrinkage 可改善条件和误差。因此本项目应在以下方案中固定一种：

- diagonal；
- 小 block；
- shrinkage-to-diagonal。

不能每个 target 按“看起来更好”选择一种。

## 5.6 Jacobian 传播的适用范围

一阶传播：

\[
\Sigma_z \approx J_g\Sigma_fJ_g^T
\]

适用于局部平滑、近线性和远离边界的区域。JCGM 101 明确指出，当 model nonlinearity 显著或输出分布非高斯时，Monte Carlo propagation 更一般。

本项目的困难点恰好包括：

- Hue 周期；
- SAT0；
- 低 SAT 的 Hue 奇异性；
- 高曲率；
- inverse branch；
- orthogonal norm 的零边界。

所以 Jacobian 可作快速估计或 sanity check，不应是所有点的唯一最终方法。

## 5.7 Hue 在 SAT0 处未定义

Hue 本质上是一个角度坐标；当 chroma/saturation 为零时，方向不存在。CIEDE2000 的实现也需要在 chroma 为零时对 Hue 做特殊处理，而不是把一个任意角度当真实颜色属性。

P6 和 P7 现有 SAT0 Hue undefined 设计是正确的。后续 `hue_unreachable` 也不能使用接近 SAT0 的点作为证据。

## 5.8 Shape residual 不是零均值高斯标量

若 `r_perp` 是正交残差向量的 norm，则：

\[
r_\perp \ge 0
\]

即使底层 feature noise 是高斯，norm 的分布也更接近 chi/weighted-chi，不以零为中心。直接计算“mean + 3 sigma”或把它当 signed Gaussian 可能失真。最稳妥方法是直接取 null Monte Carlo 的单侧 99.73% quantile。

## 5.9 三个边际 gate 的联合 coverage

若 Hue、SAT、shape 各自有 99.73% coverage，即使三项独立，三项同时处于区间内的概率为：

\[
0.9973^3\approx 0.9919
\]

即约 99.19%，而不是 99.73%。若三项相关，结果还会不同。

因此应使用：

- multivariate coverage region；或
- Monte Carlo 上 `max normalized error` 的联合 quantile；或
- 保守 Bonferroni 校正。

JCGM 102 专门讨论多输出 measurement model 的 covariance 和 coverage region，支持这一处理。

## 5.10 “3σ”命名

99.73% 与 3σ 只在高斯语境中近似对应。本项目 output distribution 可偏斜、截断或多峰。artifact 应记录：

```text
coverage_probability = 0.9973
```

而不是把所有 quantile 强称为 3σ。

## 5.11 Monte Carlo 数值收敛

JCGM 101 指出，coverage endpoint 的数值稳定需要足够多的 trials，且高 coverage 需要更多样本。对 99.73% tail，本项目建议：

1. 使用固定 seed 和 batch；
2. 至少从 `1e6` trials 起步；
3. 继续增加到各 gate 在连续两个 batch 中变化小于：
   - Hue `0.05°`；
   - SAT `0.1 percentage point`；
   - shape threshold 的 `1%`；
4. 若 1e6 不稳定，增加至 2e6–5e6 或使用自适应程序；
5. 保存 trial count、seed、quantile convergence trace。

具体数值可以由 Planner 根据 evaluator 成本调整，但必须在实拍前冻结。

## 6. 三次 confirmation 能证明什么

## 6.1 不能从三张重新估计 3σ

在正态假设下，标准差的置信区间依赖 chi-square。NIST 给出的公式为：

\[
\sqrt{\frac{(n-1)s^2}{\chi^2_{1-\alpha/2,n-1}}}
\le \sigma \le
\sqrt{\frac{(n-1)s^2}{\chi^2_{\alpha/2,n-1}}}
\]

当 `n=3` 时，95% 区间大约是：

```text
0.52 × sample_s  ...  6.28 × sample_s
```

范围极宽。因此三张不能可靠估计局部 3σ。

## 6.2 三张的合理用途

- 检查 full off/on restart 后是否重复；
- 检查每张是否独立通过冻结 gate；
- 发现 gross outlier 或 inverse branch jump；
- 发现 P1 floor 明显低估；
- 不更新 threshold。

## 6.3 为什么 boundary 用五张

`n=5` 仍不足以高精度估计 sigma，但比 n=3 更适合判断边界稳定性。边界点的错误分类会直接影响 runtime compression，因此需要更高证据等级。

## 7. 测量不确定性与合格判定

JCGM 106 区分：

- tolerance/specification limit；
- acceptance limit；
- measurement uncertainty；
- guarded acceptance。

这说明“噪声有多大”和“产品允许多大误差”是两个不同问题。

### 7.1 本项目当前可声明的 `faithful`

由于用户尚未给出独立的人眼 JND 或产品 Hue/SAT 误差规范，本轮 `faithful` 应严格限定为：

> 在冻结 Canon camera-observer、当前 geometry、INT100、full-scale policy 和 99.73% joint measurement coverage 下，未观察到可分辨的 Hue/SAT/shape 差异，并通过独立 off/on repeat。

它不是：

- 人眼不可区分；
- 其他相机不可区分；
- 1°/1% API 精度；
- 光谱一致；
- 任意材质一致。

### 7.2 后续若增加产品规范

若用户以后定义，例如：

```text
Hue absolute error <= L_h
SAT equivalent error <= L_s
shape <= L_shape
```

应采用 guard-band 规则，例如：

\[
|e_j|+U_j\le L_j
\]

而不是让噪声越大、通过区间越宽。

本轮无需阻塞 P7，但 analyzer 必须保存足够数据，以便未来增加该层。

## 8. Reference drift：本轮报告中遗漏的关键门禁

## 8.1 为什么 hash 不够

P6 hash 只能证明使用了同一数据文件，不能证明 P7 会话中的：

- Ray 输出；
- 相机响应；
- 几何；
- exposure；
- decoder；
- 环境；

仍与 P6 相同。

P6 target 若发生 systematic shift，P7 solver 会把 shift 全部补偿到灯带命令中，最终得到“匹配旧 Ray 会话”而不是当前 Ray 的结果。

## 8.2 最小 anchor 设计

建议 sentinel 前测：

- `H0/S0`；
- `H120/S100`；
- `H300/S100`。

sentinel 后再测：

- `H120/S100`。

这些点分别覆盖：

- zero anchor；
- 稳定高饱和；
- stress region；
- run 前后 drift。

## 8.3 Anchor 失败后的处理

不能在当前 P7 run 内：

- 重拟合 P6；
- 平移 target；
- 扩大 uncertainty；
- 继续把结果写成 faithful。

应停止并创建独立 `reference_drift` 诊断。

## 9. 为什么四点 sentinel 优于三点

## 9.1 原三点覆盖

| 点 | 覆盖风险 |
| --- | --- |
| H0/S0 | SAT0、Hue undefined、white path |
| H120/S100 | stable high-sat closed loop |
| H300/S100 | high-curvature/stress |

缺失：

- 中间 SAT；
- 白通道与 RGB 混合；
- full 2D manifold 的 SAT interpolation；
- Ray-equivalent SAT inverse 的中间区间。

## 9.2 新增 H120/S50 的价值

H120 复用同一 Hue，可把差异主要归因于 SAT 变化。`S50` 应明显涉及与 S100 不同的 white fraction/command active set，能够检验：

- SAT inverse；
- manifold curvature；
- WW/CW 参与；
- P2 seed 到 closed-loop 的过渡；
- 中间目标是否 measurement-observable。

因此四点是最低完整机制集合。

## 9.3 为什么不以 H120/S50 替代 H120/S100

若只保留 H120/S50 和困难的 H300/S100，则高饱和失败时无法区分：

- 高饱和普遍不可工作；
- 只是 H300 stress region；
- solver 在 endpoint 失效。

因此稳定高饱和控制点仍需保留。

## 10. Gamut：最容易产生过度声明的部分

## 10.1 `max(channel)=4095` 的双重作用

上一轮研究把 `max(u)=1` 用于：

- 避免 `u=0,k=0`；
- 固定 scale；
- 追求高输出。

在理想线性系统中，按比例放大命令不会改变颜色方向。但 P2/P3 已证实本系统不是严格线性：

- 单通道 shape 随 level 变化；
- 多通道混合存在广泛 residual。

因此 full-scale constraint 同时是：

1. 数学去尺度；
2. INT100 产品输出策略；
3. 热/负载工作点；
4. 可能限制颜色可达性的约束。

## 10.2 当前 boundary 的正确命名

应写：

```text
s_exact_max_int100_fullscale(h)
```

而不是：

```text
s_exact_max(h)
```

因为边界还可能依赖：

- output scale；
- settle time；
- INT；
- active set；
- total load；
- observer/exposure；
- temperature。

## 10.3 Scale-relaxed diagnostic

对 full-scale non-faithful point，允许 max code 上限降到 3072/2048，并重新闭环求解。

### 结果解释

#### 低 scale 通过

说明：

- 颜色方向在较低输出可达；
- full-scale 下失败可能由 level/load/thermal nonlinearity；
- runtime boundary 是 output policy boundary。

#### 低 scale 仍失败

说明：

- 经验不可达证据增强；
- 仍不能排除局部 solver、seed、feature observability 或未搜索命令区域；
- 不能写成数学证明的物理 gamut。

## 10.4 `hue_unreachable` 与低 SAT 的矛盾

Planner 原建议“在足够低 SAT 仍不能保持 Hue”来证明 hue unreachable。但 SAT 越接近零，Hue 越不可识别；到 SAT0 完全未定义。

正确条件是：

- target Hue 在 observer 中可识别；
- inverse 唯一；
- Hue uncertainty 小于局部 Hue separation；
- 在该 identifiable SAT 区间内仍稳定失败。

## 10.5 `unconfirmed` 不能构成 bracket upper

一个上界只有在以下条件下才可称为 stable non-faithful：

- measurement valid；
- uncertainty resolved；
- reference anchors valid；
- solver 没有预算或模型故障；
- 多次 confirmation 重复失败；
- best valid candidate 的 failure direction 稳定。

否则只能是 `unconfirmed`，不能用来二分 `s_exact_max`。

## 11. P8 为什么必须后做

## 11.1 13 点 pilot 只验证直接节点

13 点为：

- one SAT0；
- six main hues；
- SAT50/SAT100。

这些大多是 P6 direct nodes。即使全部通过，也没有检验：

- periodic interpolation；
- non-node SAT interpolation；
- high-curvature interpolation；
- active-set boundary；
- runtime interpolation after clamping。

## 11.2 最小 holdout

进入 P8 前建议至少：

- wrap：`H345/S50`、`H15/S50`；
- high curvature：一个 `H≈285/S80` 类目标；
- 六个 60° sector 各一个随机非节点；
- 每个已识别 gamut boundary 两侧；
- SAT low but hue-identifiable 的一点。

具体点可由 Planner 基于 P6 curvature map 生成，但必须在拟合前冻结。

## 11.3 INT 与 gamut 的耦合

如果 output level 改变 strip shape，那么：

\[
s_{max}=s_{max}(h,I)
\]

P8 需要验证是否可分离。Stage 7 只能冻结 `I=100` 的边界，不能把它自动用于 5%/20%/50%。

## 17. 最终研究判断

P0-R 至 P6 已经形成足够稳固的实验基础，不应因 P7 尚未实拍而重启前序阶段。P7 当前最大的科学风险不是局部求解器本身，而是：

- 把多个 uncertainty 来源在错误坐标中组合；
- 把三个边际 3σ 当成联合 3σ；
- 用三张数据重新估计 3σ；
- 忽略 P6→P7 跨会话 reference drift；
- 把 full-scale 工作边界写成物理 gamut；
- 在没有中间 SAT sentinel 和非节点 holdout 时进入 P8。

修复这些问题不需要推倒现有 P7。最合理路线是冻结 uncertainty 和 reference-anchor 合同，运行四点 sentinel；只有稳定高饱和、中间饱和、零饱和和 stress point 的失败模式均可解释，才扩到剩余 9 点与边界搜索。
