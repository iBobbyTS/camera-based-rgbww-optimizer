## 2. 统一评价、置信和停止语言

### 2.1 主量与容差不放宽

定义 `G=(G1+G2)/2`，`z=(ln(R/G),ln(B/G))`，所有差均为strip−同目标的本地Ray。

白光保留原代理白点算法、矩阵与容差：

`E=max(|e_K|/25, |e_mired|/1, |e_Duv|/0.0005)`。

若某历史节点有不同冻结容差，显式保留该节点原值，不擅自统一。CCT和mired是一条温度方向，不当两个独立可控方向；联合判定可以同时检查二者。

彩光SAT≥25且Hue可辨识：Hue±2°、SAT±2pp。SAT0：两个log色比各±0.01，Hue未定义。低SAT固定体验点使用经验证的Ray轨迹与其可辨识性，不强行给接近白点的唯一Hue。

每个结果必须同时输出：点估计是否在门内；均值联合95%区域是否完全在门内；下一次独立使用的联合95%预测区域是否完全在门内。可以只达到第一档或第二档，但不写成第三档。

### 2.2 独立单位与分布

一个选择帧加三个确认帧，确认n是3。三个strip确认共用两张Ray时，必须保留共享参考协方差；它们不是三个完全独立的Ray/strip配对。相隔约20秒的burst是时间序列，不当独立reset，更不等于纯传感器噪声。

N2可以使用工作模型 `d_sc=mu+b_s+epsilon_sc`。三会话的均值CI按会话单位；下一次新会话中的单次操作PI必须包含会话和循环层。正态、平稳、可交换是条件假设，不是从三会话证明的事实。系统趋势单独报告，不用池化标准差掩盖。

本轮复算的随机截距矩估计PI是**近似条件PI**，不应标成精确覆盖率。部署级PI优先通过预先冻结的低维模型和新会话预测检验；样本不足时报告条件范围及不适用原因，不用单个像素数代替独立n。

联合95%可以用源级分层MC，或预先声明的Bonferroni箱。三输出、df=2时双侧Bonferroni系数为7.64880394；不要硬写9.925再称98.33%。`mean_ci.low/high`与`prediction_interval.low/high`分别计算。箱的中心、半宽和上下界必须自洽。

每点95%不等于全70点同时95%。固定70节点通过比例不附二项式总体CI；跨设计网格P95不是噪声分布，也不是95%置信上限。

### 2.3 最佳、边界与停止

只允许以下分开状态：

1. `mean_and_prediction_qualified`：均值及适用的未来PI都在容差内，停止追求无意义更小误差。
2. `mean_only_qualified` / `point_only_in_tolerance`：相应较弱证据，不能称每次使用保证。
3. `tested_neighborhood_practical_convergence`：至少两个有效非共线主响应方向已测；当前可行方向的改善小于预登记的可分辨改善；邻域和face明确。
4. `bounded_search_exhausted`：预算耗尽、仍可能有更好命令。它不是gamut极限。
5. `reference_limited`、`measurement_limited`、`map_unqualified`、`operating_distribution_unqualified`：分别记录原因和本轮有界判别结果。

物理色域外、无可行方向、12bit量化受限需要额外直接证据。固定CW/WW为0是一个子约束，不是满幅face；至少一个**真实4095通道**定义满幅face。一个face上的一条G扫描不能代表RGBWW整个可行集合。

失败是有效结果；代码实现错误、无效输入和未测方向不是物理负结果。预算约束新观测，不约束修普通代码bug的次数。不通过重启/root改名重置科学预算。

### W13-C：修复实际插值再验证

第一步必须是离线恒等性，不是新增6个knot。

设相邻色温 `T0<T1`，`m0=1e6/T0>m1=1e6/T1`，请求 `m=1e6/T`，

`a=(m-m1)/(m0-m1)`。

则T0权重为a，T1权重为1−a；GM另作正常线性权重。**先按这些权重混合实际PWM，再按已声明规则投影至max4095并整数化**。这是候选模型，不是灯带线性光学定律。输入本身是实际PWM时，不得再套一遍code-duty映射。

离线必须做到：70/70节点原命令重现；边界与周期/范围规则一致；相同输入颜色不被映射到邻节点；每个输出实际满幅。旧20张仍保留，只评价旧反权重函数，不能拿新命令配旧照片。直接查表的70节点照片不因插值错误而作废。

在下列6个旧请求上拍修正后的命令作**开发回归**：1850/50、2400/50、5350/105、6050/160、10500/120、17500/30。它们不是新的独立留出。若多数仍失败，先看节点本底/投影/实际曝光，而不是马上宣布整个双线性方法无效。

冻结后使用 `experiment_targets.json` 中20个新请求作真正留出（覆盖范围与face切换）。每点一个源配对，必要冷端用Ray夹心。总误差是strip−该请求Ray；不能把它自动称纯插值误差。至多一次局部补点≤6个及6个新留出；仍失败则输出实际支持的点和模型区域，不凭两点通过画连续矩形。

### W13-D：噪声转移、真实使用与LONG

不重跑完整N2。复用四白光和恢复的蓝光主层分层统计。在最终采用的风险命令上进行至多6状态×2个独立源配对（24张基础源观测）的转移检查，最好分到两个新会话并兼任W13-B/C13确认；共享同一physical ID不虚增n。只有转移检查支持的分组才能外推方差。

现有40秒burst揭示20000处Ray约−39K、strip约+142K的变化，不能叫相机噪声底。若该变化会改变采用结论，至多2个固定状态各源补一个反序/规定时刻短序列，每源在预登记的80/100/120秒三个名义时刻采集、共≤12张（实际曝光延迟另记），仅分清时间趋势与重复波动，不拟合复杂热ODE。

## 4. C13：彩光五个收尾工作包

### C13-A：修复主层数据选择与Ray计量尺

#### 先使用已有数据

恢复10张C122主白块合法、仅58层近噪的候选；五个高SAT停止结论降为`bounded_search_not_exhaustive`或`primary_analysis_incomplete`。这不把它们变成产品通过，只是撤回无效的“角区不可测”推断。

当前Ray全局模型的40条训练记录只有24个不同训练坐标；k近邻IDW的重复点/切换会产生平坦区与模型多解。先按真实状态和会话合并重复坐标、保留重复协方差，再拟合周期前向图。可以使用现有C12-1与C122本地Ray，旧留出在已用于选模型后标开发集，不能继续叫独立检验。

先做到前向节点一致、S0不随Hue变化（仅在实测支持范围内）、0/360连续、局部导数定义明确。算法Jacobian奇异只能说明该模型局部奇异；除S0 Hue定义外，不证明Ray物理响应不可辨识。

#### 局部二维Jacobian，不旋转90度冒充Hue

在每个拟采用的目标附近构造

`J=[∂z/∂H, ∂z/∂S]`，`δ(H,S)≈J^{-1}δz`。

两个列向量必须分别来自对应方向的Ray实测。它们不要求正交。S0→S50等50pp长割线只能给初值，不能当已验证的±2pp局部量尺。必须传播J的参数不确定度、参考漂移、观测协方差和局部曲率/反解多解。

优先处理H0/S50、H300/S50和H60/S100；这些分别检验大直接残差、算术错误和端点一侧导数。已有足够的真实局部邻点则不新拍。否则每目标最多5个新Ray邻坐标：一般用H±2°、S±2pp四点及H+1°/S+1pp的一点留出；S100改用S98/S96与H+1°/S99。只有邻域数值足够稳定/线性才采用这个局部线性近似。

所有局部块保留同目标中心前/后参考。最多13个非S0采用目标各5邻点+2中心=91张额外Ray；至少先完成上述3目标再决定其余是否必要。局部曲率不合格时，全阶段仅额外≤12张用于较小邻域或一轮模型判别。不存在“91张必然换来全局合格”的承诺。

映射误差预算仍为0.5°/0.5pp，是从产品容差分配的工程目标。训练残差、单个留出或经验P95不是该预算的95%置信上界。稀疏局部块只能提供条件工作模型；如果不足以界定模型偏差，报告`map_unqualified`及哪些量已估计，不制造SAT置信区间。其他目标可继续直接z求解，但暂不发布菜单等效覆盖。

|---|---|
| H0/S100 | 纯R的主块有效；与加G、加B的点共同建立局部有界模型。旧几条边界点不证明全部命令无解。 |
| H120/S100 | 纯G、G+B与R/G/B组合主块有效；补必要的独立R方向与局部交叉验证，不再假定r=0不可测。 |
| H180/S100 | r=0,g4095,b1154的主层可用；从其与r512候选之间建立可验证的新方向。 |
| H240/S100 | r0/g743与r400/g700均有效；不存在已证的“r400即测量地板”。 |
| H300/S100 | 目前实际命令差秩1，主要只扫G。先在R4095固定时测试B向下的可行方向；改变满幅face必须确实固定另一通道4095。 |
| H300/S50 | 原切向算术错误，先用正确J评价，再按真实色度改善调整。 |

观测z的凸包包含目标只能作为候选线索；由于命令响应非线性，不能把z凸组合等同PWM凸组合，更不能作为物理可达证明。

每个最终采用命令至少3次独立确认，排除选择帧；至少跨两个Ray参考块，新会话确认与C13-D共享。旧3张同块确认可保留，但若命令改动则不能当新命令确认。共享Ray的协方差不可忽略。

### C13-C：每Hue真实可支持的SAT，而不是径向投影数字

逐Hue同时保存：请求H/S、实际PWM、直接Δz、估计H/S及联合区间、inverse多解、n与分组、model适用性、停止原因、secondary58结果。

`s_best_tested`是在Hue有效、量尺合格、实际满幅且重复稳定的**已测命令**中，达到的最大实际Ray等效SAT及其区间；它是未知最大可达SAT的经验下界，不是上界，也不是最高通过请求档位。

在有效lower和有界未达upper之间，只有当前目标行为单调且量尺合格时，允许每Hue最多5个中间SAT请求；每请求遵守上节同一命令预算。无lower、不单调或参考受限就停止二分，报告不连续/未建立，不向S12/S10/S5自适应寻找“终于通过”的点。

连续区间需要运行时在其中的独立支持及明确模型误差假设；否则只列离散样本。精确的硬件边界不作为完成项目的强制条件，可以以“已测试邻域稳定最佳近似+有限覆盖范围”科学收口。不能把未知区写0%，也不能把短缺18.3pp机械改成覆盖81.7%。

### C13-D：运行时语义与固定Hue的体验留出

S0必须输出已验证满幅S0命令，不随Hue改变；完整锚点集合必须被实际输出函数读取，包括合格H60/S100。S0..25、S50..100不能悄悄钳为同一颜色然后标`as-requested`。真正需要压缩时显式输出requested/realized SAT、`gamut_compressed`及置信/未认证状态。

先做离线锚点恒等、0/360、SAT边界、满幅和标签回归，再拍新命令。不要以旧W12-3错误插值为证据否定所有彩光模型。

冻结后使用`experiment_targets.json`的10个新一般留出与固定同Hue的9个SAT检查；一般留出包括三对同Hue低SAT请求。固定路径包含H60、H120、H300，各S0/S10/S20/S37；S0同一命令已有合法新会话复用时不重复拍。只比较同Hue轨迹的等效SAT和Hue偏离，不能用H2与H330相对白点距离证明SAT单调。

一般留出每点Ray前/strip/Ray后，共30张；固定路径最多36张（可共享身份减少）。最多一次局部修正后6个全新留出，共18张。量尺不合格的区域仍可报告直接色比结果，但无菜单误差通过结论。不得用本组最大失败误差作为新的通过门。

### C13-E：满幅结案与未来100%灯带基准

最终交付三种分开的完成：实现和证据完成；有限测试范围的最好稳定近似；在给定误差/预测保证内可采用的子域。三者不是同一百分比。

Ray只有在最终采用范围内的命令、运行时函数、独立验证和条件/预测不确定度均完成后，才可以不再用于后续低亮度标定。尚未建立的Hue区不能随着“收官”变成已覆盖。

为未来保存每条100%灯带基准的实际PWM、相机原生色比/58层、曝光、源状态、独立重复与协方差、会话条件和原Ray目标绑定。未来只沿灯带自身PWM-duty优化相对100%颜色，不调用Ray低INT；不在本GUIDE执行该阶段。

## 5. 预算和推进顺序

顺序：**离线纠错/已有主层恢复 → 正确量尺与必要方向 → 冻结命令 → 独立确认 → 实际运行时留出 → 不确定度/有限采用范围/数据包**。白光、彩光共用设备时不并发；普通实现修复不升级为新的科学门。
