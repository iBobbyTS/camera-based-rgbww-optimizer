## 2. 为什么不能直接把正式快门改慢

### 2.1 当前差异远超原 exposure envelope

冻结 P1 observer envelope 是一个局部 `1.0x..1.25x` 曝光窗口。当前 `1/5000` 到最慢的原窗口候选约 `1/4000`，只增加 25% exposure。当前图像的 brightest observed pixel 也仅高于 black 约 27 DN；该变化不足以把 58 个 feature 从全体 near-noise 变为合法 observation。

### 2.2 历史同状态、同曝光已经有效

两个前一日 direct target-local root 在同一 state 和相同 MakerNote exposure 下都产生了有效 Ray target。因而当前 failure首先是一个 **reference-output/path contradiction**，不是一个尚未标定过的正常 exposure state。

### 2.3 直接改慢会改变错误的对象

如果 Ray 实际未发光，而相机改用很慢快门，可能最终测得：

- 环境漏光；
- 色卡暗噪声；
- 其他设备指示灯；
- Ray 极弱的非目标泄漏光。

这种 frame 即使数值上跨过 near-noise threshold，也不能成为 Ray H120/S100 的参考目标。

因此必须先区分：

```text
source/path failure
vs
state-specific legal exposure window shift
```

## 3. 最小充分诊断的设计原则

### 3.1 两个独立问题

诊断必须依次回答：

1. 当前相机/光路能否观察到一个已知 Ray control state；
2. H120/S100 是否存在一个来源于 Ray、且满足 58-feature 质量与局部 exposure invariance 的单曝光窗口。

### 3.2 为什么需要 control state

采用近期已验证的：

```text
H300/S100/INT100 at nominal 1/2500
```

若该 control 也不能在其 qualified shutter 下产生合法 observation，不能把 H120 failure解释为 state-specific exposure。此时应停止为全局 source/optical-path unresolved。

### 3.3 为什么需要 all-off dark

在 H120 exposure ladder 前，在全关状态以最慢 diagnostic shutter `1/250` 拍一张 dark。其用途只是在 diagnostic root 中证明慢曝光没有把环境光变成一个合法 58-feature target。它不进入 formal no-ambient statistic，也不用于 target subtraction。

### 3.4 为什么使用完整 1.25x shutter ladder

预先冻结 ladder：

```text
1/5000
1/4000
1/3200
1/2500
1/2000
1/1600
1/1250
1/1000
1/800
1/640
1/500
1/400
1/320
1/250
```

相邻名义 exposure 比约为 `1.25x`。H120 保持连续点亮，不在 ladder 内重新发 off 或改变 command。

一旦出现两个相邻 exposure 均满足：

- 58/58 required features accepted；
- no clipping/nonfinite/near-noise failure；
- recorded exposure 合法；
- exposure-normalized feature shape 通过既有 P1 invariance evaluator；

则选择其中**较快**的 shutter 作为新的 nominal policy，较慢的一档作为 `1.25x` guard，并立即停止 ladder。

该规则不根据目标颜色误差选择 shutter，只根据 measurement validity 与 exposure invariance选择，避免 data-dependent target fitting。

## 4. 新 exposure policy 的科学含义

### 4.1 observer 不改变

以下保持冻结：

```text
Canon native Bayer
R/G1/G2/B
58 features
identity response
patch/location
quality thresholds
feature statistic
source covariance
coverage 0.9973
FAST reset600 / D120 / A120 / Q120
```

改变的只是：

```text
Ray H120/S100 state-specific nominal shutter
```

### 4.2 envelope 的精确定义

```text
diagnostic slowest shutter = 1/250
formal selected shutter must be no slower than 1/320
formal observer window = selected shutter .. one adjacent 1.25x slower guard
formal run = fixed selected shutter only
in-run auto exposure or fallback = prohibited
```

如果 qualified pair 为 `1/320 + 1/250`，正式 shutter 为 `1/320`。

### 4.3 与历史 evidence 的可比性

#### 若仍选择 `1/5000`

且 `1/5000 + 1/4000` 两档均合法、shape invariant：

```text
old exposure policy retained
current failure = transient reference-emission/path anomaly
```

历史 direct evidence 可继续按原 scope 使用。

#### 若选择其他 shutter

```text
new policy = ray_h120_s100_exposure_v2
old/new numerical centers = not pooled
P6/R6 numerical compatibility = diagnostic only
P6 topology = retained
new target-local comparison = allowed only in a fresh root
```

原因：P1 只证明局部 exposure window 的响应有效，不能把不重叠的远距离 shutter window静默当成同一个 historical measurement procedure。

新 direct solver 中 Ray `Q_before/Q_after` 必须使用同一个 v2 shutter，并继续通过冻结 covariance/guard bracket；该 bracket失败时不能重估 covariance。

### E-B — dark 本身形成合法 observation

```text

```

停止。不能通过 ambient subtraction改变当前 no-ambient observer。

### E-C — `1/5000 + 1/4000` 合法且 invariant

```text

```

允许新 root重新执行 H120 local-controllability；不再请求 Advisor。

### E-D — 更慢的相邻 pair 合法且 invariant

```text
classification = state_specific_exposure_window_shift
new policy = ray_h120_s100_exposure_v2
```

允许新 root使用 selected fixed shutter执行 local-controllability；不池化旧 target center，不再请求 Advisor。

### E-E — 从 near-noise 直接进入 clipping，没有两个相邻合法点

```text
classification = no_single_exposure_window_under_frozen_observer
```

停止。未来若要使用 dual-exposure/HDR，必须新 Advisor gate，因为那会改变 observer和 covariance。

### E-F — 到 `1/250` 仍 near-noise

```text
classification = H120_S100_reference_emission_not_established
```

停止。不能继续放慢快门，也不能形成 gamut inference。

### E-G — 两个相邻合法 exposure shape不兼容

```text
classification = exposure_response_not_invariant_for_current_state
```

停止。不能选择其中一档作为 formal target；需要另行研究 response model。

## 7. 最终研究判断

本次根目录应永久保留为：

```text
valid measurement-quality failure
not a valid color observation
not a solver attempt
```

当前证据不支持直接扩大正式曝光。最小充分动作是一个 Ray-only、0-formal、最多 16 张的 emission/exposure-window diagnostic：先用 H300 control验证光路，再用 all-off dark排除环境信号，最后在 H120/S100 连续点亮下扫描预冻结的 1.25x shutter ladder。

只有两个相邻 shutter同时产生合法、曝光归一化 shape一致的 58-feature observation，才允许版本化新的 H120/S100 state-specific exposure policy。这样既不修改 observer，也不会把 Ray 未发光误当成相机曝光不足。
