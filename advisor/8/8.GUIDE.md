### Early stop

#### 成功停止

一旦两个相邻 shutter：

```text
58/58 quality valid
recorded exposure valid
exposure-normalized 58-feature shape compatible
```

选择较快一档作为 formal nominal shutter，较慢一档作为 guard，停止后续 captures。

#### 失败停止

出现以下任一项且尚未形成合法相邻 pair：

```text
clipping
nonfinite
unexpected quality failure other than near-noise
shape invariance failure
physical/evidence/isolation failure
```

立即停止；不得继续到更慢 shutter寻找“可通过”帧。

`near-noise-only` 允许继续到下一档。

# 5. Exposure qualification gate

合法 pair 必须同时满足：

1. 两帧属于同一连续 H120/S100 command interval；
2. 相邻 nominal exposure ratio `<=1.25`；
3. 58/58 required features均 accepted；
4. clipped/nonfinite/near-noise gate全部通过；
5. MakerNote exposure与计划 setting一致；
6. 使用现有 P1 exposure-normalized shape-invariance evaluator通过；
7. 不使用 target mismatch、Hue/SAT或solver score选择 shutter。

选择规则：

```text
selected nominal shutter = faster member of the valid adjacent pair
guard shutter = slower member
```

上限：

```text
diagnostic slowest = 1/250
formal selected shutter must be no slower than 1/320
```

formal solver run中：

```text
fixed selected shutter only
in-run auto exposure = prohibited
weak-signal fallback to guard = prohibited
```

guard只证明 observer window，不作为formal自动重拍路径。
