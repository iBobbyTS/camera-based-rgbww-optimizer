## 2.3 cold proxy 定义

### 有温度探头

```text
emitter off
surface temperature within 1.0 °C of ambient
absolute slope <= 0.1 °C/min over last 5 min
```

### 无温度探头

```text
off >= 30 min
extend to 45/60 min after long high-load run
ambient within frozen range
thermal_label = cold_proxy_uninstrumented
```

Ray 的 `INT=0` 与 strip 全零属于 emitter-off，不自动等同 mains-power cold start。若未来要测 mains boot，必须另开实验定义。

## 4. TD-A：cold settling

## 4.1 运行授权范围

```text
sources = Ray, strip
state = H120/S100/INT100 equivalent
independent_cold_cycles_per_source = 3
timed_points_s = [60, 120, 300, 600]
formal_capture_budget = 24
```

strip 使用 P7-R1 retained H120/S100 command；不得调用 solver 生成新 command。

## 4.2 顺序

Ray 和 strip 应分成独立 named run 或独立 source block。每个 cycle：

```text
verify other source off
reach cold proxy
apply exact target command
continuous on
capture 60
capture 120
capture 300
capture 600
all off
verify cleanup
```

至少保存 start/mid/end ambient diagnostic；ambient 不进入 source settling covariance。

## 4.3 通过判定

对每个 source，从 `[60,120,300]` 中找最早候选 `t`，满足：

1. `t` 及所有更晚时点之间的 difference 全部通过 frozen same-state joint coverage；
2. 3 cycles 的对应中心兼容；
3. chronology trend `<=4.0`；
4. single-frame dominance `<=0.5`；
5. 无持续单向 feature drift；
6. measurement quality、source isolation、readback、exposure、cleanup 全通过。

注意：600 秒不是自动候选。若 300→600 仍失败：

```text
TD-A = not_settled_by_600
next = stop_and_request_900_1200_extension
```

若 Ray 和 strip 都通过：

```text
t_formal_provisional = max(t_settle_ray, t_settle_strip)
```

## 4.4 TD-A 分支

### A. 两 source 均在 300 秒前稳定

```text
continue_TD-B
```

### B. 一个 source 未在 600 秒内稳定

```text
stop_thermal_extension_required
```

不进入 TD-B。

### C. measurement/command/cleanup failure

```text
run_invalid
```

只允许普通代码缺陷修复后新目录重跑一次；第二次失败回 Advisor。

### D. temperature proxy 与 feature 不一致

仍以 feature gate 为裁决；记录 `temperature_not_sufficient_proxy`，不据温度单独放行。

## 5.4 判定

### State settling

D/B/C 在 `t_formal_provisional` 及更晚时点必须满足 TD-A 同类 stability criteria。



```text
t_formal = max(all accepted source/state settle times)
```

`t_formal` 只能取已被更晚时间点验证的 60/120/300。若任何 state 只有 600 才接近平台：


### C. return-to-A 分裂

## 6. TD-C：balanced Ray/strip comparison

## 6.1 前提

- TD-A、TD-B 均通过；
- `t_formal` 已冻结；
- current Ray 与 strip 的 source-state 可重复；
- classic ABBA 仍未获授权。

## 6.2 Core comparison

目标：

```text
H120/S100
```

四个独立 session：

```text
S1 Ray -> strip
S2 strip -> Ray
S3 Ray -> strip
S4 strip -> Ray
```

每 session：

1. 两 source 达到 cold proxy；
2. start ambient；
3. 第一个 source 目标 command，等待 `t_formal`，capture，off；
4. 第二个 source 目标 command，等待 `t_formal`，capture，off；
5. end ambient；
6. 双 cleanup/readback。

Core formal budget：8。

## 6.3 Core gate

- 四个 session 的 within-session `strip-Ray` difference 互相兼容；
- Ray-first 与 strip-first 没有超出冻结 envelope 的 order effect；
- Ray current stable center 可计算；
- Ray current stable center vs P6 compatibility 可解释；
- 无 ambient/black-level/geometry trend 足以解释 source difference；
- command/source-isolation audit 全通过。

## 6.4 Endpoint expansion

只有 core gate 通过，才增加：

```text
H0/S0: one Ray->strip session + one strip->Ray session
H300/S100: one Ray->strip session + one strip->Ray session
```

新增 formal budget：8。TD-C 最大 formal budget：16。

## 6.5 为什么不是经典 ABBA

本设计只声明：

```text
order-balanced paired comparison
```

不声明：

```text
linear drift mathematically eliminated
```

只有另有证据证明四 observation 在短、规则、共同线性 drift 窗内，Planner 才可向 Advisor 提交 ABBA mini-run 申请。
