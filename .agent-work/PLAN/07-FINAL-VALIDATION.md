# 阶段 7：最终独立验证、安装与审计

**覆盖原阶段：** P9

**进入条件：** Gate-6 已冻结候选、产品范围、阈值和验证矩阵；验证 run 不再允许优化。

**阶段目标：** 用同日/跨日、节点/留出和完整安全记录决定安装、部分交付或回滚。

**不得跨越：** 默认配置安装、覆盖或提交必须分别获得用户明确授权。

## 执行顺序

1. 先离线生成不可变验证计划和候选/输入 hash。
2. 获授权后完成 CCT、HSI、gamut、INT、跨日和留出验证。
3. 任何候选变化都创建新版本并使旧验证不能充当新候选完整证据。
4. 生成统计报告、失败列表、安装/回滚命令和审计摘要。
5. 到达 Gate-7 后停止；高级模型给出技术结论，用户决定是否实际安装和提交。

## 高级模型决策门 Gate-7

允许技术出口：`install_all`、`deliver_cct_only`、`deliver_hsi_with_explicit_gamut`、`hold_external_candidates`、`repeat_validation`、`rollback`、`stop_route`。高级模型不得把缺少跨日、失败点或不完整关灯记录的 run 判为通过。

用户明确批准安装后，执行模型才备份默认配置、安装、做代表命令 smoke test、双关灯并验证回滚；用户明确说“提交”后才 commit。

## 15. P9：最终独立验证和安装

### 15.1 CCT 验证

- 完整 70 节点。
- 至少 20 个非节点。
- 极端 CCT、GM 塌缩区、active-set 边界。
- 同日和跨日。
- 训练色卡和留出目标。

### 15.2 HSI 验证

- 粗节点和至少 50 个未训练随机点。
- 0/360、SAT0/2/5、SAT90/95/100。
- 每个 `s_exact_max` 两侧。
- 多个 INT 和跨日。

### 15.3 统计报告

必须同时报告：

- P50/P90/P95/max，不只平均值。
- 重复性和置信区间。
- training 与 holdout。
- 同日与跨日。
- 所有失败点。
- CCT 的 RAW、Duv、CCT/mired、multipatch、RGB/white 贡献。
- HSI 的 Hue、SAT progress、正交误差、gamut、white fraction 和 INT 色偏。

### 15.4 最终分支

- **全部通过：** 备份默认配置，安装候选，写 hash 和回滚命令，再做代表命令和关灯 smoke test。
- **节点通过、插值失败：** 不安装，增加节点或更换插值后重新独立验证。
- **同日通过、跨日失败：** 不安装，先解决环境/热态或给出会话校准限制。
- **CCT 通过、HSI 失败：** 允许只交付 CCT，HSI 保持实验状态；两个配置不得捆绑安装。
- **HSI 部分 gamut 不可达但压缩稳定：** 可交付带显式 gamut 状态的 HSI，不得宣称全域精确复制。
- **安全记录不完整或最终关灯未确认：** 整个验证 run 无效。
