## 5. 新发现：REV-C2-003

### REV-C2-003 - Must Fix / Agent-Fixable

**触发：** TD-B v2 formal plan 使用 `native_raw_ambient_policy=unsubtracted_no_ambient`，但 production runner
在 `run_authorized_plan()` 中调用 `required_hsi_features_from_report(report, feature_ids)` 时未显式传入 TD-B
冻结 statistic。共享 helper 因此使用默认 `ambient_subtracted.trimmed_mean_per_second`。

**合同证据：** `docs/README.md` 与项目 skill 均冻结 TD-B v2 的 58-feature statistic 为
`statistics.normalized_per_second.trimmed_mean`；TD-A、TD-C 与其他 caller 才保留 ambient-subtracted default。
public forensic analyzer 已显式使用正确的 no-ambient statistic。

**旧 R1 只读回放：** 对 SHA-256
`64a84ea2b6169c11eb457adc54b8a0839895afc5b2ac9a0729d17e62888ed5bd` 的首张 patch-statistics report：

```text
default ambient_subtracted statistic:
selected=58, included=0, missing_statistic=58, quality_rejected=0

statistics.normalized_per_second.trimmed_mean:
selected=58, included=58, missing_statistic=0, quality_rejected=0
```

直接调用当前 helper 重现：

```text
HsiRejectedFeaturesError: 58 required HSI observer features were rejected
first feature = block_03::G1
status = missing_statistic
quality_status = accepted
weak_signal_only = false
```

旧 report 的六个 raw plane rejection 是 `block_01::B/R`、`block_02::R`、`block_10::B`、`block_12::R`、
`block_15::R`；它们均不属于冻结的 58 feature IDs。正确 statistic 下 58 个 required features 全部质量接受。

**影响：** R1 的 hard failure 实际由 measurement statistic owner 漂移造成，不是已证实的 formal 低信号失败。
若此时交 Advisor 决定 shutter、threshold 或 reacquire，会基于错误根因改变科学合同，并掩盖可离线修复的实现缺陷。

**最小修复方向：** 让共享 helper 接受显式 statistic，同时保留现有 ambient-subtracted default；建立一个共享的
TD-B no-ambient statistic 常量，production runner 与 public analyzer 只在 exact TD-B v2 formal owner 下使用它。
禁止 silent fallback、全局默认变更或仅为旧 R1 特判。
