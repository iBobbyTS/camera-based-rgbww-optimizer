### 5.3 Timed capture scheduler

实现要求：

1. 使用 monotonic clock 记录 command apply、readback 完成和 exposure-start；
2. 60/120 秒目标误差不超过 `+-2 s`；
3. 300/600 秒目标误差不超过 `+-5 s`；
4. source 在 timed points 之间保持同一 command 连续点亮；
5. timed cycle 内不允许 auto-exposure trial；
6. 每 source 的 shutter cache 在 cycle 前冻结；
7. missed timing 使该 capture invalid，不能用附近帧或 wall-clock 时间替代；
8. 每张 capture 记录 requested/actual elapsed、timing error 和有效性；
9. scheduler 支持注入 fake monotonic clock 和 fake sleeper；
10. dry-run 不加载 `.env`、不构造设备 client、不访问网络、不调用 `all_off`。

曝光起点和 source isolation 是执行硬门：

- `exposure_start_monotonic_s` 必须来自相机/remote adapter 的实际曝光开始证据，不能用 host 发起 capture 请求的时间代替；若 adapter 只能提供 request-start，正式 execute 必须 fail closed；
- 每个 run 开始、每个 ambient 前和每次 source transition 后都必须执行双源 all-off/readback，确认 Ray 与 strip 的独立状态均为 off；只关闭当前 source 不满足隔离合同；
- fake backend 和 analyzer 必须能拒绝缺失的 exposure-start provenance、另一 source 未确认 off、以及 command/readback 与 source owner 不一致。

Exposure cache 规则：

- TD-A 使用 P7-R1 retained source-specific shutter 作为首选；
- 如需 exposure setup，只能在 cold cycle 前的独立 setup 阶段进行，且必须记录为非 formal；
- setup 后 shutter 精确冻结，不能在 60/120/300/600 之间插 trial；
- setup 使 source 进入热态时，必须重新满足 cold proxy 后才开始 formal cycle；
- exposure setup 失败则停止 run，不得在 timed cycle 内自适应补救。
