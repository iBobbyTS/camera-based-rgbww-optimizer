## 3. Planner 发现的唯一剩余问题

Ray TD-B dry plan 的 capture ledger 包含未来 D 状态所需的 key，但它没有可声称的值：

```text
frozen_shutters["ray-h120-s50"] = null
exposure_setup_required = ["ray-h120-s50"]
```

strip 的四个 key 都有非空值，Ray 另外三个 key 也有非空值。当前 production validator
`measure_p7_thermal_diagnostics._validate_execution_shutter_ledger()` 会在 backend connect 之前拒绝
该 Ray plan，实际错误为：

```text
PermissionError: thermal diagnostic execution has unresolved shutter setup: ['ray-h120-s50']
```

因此 readiness 中的 `required_shutter_keys_present=true` 只能理解为“ledger 中存在该 key”，不能理解为
“所有 key 已可执行”。当前代码没有实现历史 contract 所说的独立 non-formal setup producer；如果不补齐，
正式 runner 必然在设备动作前停止。这是可修复的执行合同缺口，不是 TD-B 科学结果，也不是设备/相机故障。
