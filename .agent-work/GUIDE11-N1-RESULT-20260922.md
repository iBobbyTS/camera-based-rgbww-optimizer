## 科学结论（初步，条件区间已存分析文件）

1. **重复性分层清楚且量级可用**：暖端/中段（1800–5600）循环间 SD 0.1–2.4K；
   冷端放大（14000: 11K；20000: 40K）。burst 层与循环层量级一致，说明短时噪声
   主导（相机+快速 LED），reset/会话分量未观察到额外大幅系统项。
2. **mired 域重复性远好于 CCT 域**（20000/100：CCT 循环SD 40K 但 mired SD 0.21）。
   GUIDE11 §1.1 "CCT/mired 同一温度方向"在 20000K 端表现为 duv→CCT 映射放大；
   duv 两循环一致到第 4 位小数。导航与验收应以 mired/duv 为主量（已按 §W1 实现
   全容差 E(u)）。
3. **系统性大残差确认**：3200/0（−178K / +17.6 mired）与 14000/0（−230K）两循环
   高度一致——是命令偏差而非噪声，是 W2 有界纠偏的明确对象；duv 也带系统项
   （3200/0 duv −0.0084）。
4. 会话层：两 session 之差即上表 c1−c2 列；n=2 只给条件区间，不外推为会话分布。
