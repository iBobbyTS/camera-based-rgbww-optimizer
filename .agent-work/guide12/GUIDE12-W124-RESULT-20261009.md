## 解释（按 GUIDE 的三类区分）

1. **暖/中段（1800、3200、5600）：协议关联偏移为主**。Ray 参考 LONG−FAST
   仅 +2~+4.5K（稳定）；DiD 几乎全部来自 strip 侧——FAST 冷启动偏移
   （strip−Ray 为 −15.2/−34.6/−20.6K）在 LONG 驻留下收敛到
   −11.4/−16.6/−18.6K，方向一致、幅度小。单次 DiD 为一次观察而非重复
   区间；顺序/时段效应未被设计分离，但 LONG/FAST 交错占位使粗时段混叠
   不成立。
2. **20000/100：不可分离的组合**。Ray 侧 −105.8K 与三重独立证据记录的
   20000K Ray 漂移特性一致（W12-1 两块、N2 组内散布 61.5K、W12-2 三个
   drift-gate 节点）；strip 侧 +410.5K 表明蓝轨命令对驻留时长高度敏感。
   两源同时移动且该点设备本身不稳定——协议效应、顺序效应与设备漂移在
   此点不可分离。
3. **对采用决定的影响：无**。所有 LUT 采用命令均为 FAST 协议验证产物；
   LONG 数据仅描述协议敏感性，不触发重采用、不回灌 FAST 拟合。因此
   "2 个会改变采用决定的风险点各加反序对照（≤8 张）"的分支条件不成立，
   预算保留不烧。
